## Reacquisition and inspection

For each arXiv row, use its explicit version, for example:

```sh
curl -fL --retry 2 https://arxiv.org/pdf/1609.00305v2 -o sources/1609.00305v2.pdf
sha256sum sources/1609.00305v2.pdf
pdfinfo sources/1609.00305v2.pdf
pdftotext -f 4 -l 5 -layout sources/1609.00305v2.pdf -
```

failed to connect; the retained BB94 file was successfully acquired from

returned 404; the retained files are their available v1 versions. Temporary
text extracts and the page image were reading aids generated with the
commands above; the retained original PDFs are the source evidence.
