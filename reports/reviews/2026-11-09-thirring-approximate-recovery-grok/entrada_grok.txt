## 2. Mechanism: a two-particle bound state overlapping the code

The line of argument changed after reading the source; the contract's R2(a)
assumed localized bound states of U, which is not the structure here. In
`sources/1711.03920v1.pdf`, U_2=W_2 V_2(chi) (p.2, Eq.(2); same order as
U=FJ, phase first; same W and chi convention, p.1) commutes with the diagonal
translation and decomposes into fibers U(p) over the half total momentum p
(p.2, Eq.(3) and below). Bound states form one band, one eigenvector per
fiber (p.3, Lemma 2; p.4, Eq.(14) and Proposition 1). They travel in the
centre of mass; they are not normalizable eigenvectors of U on the lattice.
The argument is therefore made fiber by fiber.

Fiber convention: w=x1+x2, y=x1-x2 (w and y of equal parity),
psi_p(y)=sum_w exp(ipw) psi(w,y), p in (-pi/2,pi/2], with
||psi||^2=(1/pi) integral ||psi_p||^2 dp. U and F act fiberwise as U(p) and
W_2(p); U(p)-W_2(p)=W_2(p)(J(p)-I) has rank 2 (y=0, opposite components).

**Step 1 (explicit eigenvector).** At p0=pi/4 one has exp(2i p0)=i=z, the
exceptional case of Eq.(14), p.4. Its "+" vector, with basis order
(up up, up down, down up, down down),

  f(1)=(-i e^{i p0},0,0,0),  f(0)=(0, mu/nu, -mu/nu, 0),
  f(-1)=(i e^{i p0},0,0,0),  f(y)=0 for |y|>=2,

satisfies U(p0) f = i f. Verified exactly as the lattice identity
U[exp(-i p0 w) f(y)] = i exp(-i p0 w) f(y) at every target with w in {0,1};
diagonal translation covariance extends it to all w (verifier check 1).
f is antisymmetric (check 2), ||f||^2=25/8.

**Step 2 (isolation).** W(q) has det 1 and trace 2 nu cos q, so eigenvalues
exp(+-i omega(q)), cos omega=nu cos q, omega in [0,pi]. The spectrum of
W_2(p) is the closure of {exp(-i(s omega(p+k)+r omega(p-k)))}, s,r=+-, k real
(multiplication operator). Equality with i requires a+-b to be congruent to
+-pi/2 (a=omega(p+k), b=omega(p-k)); in all four cases this gives
cos^2 a = sin^2 b, i.e.
nu^2(cos^2(p+k)+cos^2(p-k)) = nu^2(1+cos2p cos2k) = 1. At p0, cos 2p0=0,
so this would require nu^2=1; false. By compactness in k, i lies at positive
distance from sigma(W_2(p0)), which equals sigma_ess(U(p0)) (rank-2
perturbation, Weyl). So i is an isolated eigenvalue of U(p0) with finite
multiplicity. Check 3 verifies the algebraic identities; the case analysis
is written here.

**Step 3 (positive bound-state weight).** Choose a circle Gamma around i in the
resolvent set of U(p0). U(p) depends norm-continuously on p (banded in y,
trigonometric in p), so Gamma stays in the resolvent set for p in an interval
I around p0. The Riesz projection P(p) is norm-continuous there and has
constant finite rank; its range consists of eigenvectors of U(p). The code
fiber vector b_p of input 00 has ||b_p||=1 and is continuous in p. At p0,

  <b_{p0}, P(p0) b_{p0}> >= |<f, b_{p0}>|^2/||f||^2 = 2/(25/8) = 16/25

(<f,b_{p0}> = -i sqrt2, check 4). By continuity the integrand is positive on
I, so with P_I the direct integral of P(p) over I,

  c := ||P_I B|00>||^2 = (1/pi) integral_I <b_p, P(p) b_p> dp > 0.

**Step 4 (that weight never returns to the free frame).** P_I commutes with
U. Split B|00> = P_I B|00> + (I-P_I)B|00>. For each code column b_j,

  <F^T b_j, U^T P_I B|00>> = (1/pi) integral_I <W_2(p)^T b_{j,p}, U(p)^T P(p) b_p> dp.

On ran P(p), U(p)^T is a finite sum of lambda_i(p)^T P_i(p), |lambda_i|=1.
For p in I (taken small around pi/4), every branch
k -> s omega(p+k)+r omega(p-k) is real-analytic (|nu cos|<1) and
non-constant (omega_{++}(p,0)=2omega(p) != pi=omega_{++}(p,pi/2) as p != pi/2;
omega_{+-}(p,0)=0 != omega_{+-}(p,pi/2) as sin p != 0; the others are
negatives). Hence W_2(p) has purely absolutely continuous spectrum and, by
Riemann-Lebesgue on the spectral measure, each <W_2(p)^T b, P_i(p)v> -> 0.
The integrand is bounded by ||b_{j,p}|| ||b_p||, which is integrable, so
dominated convergence gives B_T^dagger U^T P_I B|00> -> 0 (finite rank). Then

  ||K_T|00>|| <= ||(I-P_I)B|00>|| + o(1) = sqrt(1-c) + o(1),

and since ||U^T B|00>||=1 with orthogonal decomposition,

  ||E_T|00>||^2 = 1 - ||K_T|00>||^2 >= c - o(1).

"""Exact checks for the approximate-recovery obstruction of the M=1 Thirring code.

Contract: theory/THIRRING_APPROXIMATE_RECOVERY_GATE.md (commit 61a8215).
Report:   reports/2026-11-09--thirring-approximate-recovery.md

  1. The compact two-particle vector of 1711.03920v1 Eq.(14), as a plane wave
     psi(w,y)=exp(-i p w) f(y), w=x1+x2, y=x1-x2, p=pi/4, satisfies
     U psi = i psi pointwise for U=F J (phase first), mu=3/5, nu=4/5, z=i.
     U commutes with the diagonal translation by one site, under which psi
     picks up the phase exp(-2ip); hence checking every target with w in
     {0,1} (all y) proves the identity on the whole lattice. A larger window
     is checked anyway.
  2. f is antisymmetric under particle exchange.
  3. Isolation: single-particle W(q) has trace 2 nu cos q and det 1, and
     cos^2(p+k)+cos^2(p-k)=1+cos2p cos2k. The written case analysis reduces
     exp(-i(s w(p+k)+r w(p-k)))=i to nu^2(1+cos2p cos2k)=1, impossible at
     p=pi/4 because nu^2 != 1.
  4. Fiber overlaps of the four logical code vectors with f at p=pi/4.

Does NOT certify: the analytic-continuation (Riesz projection) step, the
Riemann-Lebesgue step, absolute continuity of the free fiber spectrum, or the
case analysis behind check 3. Those are written in the report.
No time evolution, no floating point in any certified quantity.
"""
import hashlib
import json
from pathlib import Path

import sympy as sp

ROOT = Path(__file__).resolve().parents[1]
OUT = ROOT / "reports/2026-11-09--thirring-approximate-recovery"
CHECKS = []

I = sp.I
MU, NU, Z = sp.Rational(3, 5), sp.Rational(4, 5), sp.I
P0 = sp.pi / 4
R, L = 0, 1  # component index: R == up, L == down (1711.03920v1 p.1 convention)


def exact(name, condition):
    CHECKS.append(dict(name=name, passed=bool(condition)))


def simp(x):
    return sp.nsimplify(sp.simplify(sp.expand_complex(x)))


def iszero(x):
    return sp.simplify(sp.expand_complex(x)) == 0


# ---------- the claimed bound state, 1711.03920v1 p.4 Eq.(14), "+" case ----------
# basis order (a1 a2) = (up up, up down, down up, down down)
BASIS = [(R, R), (R, L), (L, R), (L, L)]
EP = sp.exp(I * P0)
F_REL = {
    1: [-I * EP, 0, 0, 0],
    0: [0, MU / NU, -MU / NU, 0],
    -1: [I * EP, 0, 0, 0],
}


def psi(x1, a1, x2, a2):
    """Plane-wave amplitude exp(-i p0 w) f_{a1 a2}(y)."""
    y, w = x1 - x2, x1 + x2
    if y not in F_REL:
        return sp.Integer(0)
    return sp.exp(-I * P0 * w) * F_REL[y][BASIS.index((a1, a2))]


def J(amp):
    def out(x1, a1, x2, a2):
        v = amp(x1, a1, x2, a2)
        return Z * v if (x1 == x2 and a1 != a2) else v
    return out


def W_preimages(x, a):
    """(coefficient, source site, source component) with (W phi)(x,a)=sum c phi(src)."""
    if a == R:
        return ((NU, x - 1, R), (-I * MU, x, L))
    return ((-I * MU, x, R), (NU, x + 1, L))


def F(amp):
    def out(x1, a1, x2, a2):
        s = 0
        for c1, y1, b1 in W_preimages(x1, a1):
            for c2, y2, b2 in W_preimages(x2, a2):
                s += c1 * c2 * amp(y1, b1, y2, b2)
        return s
    return out


def check_eigenvector():
    U_psi = F(J(psi))
    ok_all, ok_core = True, True
    for x1 in range(-6, 7):
        for x2 in range(-6, 7):
            for a1, a2 in BASIS:
                good = iszero(U_psi(x1, a1, x2, a2) - I * psi(x1, a1, x2, a2))
                ok_all &= good
                if x1 + x2 in (0, 1):
                    ok_core &= good
    exact("eq14-eigenvector-all-targets-w-in-{0,1}", ok_core)
    exact("eq14-eigenvector-window-|x|<=6", ok_all)
    exact("eigenvalue-equals-exp(2ip0)-equals-z", iszero(sp.exp(2 * I * P0) - Z))
    exact("diagonal-translation-phase-exp(-2ip0)",
          all(iszero(psi(x1 + 1, a1, x2 + 1, a2) - sp.exp(-2 * I * P0) * psi(x1, a1, x2, a2))
              for x1 in range(-3, 4) for x2 in range(-3, 4) for a1, a2 in BASIS))


def check_antisymmetry():
    swap = [0, 2, 1, 3]
    exact("f-antisymmetric-E f(-y)=-f(y)",
          all(iszero(F_REL[-y][swap[j]] + F_REL[y][j]) for y in (-1, 0, 1) for j in range(4)))


def check_isolation():
    q, p, k = sp.symbols("q p k", real=True)
    Wq = sp.Matrix([[NU * sp.exp(I * q), -I * MU], [-I * MU, NU * sp.exp(-I * q)]])
    exact("W(q)-det-1", iszero(Wq.det() - 1))
    exact("W(q)-trace-2nu-cos-q", iszero(sp.expand_complex(Wq.trace()) - 2 * NU * sp.cos(q)))
    ident = sp.cos(p + k) ** 2 + sp.cos(p - k) ** 2 - 1 - sp.cos(2 * p) * sp.cos(2 * k)
    exact("cos-square-sum-identity", sp.simplify(sp.expand_trig(ident)) == 0)
    exact("cos2p-zero-at-p0", sp.cos(2 * P0) == 0)
    exact("nu-squared-not-one", NU ** 2 != 1)


def code_vectors():
    """Logical inputs ab: A in mode a of (R@0, L@1), B in mode b of (R@1, L@0)."""
    A = [(0, R), (1, L)]
    Bm = [(1, R), (0, L)]
    vecs = {}
    for a in range(2):
        for b in range(2):
            (xa, ca), (xb, cb) = A[a], Bm[b]
            vecs[f"{a}{b}"] = {(xa, ca, xb, cb): 1 / sp.sqrt(2), (xb, cb, xa, ca): -1 / sp.sqrt(2)}
    return vecs

## 1. Teorema y alcance

Para el código microscópico M=1 del trabajo anterior, regla fija con
mu=3/5,nu=4/5,chi=pi/2, recta infinita y salida libre exacta F^T B:

\[
 \boxed{\text{para todo entero }T\ge2,\quad
 \nexists\,V\in\mathbb C^{4\times4}:\ U^T B=F^T B V.}
\]

Se excluye cualquier matriz V, y en particular una unitaria entrelazante.
Más concretamente, la entrada producto lógica 01 tiene fuga estrictamente
positiva para cada T>=2. En T=1 permanece la puerta exacta D ya comprobada.

Veredicto: `EXACT_RECOVERY_EXCLUDED_FOR_ALL_FINITE_T_GE2 /
FIRST_STEP_GATE_RETAINED / APPROXIMATE_RECOVERY_OPEN`.

exclusión con este código. La ejecución y el contrato físico conservan

No se excluyen recuperación aproximada, otro código de salida, medidas,

## 2. Definiciones y coordenadas

Se mantiene U=FJ y

\[
 W=\begin{pmatrix}\nu\mathsf T&-i\mu\\-i\mu&\nu\mathsf T^{-1}\end{pmatrix},
 \quad J=\prod_x e^{i\chi n_R(x)n_L(x)}.
\]

La traslación espacial se escribe mathsf T para distinguirla del tiempo T.
El modelo publicado se consultó en `1804.08508v1.pdf` p.3, Ec.(1) y sección 3.
La fase precede al paso libre. La orientación R/L es la declarada en los
informes previos; no cambia la interacción local.

Los qubits iniciales son A=(R|0>,L|1>) y B=(R|1>,L|0>), con producto de
creación en orden A,B. Escribimos B para la isometría de sus cuatro
entradas, en orden 00,01,10,11. Como antes, los modos pertenecen a sectores
opuestos de Gamma=sigma_z(-1)^x. En cada tiempo se sigue cada etiqueta
en su sector alternante. Las amplitudes ordenadas por sus dos posiciones
son una representación isométrica del sector fermiónico correspondiente,
no una eliminación de la estadística sin justificación.

Explícitamente, para modos de sectores opuestos, el mapa es
I_t(psi tensor phi)=(psi tensor phi-phi tensor psi)/sqrt(2).
Es isométrico porque los sectores son ortogonales. La evolución libre
satisface F I_t=I_{t+1}(W tensor W): se conserva el orden A,B mientras
sus sectores alternan. J conserva esta imagen y actúa como fase z solo
si las posiciones coinciden, pues entonces las componentes son opuestas.
Así no se introduce un signo dependiente del camino al usar posiciones
ordenadas A,B, tanto para U como para F.

La salida B_T=F^T B se obtiene de modos libres de una partícula. No depende
de U, de V o del estado lógico de entrada. No se aplica F^{-T} como control.

El primer contacto preserva el código:

\[
 JB=BD,\qquad D=\operatorname{diag}(1,z,z,1),\qquad UB=FB D.
\]

## 3. Cuatro rayos extremos fuerzan la matriz V

En el sector ordenado de Gamma opuestos, sea Pi_T la extracción de las
cuatro amplitudes en posiciones (x_A,x_B), en este orden:

\[
 (T,T+1),\quad(1-T,T+1),\quad(T,-T),\quad(1-T,-T).
\]

Son cuatro coordenadas ortogonales, así que ||Pi_T||=1. Para T>=1,

\[
 R_T:=\Pi_T F^T B=\nu^{2T-1}G,\qquad
 G=\begin{pmatrix}
 \nu&0&-i\mu&0\\
 -i\mu&0&\nu&0\\
 0&\nu&0&-i\mu\\
 0&-i\mu&0&\nu
 \end{pmatrix},\qquad G^\dagger G=I.
\]

Justificación de los factores, sin extrapolar casos finitos:

- B en T+1 solo proviene del modo inicial R|1> mediante T traslaciones
  a derecha. Su amplitud es nu^T. Ninguna trayectoria del modo L|0>
  puede llegar allí: necesita primero convertir su componente y pierde
  al menos un desplazamiento.
- B en -T solo proviene del modo inicial L|0> por T traslaciones a
  izquierda, también con amplitud nu^T.
- A en T tiene amplitudes (nu^T,-i mu nu^(T-1)) desde sus modos 0 y 1.
  A en 1-T tiene amplitudes (-i mu nu^(T-1),nu^T). Para esos extremos,
  la conversión de componente, cuando hace falta, tiene que ocurrir
  en el primer paso; después todas las traslaciones deben ser exteriores.

Además, las trayectorias extremas de B no pueden volver a contactar con A
tras t=0: B corre hacia fuera a velocidad máxima, y después del primer
paso A queda estrictamente detrás. En efecto, para t>=1 cualquier trayectoria
de A satisface 1-t<=x_A(t)<=t: desde R0 no puede empezar a izquierda,
y desde L1 no puede empezar a derecha; una conversión de componente
consume un paso sin desplazamiento. Frente a ello los rayos de B están
en t+1 o -t. Una trayectoria de A de alcance uno
por paso no puede alcanzarlo. Esto vale independientemente de los caminos
internos de A. Las únicas fases posibles son las del contacto inicial,
por lo que para **todos** los T>=1,

\[
 \Pi_T U^T B=R_T D.
\]

Como nu>0 y G es unitaria, R_T es invertible. Si existiera una matriz V
con U^T B=F^T B V, al extraer esas coordenadas se obtendría
R_T V=R_T D y necesariamente **V=D**. Esto incluye cualquier fase global
o cambio de base lógico que se pretendiera absorber en V.

## 4. El segundo contacto emite una amplitud que no puede cancelarse

Definimos Delta_T=U^T B-F^T B D. Usando UB=FB D y telescopaje de potencias,

\[
 \Delta_T=\sum_{k=1}^{T-1}
 U^{T-1-k}F(J-I)F^k B D,\qquad T\ge2.
\]

Cada factor J-I es (z-1)C, con C el proyector de coincidencia de dos
componentes opuestas. Su fuente tiene separación relativa cero. Desde
la fuente k quedan T-k pasos: la separación relativa absoluta alcanzable
es como máximo 2(T-k), porque cada partícula se desplaza a lo sumo
una celda por paso y el contacto no mueve posiciones.

Consideremos la entrada lógica 01, y extraigamos la coordenada

\[
 q_T=(1-T,T-1),\qquad x_A-x_B=-2(T-1).
\]

Ningún término k>=2 puede llegar a q_T, pues 2(T-k)<2(T-1).
Para k=1, sobre esa entrada, la única coincidencia tras el primer paso
libre es la rama de masa en el sitio cero:

\[
 CFB D|01\rangle=-\mu^2z\,|L0,R0\rangle.
\]

Para llegar desde allí a q_T en los T-1 pasos restantes, A debe trasladarse
siempre a izquierda y B siempre a derecha. Es un único par de caminos,
de peso nu^(2T-2), sin nuevos contactos. Por consiguiente,

\[
 \boxed{\langle q_T|\Delta_T|01\rangle
 =-\mu^2z(z-1)\nu^{2T-2}\ne0,\qquad T\ge2.}
\]

Con los parámetros congelados es mu² nu^(2T-2)(1+i). En numeradores
gaussianos sobre el denominador 25^T, sus dos componentes son exactamente
9*4^(2T-2). No hay suma de fases tardías que pueda anular esta amplitud:
las fuentes tardías tienen un cono de separación relativa demasiado corto.

La sección 3 forzaba V=D. Esta amplitud contradice U^T B=F^T B D y cierra
la posibilidad para cualquier T>=2. La prueba no procede de buscar
numéricamente un tiempo de recuperación y no utiliza un anillo finito.

Incluso si solo se exigiera recuperar la entrada 01 en algún vector del
código libre, sus cuatro amplitudes extremas fuerzan los coeficientes a
D|01>. La misma coordenada q_T lo impide. Por tanto esa entrada producto
queda fuera del código libre en todo T>=2.

## 5. Cota cuantitativa y distinción entre exacto y aproximado

Una segunda formulación usa la compresión y el residuo, sin suponer una
recuperación exacta. Sean

\[

\[

Al extraer q_T de Delta_T=E_T+B_T(K_T-D), con B_T isométrica,

\[
 |\langle q_T|\Delta_T|01\rangle|

\]

Resulta una cota explícita para la probabilidad de fuga de la entrada 01:

 \boxed{p_{01}(T)\geq
