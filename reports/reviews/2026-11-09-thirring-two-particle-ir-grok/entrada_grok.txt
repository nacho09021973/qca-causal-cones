- O3: inside the frozen window ((+,+) near +2 omega0) there is **no** bound

  bound branch does exist at the opposite threshold (-2 omega0); it lies

Scope: family F = {chi = pi/2, 0 < mu < 1}, two-fermion sector of the

## 2. O1 and O2

- **O1.** Since J acts before F and the only same-site opposite-component
  pairs of the M=1 code are inputs 01 and 10, U B = F J B = F B D with
  D = diag(1,i,i,1) for every mu (certified for symbolic mu, rational
  parametrization mu = 2s/(1+s^2)). Property (G) holds along F.
- **O2.** omega(q) = acos(nu cos q): omega'(0) = 0, omega''(0) = nu/mu,
  omega^2 = omega0^2 + c_f^2 q^2 + O(q^4) with omega0 = acos(nu) = asin(mu),
  c_f^2 = omega0 nu / mu. Limits omega0/mu -> 1, c_f^2 -> 1. A free pair at
  total momentum P has threshold 2 omega(P/2) = 2 omega0 + omega''(0) P^2/4,
  so its squared threshold is (2 omega0)^2 + c_f^2 P^2 + O(P^4): same c_f.

## 3. O3: the bound branch

Conventions of `sources/1804.08508v1.pdf` (p.3-4): k is the half-relative
momentum, p the half-total momentum, P = 2p, v^s_q = (-i mu, g_s(q)),
g_s(q) = -i(s sin omega(q) + nu sin q). By 1804.08508 p.10 and 1711.03920
Lemma 2 (p.3), a proper eigenvector requires T_+ = 0 or T_- = 0 at complex
k = k_R + i k_I with k_I < 0; for (+,+) eigenphases, k_R is 0 or pi
(1711.03920 Lemma 1).

### 3.1 No bound state at the (+,+) threshold +2 omega0

At p = 0, k = i kappa, chi = pi/2, the numerator of T_+ is
(-i)(1-i)(S - nu sinh kappa), where S = sqrt(1 - nu^2 cosh^2 kappa) >= 0
(certified). It vanishes only if sinh kappa = S/nu >= 0, i.e. k_I >= 0. That
solution is not normalizable. Small p != 0: Lemma 2 gives exactly one bound
state per p (e^{2ip} != i). At p = 0, 1804.08508 p.13 gives the point
spectrum {e^{-2i omega(k~)}, 1}. The bound state identified in 3.2 is
therefore the only one, and it is not at +2 omega0. By continuity in p,
the window has no bound branch near P = 0.

### 3.2 The bound branch at k_R = pi

With g_+(x ± pi) = -g_-(x), the T_+ = 0 condition at k = pi + i kappa
becomes X(p + i kappa) = i conj(X(p + i kappa)), with
X(z) = sin omega(z) - nu sin z. Equivalently Re X = Im X, a single real
equation. At p = 0 it gives sin omega(i kappa) = -nu sinh kappa, hence
cosh 2 kappa = 1/nu^2 with kappa < 0 (normalizable). The eigenphase is
e^{i M_b} with

  cos M_b = nu^2,   M_b = 2 asin(mu/sqrt2),   M_b < 2 omega0.

The eigenvector (1804.08508 Eq.(19), y >= 0, restricted to the
opposite-Gamma pattern) is f_j(y) = 2 u_j lambda^y, with
u = v^{++}_{pi + i kappa} ∝ (1, (1-i)/sqrt2, (1+i)/sqrt2, 1),
lambda = -t, t = e^kappa = (sqrt(2-mu^2) - mu)/(sqrt2 nu) in (0,1), the
factor e^{-i chi} on the up-down component at y = 0, and antisymmetric
extension to y < 0. Certified as a pointwise lattice eigenvector of U = FJ
with eigenvalue (1-mu^2) + i mu sqrt(2-mu^2) at mu = 3/5 and mu = 5/13, on
every target with |x1|, |x2| <= 5.

This covers all sites. For |y| >= 3 every equation involves only y' with
|y'| >= 1 on the same side. The equations there are lambda^y times a fixed
pattern of period 2 in y, so y = 3, 4 settle all of them. y in {0, 1, 2} is
checked directly. y < 0 follows from exchange symmetry, and all w from
translation invariance (p = 0). This argument is written here, not certified.

### 3.3 Curvature and limits

Implicit differentiation of Re X = Im X at p = 0 (z0 = i kappa0, all
quantities exact):

- omega'(z0) = -i and omega''(z0) = 2 sqrt2 C0/mu, with
  C0 = cos omega(z0) = sqrt((1+nu^2)/2);
- kappa''(0) = -F_pp/F_kappa;
- E''(0) = 2 sqrt2 nu^2/(C0 mu), where E(p) = 2 Re omega(p + i kappa(p)) is
  the distance of the eigenphase from the -2 omega0 edge.

Hence

  omega_b^2 = M_b^2 + c_b^2 P^2 + O(P^4),   c_b^2 = M_b nu^2 / (sqrt2 C0 mu).

Limits as mu -> 0: M_b/mu -> sqrt2, c_b^2 -> 1, and
c_b^2 - c_f^2 = -mu^2/3 + O(mu^4). At mu = 3/5: c_b^2 = 0.72989, while
c_f^2 = 0.85800. A floating-point finite difference, labelled illustration,
gives 0.7298921 against the closed form 0.7298921.

Which threshold carries the bound branch depends on the sign of chi.
Complex conjugation maps W(q) to sigma_z W(-q) sigma_z and J(chi) to
J(-chi). So at chi = -pi/2 the same branch, with the same M_b and c_b,
would sit at +2 omega0. This is a written remark, not certified. The
infinite-dimensional eigenvalue-1 space at p = 0 (the (+,-) states, of
quasienergy 0; 1804.08508 p.13) is a single fibre and lies outside the
window.

The limit (R) is established at the level of the rest mass and the P^2
coefficient. The full scaling function omega_b(mu Q)/mu was not computed.

## 4. O4: why it stays OPEN

- Gamma = sigma_z (-1)^x anticommutes with W (certified on the lattice). So
  Gamma_1 Gamma_2 commutes with W ⊗ W, and the opposite-Gamma subspace (the
  subspace P of 1804.08508 Eq.(8)) is invariant.
- A P-state built from a (+,+) pair at momenta (q1, q2) necessarily contains
  the (-,-) pair at (q1+pi, q2+pi). This "doubler" component carries weight
  1/2 whether or not the particles interact, in incoming and outgoing
  states alike, independent of mu.
- Within P, the scattering eigenvectors of Eq.(18) map P(+,+;k) to
  T_+ P(+,+;-k). For fermions this is a phase on the same momentum pair.
  This is a written argument; I have not done a wave-packet proof.
- At low energy, g_+(mu Q)/(-i mu) -> sqrt(1+Q^2) + Q = e^{theta}, with
  rapidity theta = asinh Q (certified). Hence
  T_+ -> (e^{Delta/2} + e^{-i chi} e^{-Delta/2}) / (e^{-Delta/2} + e^{-i chi} e^{Delta/2}),
  which depends only on the rapidity difference Delta. This is consistent
  with a relativistic two-body phase.

The frozen O4 asks for "the outgoing weight carried by the doubler
components", defined by a wave-packet analysis to be stated in the report
before evaluation. Read literally, that weight is 1/2, nonzero and
mu-independent, but it is equally present in the incoming state. Read as
transfer, the written argument gives zero. Choosing the reading after having
derived both would be a post-hoc definition. O4 is therefore recorded as not
decided, and the contract wording is flagged as defective.

## 5. What this means for the coexistence question

- Along F, the T=1 gate and a two-particle low-energy sector coexist at the
  same points.
- In that sector, the free pairs and the only bound branch (at -2 omega0)
  approach the same speed as mu -> 0.
- The low-energy two-body phase depends only on rapidity differences.
- Open: the doubler question (O4, a definitional issue), the full scaling
  function, composable gates, many-body and finite-density behaviour, and
  whether the T=1 gate acts on low-energy states at all. The M=1 code is a
  lattice-scale state, not an IR wave packet.

count (decision of 2026-11-09).

S_PAR = sp.symbols("s", positive=True)          # mu = 2s/(1+s^2), nu = (1-s^2)/(1+s^2), 0<s<1
MU_S = 2 * S_PAR / (1 + S_PAR**2)

def exact(name, cond):
    CHECKS.append(dict(name=name, passed=bool(cond)))


def iszero(x):
    x = sp.expand(sp.expand_complex(x))
    if x == 0:
        return True
    return sp.simplify(sp.radsimp(x)) == 0


# ---------------- lattice machinery (first-quantized two-fermion amplitudes) ----------------
def W_pre(x, a, MU, NU):
    """(coef, src site, src comp) with (W phi)(x,a) = sum c phi(src). R moves right."""
    if a == R:
        return ((NU, x - 1, R), (-I * MU, x, L))
    return ((-I * MU, x, R), (NU, x + 1, L))


def F_op(amp, MU, NU):
    def out(x1, a1, x2, a2):
        s = 0
        for c1, y1, b1 in W_pre(x1, a1, MU, NU):
            for c2, y2, b2 in W_pre(x2, a2, MU, NU):
                s += c1 * c2 * amp(y1, b1, y2, b2)
        return s
    return out


def J_op(amp):
    def out(x1, a1, x2, a2):
        v = amp(x1, a1, x2, a2)
        return Z * v if (x1 == x2 and a1 != a2) else v
    return out


# ---------------- O1 ----------------
def check_O1():
    mu, nu = MU_S, NU_S
    A = [(0, R), (1, L)]
    Bm = [(1, R), (0, L)]
    D = [1, Z, Z, 1]
    ok = True
    for j, (a, b) in enumerate([(0, 0), (0, 1), (1, 0), (1, 1)]):
        (xa, ca), (xb, cb) = A[a], Bm[b]
        vec = {(xa, ca, xb, cb): 1, (xb, cb, xa, ca): -1}
        amp = lambda x1, a1, x2, a2, vec=vec: vec.get((x1, a1, x2, a2), 0)
        UB = F_op(J_op(amp), mu, nu)
        FB = F_op(amp, mu, nu)
        for x1 in range(-2, 4):

# ---------------- O2 ----------------
def check_O2():
    mu, q = sp.symbols("mu q", positive=True)
    nu = sp.sqrt(1 - mu**2)
    om = sp.acos(nu * sp.cos(q))
    d2 = sp.simplify(sp.diff(om, q, 2).subs(q, 0))
    exact("O2-omega''(0)=nu/mu", iszero(d2 - nu / mu))
    exact("O2-omega'(0)=0", iszero(sp.diff(om, q).subs(q, 0)))
    om0 = sp.acos(nu)
    cf2 = om0 * nu / mu
    ser = sp.series(om**2, q, 0, 4).removeO()
    exact("O2-omega^2-q^2-coefficient=c_f^2", iszero(ser.coeff(q, 2) - cf2))
    exact("O2-limit-omega0/mu=1", sp.limit(om0 / mu, mu, 0, "+") == 1)
    exact("O2-limit-c_f^2=1", sp.limit(cf2, mu, 0, "+") == 1)
    return cf2, mu


# ---------------- O3 ----------------
def bound_vector(MU):
    """p=0, k~ = pi + i kappa, cosh(2 kappa)=1/nu^2, kappa<0. Returns f(y) and lambda_b."""
    NU = sp.sqrt(1 - MU**2)
    r = (1 - MU * sp.sqrt(2 - MU**2)) / NU**2          # t^2, t = e^{kappa}
    lam = -TT                                            # e^{-i k~}
    # v^{++}_{k~} components, from g_+(pi+i kappa)=-i mu (1+i)/sqrt2, g_+(-pi-i kappa)=-i mu (1-i)/sqrt2
    gpk = -I * MU * (1 + I) / sp.sqrt(2)
    gmk = -I * MU * (1 - I) / sp.sqrt(2)
    a, b, c, d = -MU**2, -I * MU * gmk, -I * MU * gpk, gpk * gmk
    def f(y, comp):
        if y >= 0:
            if comp in (0, 3):
                if y % 2 == 1:
                    return 2 * (a if comp == 0 else d) * lam**y
                return 0
            if y % 2 == 0:
                val = 2 * (b if comp == 1 else c) * lam**y
                if comp == 1 and y == 0:
                    val = val / Z                          # e^{-i chi} on component 2 at y=0
                return val
            return 0
        swap = {0: 0, 1: 2, 2: 1, 3: 3}
        return -f(-y, swap[comp])
    lam_b = (1 - MU**2) + I * MU * sp.sqrt(2 - MU**2)    # e^{i M_b}, cos M_b = nu^2
    return f, lam_b, r, (a, b, c, d), (gpk, gmk), NU


def reduce_T(expr, r):
    """Reduce a polynomial in T modulo T^2 = r; return the two coefficients."""
    poly = sp.Poly(sp.expand(expr), TT)
    rem = sp.rem(poly, sp.Poly(TT**2 - r, TT))
    return [rem.coeff_monomial(TT**k) for k in (0, 1)]


def check_O3_eigenvector(MU, tag):
    f, lam_b, r, (a, b, c, d), (gpk, gmk), NU = bound_vector(MU)
    exact(f"O3a-{tag}-decay-0<t^2<1", bool(0 < r < 1))
    t_exp = (sp.sqrt(2 - MU**2) - MU) / (sp.sqrt(2) * NU)        # denested sqrt(r)
    exact(f"O3a-{tag}-t_explicit^2=r-and-0<t<1", iszero(t_exp**2 - r) and bool(0 < t_exp < 1))
    exact(f"O3a-{tag}-T+numerator-zero", iszero(gpk + sp.conjugate(Z) * gmk))
    exact(f"O3a-{tag}-|lambda_b|=1", iszero(sp.Abs(lam_b)**2 - 1))
    exact(f"O3a-{tag}-cos-M_b=nu^2", iszero(sp.re(lam_b) - NU**2))
    psi = lambda x1, a1, x2, a2: f(x1 - x2, BASIS.index((a1, a2)))
    Upsi = F_op(J_op(psi), MU, NU)
    ok, nonzero = True, False
    for x1 in range(-5, 6):
        for x2 in range(-5, 6):
            for a1, a2 in BASIS:

                ok &= iszero(A + B * t_exp)
                A, B = reduce_T(psi(x1, a1, x2, a2), r)

    exact(f"O3a-{tag}-lattice-eigenvector-window-|x|<=5", ok and nonzero)

def check_O3b():
    kap = sp.symbols("kappa", real=True)
    nu = sp.symbols("nu", positive=True)
    S = sp.sqrt(1 - nu**2 * sp.cosh(kap)**2)
    sh = sp.sinh(kap)

    gm = -I * (S - I * nu * sh)       # g_+(-i kappa)
    num = sp.expand(gp + sp.conjugate(Z) * gm)
    target = sp.expand((-I) * (1 - I) * (S - nu * sh))
    exact("O3b-Gamma0-T+numerator=(-i)(1-i)(S-nu sinh kappa)", iszero(num - target))
    # S >= 0, so S = nu sinh(kappa) forces kappa >= 0: k_I = kappa > 0, not normalizable.


def check_O3c(cf2_mu, mu_sym):

    om0_s = 2 * sp.atan(S_PAR)                       # = acos(nu) for s in (0,1)

technique. However, discreteness of the evolution prevents the application of the usual Ansatz, and a
new Ansatz has been introduced successfully [1].
        In this paper we present an original simplified derivation of the solution of Ref. [1] which exploits
the symmetries of the interacting walk. We present the diagonalization of the evolution operator and
the characterization of its spectrum. We explicitly write the two particle states corresponding to the
scattering solutions of the system, having eigenvalues in the continuous spectrum of the evolution
operator. We then show how the present model predicts the formation of bound states, which are
eigenstates of the interacting walk corresponding to the discrete spectrum. We provide also in this
case the analytic expression of such molecular states.
        We remark the phenomenological differences between the Hamiltonian model and the
discrete-time one. First we see that the set of possible scattering solutions is larger in the discrete-time
case: for a fixed value total momentum, a non trivial transfer of relative momentum can occur besides
the simple exchange of momentum between the two particles, differently from the Hamiltonian case.
Also the family of bound states appearing in the discrete-time scenario is larger than the corresponding
Hamiltonian one. Indeed, for any fixed value of the coupling constant, a bound state exists with
any possible value of the total momentum, while for Hamiltonian systems bound states cannot have
arbitrary total momentum.
        Finally we show that in the set of solutions for the interacting walk there are perfectly localized
states (namely states which lie on a finite number of lattice sites) and, differently from the Hamiltonian
systems, bound states exist also for vanishing coupling constant. In addition to the exact analytical
solution of the dynamics we show the simulation of some significant initial state.

3. The Thirring Quantum Walk
     In this section we present a Fermionic cellular automaton in one spatial dimension with an on-site
interaction, namely two particles interact only when they lie at the same lattice site. The linear part
corresponds to the Dirac QW [44] and the interaction term is the most general number-preserving
coupling in one dimension [45]. The same kind of interaction characterizes also the most studied
integrable quantum systems, such as the Thirring [46] and the Hubbard [47] models.
     The linear part of the N-particle walk is described by the operator WN := W ⊗ N , acting on the
Hilbert space H N = H ⊗ N and describing the free evolution of the particles. In order to introduce
an interaction, we modify the update rule of the walk with an extra step Vint : UN := WN Vint . In the
present case the term Vint has the form

                                               Vint = VN (χ) := eiχn↑ ( x)n↓ ( x) ,

where n a ( x ), a ∈ {↑, ↓}, represents the particle number at site x, namely n a ( x ) = ψa† ( x )ψa ( x ), and χ is
a real coupling constant. Since the interaction term preserves the total number operator we can study
the walk dynamics for a fixed number of particles. In this work we focus on the two-particle sector
whose solutions has been derived in Ref. [1]. As we will see, the Thirring walk features molecule states
besides scattering solutions. This features is shared also by the Hadamard walk with the same on-site
interaction [48].

4. Symmetries of the Thirring Quantum Walk
      The Thirring walk manifests some symmetries that allow to simplify the derivation and the
study of the solutions. First of all, as we already mentioned, one can show that the interaction V (χ)
commutes with the total number operator. This means that one can study the walk dynamics separately
for each fixed number of particles. We focus here on the two-particle walk U2 = W2 V2 (χ), where

5.4. Solutions for p ∈ {0, π/2}
    The solutions that we presented in the previous discussion do not cover the extreme values
p = 0, π/2 (see Ref. [1] for a reference). Let us consider for definiteness the case p = 0 since the other
Version April 24, 2018 submitted to Entropy                                                              13 of 16



case is obtained in a similar way. For e−iω 6= 1 the previous analysis still holds. Indeed, noticing
that ω±± (0, k) = ±2ω (k ), we have ω (k) ∈ R and ω (k ) 6= 0 if and only if k ∈ Γ f ∪ Γ0 ∪ Γ2 , whereas
ω±∓ (0, k ) = 0 for all k ∈ C. This means that the solutions |ψk+ i of Eq. (18) are actually eigenvectors of
U2 (χ, 0). Thus, the spectrum is made by a continuous part, given by the arc of the unit circle containing
−1 and having e±2iω (0) as extremes, and a point spectrum with two points: e−2iω (k̃) , where k̃ is the
solution of T+ = 0 for p = 0, and 1. As shown in Ref. [1], 1 is a separated part of the spectrum of
U2 (χ, 0) and the corresponding eigenspace is a separable Hilbert space of stationary bound states.
This fact underlines an important feature of the Thirring walk not shared by analogous Hamiltonian
models. It is remarkable that this behaviour occurs also for the free walk with χ = 0. In Fig. 6 we show
the probability distribution of two states having he properties hereby discussed. It is worth noticing
that all the states v+−
                      k   with k ∈ (−π, π ] are eigenvectors relative to the eigenvalue 1, and thus they
generate a subspace on which the walk acts identically. We remark that this behaviour relies on the
fact that the dispersion relation in one dimension is an even function of k.

spectrum as a function of the total momentum p. The solid curves in the gaps between the
continuous bands denote the discrete spectrum for different values of the coupling constant χ =

on-site interaction [48].

6. Conclusions
     In this work we reviewed the Thirring quantum walk providing a simplified derivation of its
solutions for Fermionic particles. The simplified derivation relies on the symmetric properties of the
walk evolution operator allowing to separate the subspace of solutions affected by the interaction
from the subspace where the interaction step acts trivially. The interaction term is the most general
number-preserving interaction in one dimension, whereas the free evolution is provided by the Dirac
QW [44].
     We showed the explicit derivation of the scattering solutions (solutions for the continuous
spectrum) as well as for the bound-state solutions. The Thirring walk features also localized bound
states (namely, states whose support is finite on the lattice) when e−iω = e±i2p . Such solutions exist
only when the coupling constant is χ = 2p. In Fig. 3 is depicted the evolution of a perfectly localized
state showing the overlapping with bound states components. In Fig. 5 we reported the evolution
of a bound state of the two particles peaked around a certain value of the total momentum: one
can appreciate that the probability distribution remains localized on the main diagonal during the
evolution.
     Finally, we discussed also the class of proper eigenvectors arising in the free theory highlighting
another difference between the discrete model of the present work with analogous Hamiltonian
models.

                                                                             The Thirring quantum cellular automaton

                                                           Alessandro Bisio,∗ Giacomo Mauro D’Ariano,† Paolo Perinotti,‡ and Alessandro Tosini§
                                                                    Dipartimento di Fisica dell’Università di Pavia, via Bassi 6, 27100 Pavia and
                                                                     Istituto Nazionale di Fisica Nucleare, Gruppo IV, via Bassi 6, 27100 Pavia

                                                            We analytically diagonalize a discrete-time on-site interacting fermionic cellular automaton in
                                                          the two-particle sector. Important features of the solutions sensibly differ from those of analogous
                                                          Hamiltonian models. In particular, we found a wider variety of scattering processes, we have bound
                                                          states for every value of the total momentum, and there exist bound states also in the free case,
                                                          where the coupling constant is null.
