## 3. Arguments

- **L1.** Tr U = z + 1/z and det U = 1 (exact), so cos omega = cos k and
  omega = |k| on the branch. Group speed is 1 = c_0 everywhere.
- **L2, L3.** Exact identities: Tr U / 2 = prod_j cos p_j, det U = 1, and
  c_0 = 1/L, with p_j = k_j/L and L = sqrt d. Then
  omega = arccos(prod cos p_j) and, with a_j = cos^2 p_j,

    L^2 |grad_k omega|^2 = sum_j (1 - a_j) prod_{i≠j} a_i / (1 - prod a_i).

  This is at most 1 iff f(a) = 1 - prod a - sum_j (1 - a_j) prod_{i≠j} a_i ≥ 0
  on [0,1]^d. f is multilinear, so its minimum is attained at a vertex.
  All vertex values are ≥ 0 (certified for d = 2, 3). Hence
  |grad omega| ≤ 1/L = c_0, with equality along the axes, so
  V_grp^max = c_0.
- **Rows with beta not identically 0.** The parent's exact expansion gives
  |grad eps_+|/c_0 ≥ 1 + 2 beta(n̂) t + O(t^2) along k = t n̂, with the
  radial derivative as a lower bound. beta is positive on a declared ray
  (exact):

  | Row | Ray | beta |
  | --- | --- | --- |
  | L5a, L5b | +111 | 1/9 |
  | L4 | -111 | 1/9 |
  | L6a | theta = 60° | sqrt15/36 |
  | L6b | theta = 0° | sqrt15/18 |
  | L3s4, upper-sign cluster | +111 or -111 | the two values sum to 2 beta0 > 0 for all 0 < a < 1 |

  So super-c holds for small t. For the 2x2 rows an explicit point on the
  rational grid is also certified by rigorous interval arithmetic. The
  certified lower bounds match c_0(1 + 2 beta t) at t = 1/16 to the
  expected order; for example L5a gives 0.5852 against 0.5854.
- **Signatures** are read from the promoted parent table (Sec. 1 and
  Sec. 3.3 of `reports/2026-11-02--dispersion-corrections-across-lattices.md`),
  transcribed into the script, not recomputed.

## 4. Deviation and limits

- **Contract defect.** The contract asked for k* with algebraic coordinates
  on a rational |k| grid, certified "by exact inequality (radicals,
  Sturm)". At rational |k|, e^{ik} is transcendental, so these
  requirements cannot all hold. The explicit witnesses are certified with
  outward-rounded interval arithmetic (mpmath.iv, 40 digits, irrational
  inputs enclosed within ±1e-55). Existence of super-c for every beta row
  also follows from exact signs alone.
- **Search.** Only the declared rays and grid were searched. No row was
  searched beyond them.
- **V_grp^max** remains OPEN for L6e, L6c, L6d and L6f.
- **Signatures** are leading-order and near the node only. Their range of
  validity is OPEN, as in the parent.
- **Scope.** No comparison with observational bounds (contract Sec. 5), no
  value of ell or of the clock frequency, and no claim that our universe
  is a QCA or a simulation.

## 5. What this says about "c is the clock, therefore it cannot be exceeded"

In these models, two statements are independent:

- c being the largest isotropic speed the update allows;
- c being unbeatable.

Some walks at that ceiling still let excitations outrun c (L5a, L5b, L4).
Some walks below it do not show any excitation faster than c on the
declared rays (L6c, L6d, L6f). Only exact saturation of the clock, which
for an isotropic c is possible only in one dimension, comes with no
dispersion at all. An observation that nothing outruns c would therefore
not, by itself, identify c with the clock in this class.

    exprs += [sp.expand(der * dp(dei, j, cs, ss) - dei * dp(der, j, cs, ss)) for j in range(n)]
    args = list(cs) + list(ss)
    fns = [sp.lambdify(args, e, modules=[{"sqrt": iv.sqrt, "mpf": iv.mpf}, "mpmath"]) for e in exprs]
    return fns, n


def branch_speeds_interval(prep, gens, L, div, kvec):
    """Rigorous intervals for |grad eps_+|, |grad eps_-| of a 2x2 unitary block at k.
    Tr U = e^{i phi_d/2} 2 cos(theta): eps_pm = -phi_d/2 -+ theta, |Tr|^2 = 4 cos^2 theta,
    grad theta = -+ grad|Tr|^2 / (2 |Tr| sqrt(4-|Tr|^2)) (sign covered by the two branches),
    grad phi_d = Im(conj(det) grad det) since |det| = 1."""
    fns, n = prep
    dim = len(gens[0])
    Lv = ivnum(L)
    pv = []
    for g in gens:
        acc = iv.mpf(0)
        for m in range(dim):
            acc += ivnum(kvec[m]) * ivnum(g[m])
        pv.append(acc / Lv)
    args = [iv.cos(x) for x in pv] + [iv.sin(x) for x in pv]
    vals = [f(*args) for f in fns]
    T2v, detmod = vals[0], vals[1]
    dT2 = vals[2:2 + n]
    dphi = vals[2 + n:2 + 2 * n]
    a = [-x / 2 for x in dphi]
    bmag = iv.mpf(1) / (2 * iv.sqrt(T2v) * iv.sqrt(4 - T2v))
    b = [x * bmag for x in dT2]
    def kgrad(vec):
        return [sum(vec[j] * ivnum(gens[j][m]) for j in range(n)) / Lv / div for m in range(dim)]
    A, Bv = kgrad(a), kgrad(b)
    plus = iv.sqrt(sum((A[m] + Bv[m]) ** 2 for m in range(dim)))
    minus = iv.sqrt(sum((A[m] - Bv[m]) ** 2 for m in range(dim)))
    return T2v, detmod, plus, minus


def rays(dim, label):
    if dim == 1:
        return {"+x": (1,), "-x": (-1,)}
    if dim == 2:
        if label in ("L2", "L6e"):

    out = {}

def witness_search(label, row):
    L = scale_of(row)
    dim = len(row["gens"][0])
    c0 = row["c0"]
    c0v = ivnum(c0)
    found = None
    for bi, blk in enumerate(row["blocks"]):
        if blk.rows != 2:
            return None, "block not 2x2"
        prep = prepare_block(blk, row["zs"], row["sigma"])
        for rname, n in rays(dim, label).items():
            for t in GRID:
                k = [t * x for x in n]
                T2v, detmod, plus, minus = branch_speeds_interval(prep, row["gens"], L, row["div"], k)
                ok_branch = (T2v.a > 0) and (T2v.b < 4)

                    return found, "found"
    return None, "none on declared rays and grid"

def check_L1(row):

def check_product_form(label, row):
    U = row["blocks"][0]; zs = row["zs"]
    target = sp.prod([(z + 1 / z) for z in zs]) * 2 / 2 ** len(zs)
    ok_tr = zero(U.trace() - target)
    ok_det = zero(U.det() - 1)
    L = scale_of(row)
    exact(f"{label}-trace/2=prod(cos p_j)-and-det=1", ok_tr and ok_det, f"L={L}")
    exact(f"{label}-c0=1/L", zero(row["c0"] - 1 / L), f"c0={row['c0']}, L={L}")
    return ok_tr and ok_det


def check_multilinear(d):
    a = sp.symbols(f"a1:{d + 1}", real=True)
    lhs = sum((1 - a[j]) * sp.prod([a[i] for i in range(d) if i != j]) for j in range(d))
    f = sp.expand(1 - sp.prod(a) - lhs)          # >= 0 on [0,1]^d  <=>  sum_j (dω/dp_j)^2 <= 1
    multilinear = all(sp.degree(f, x) <= 1 for x in a)
    import itertools
    vert = all(f.subs(dict(zip(a, v))) >= 0 for v in itertools.product((0, 1), repeat=d))
    exact(f"multilinear-bound-d={d}: 1 - prod a - sum_j (1-a_j) prod_(i!=j) a_i >= 0 on [0,1]^d (vertices)",
          multilinear and vert, f"f={f}")

## 2. Method (contract Sec. 3)

For each row the symbol is expanded exactly as a Taylor polynomial in `k`
to total degree `N` (`N = 6` in `d <= 2`, `N = 4` in `d = 3`). The node
branch is read from the quadratic factor `lambda^2 - s1 lambda + s2` of
the characteristic polynomial that carries the node:

- `s = 2` rows: the whole characteristic polynomial.
- L5b (`s = 4`): `Gamma = dP_X dP_Y dP_Z` commutes with every Fourier
  coefficient and `Gamma^2 = -I`; its two eigenspaces give two `2x2`
  Weyl blocks.
- L6b: the three `2x2` orientation blocks of `V = U^3`, as in the L6b
  verifier.
- L3s4: Hensel lifting of the quadratic factor at the double root
  `exp(∓ i pi/4)` of `A_a(0) = W`. The characteristic polynomial is
  computed from Newton's identities on truncated power traces; the script
  checks this route against the full characteristic polynomial on the
  `4x4` L5b symbol. The parameter is kept symbolic: `a` and
  `b = sqrt(1-a^2)` are independent symbols reduced with `b^2 = 1 - a^2`.
  This keeps the zero test exact, because `sqrt(1-a^2)` is not a rational
  function of `a`.

From `s1`, `s2`: `exp(-2i phi) = s2 / s2(0)` gives the common phase
`phi(k)` of the two node levels, and `cos^2 omega = s1^2/(4 s2)` gives
`omega^2(k)` as a power series with exact homogeneous parts. Then
`eps_± = eps_0 + phi ± omega`. No series is fitted; every coefficient is
an exact algebraic number or, for L3s4, an exact rational function of
`a`. The Taylor coefficients of `arccos(1-v)^2`, `log(1+v)`, `sqrt(1+v)`
and `1/(1+v)` are checked against SymPy's series.

`G_walk` is the set of point-group elements `g` of the substrate with
`charpoly U(g k) = charpoly U(k)` as Laurent identities. In characteristic
0 this equals equality of `tr U^m`, `m = 1..s`, and `tr U(gk)^m` is
`tr U^m` under the monomial substitution `z^h -> z^(Mh)`. The angular
content is read as a trigonometric polynomial in `d = 2` and projected on
`1, K4, K6` in `d = 3` (and `beta` on `1, n1 n2 n3`). A zero residual is
certified wherever `|G_walk| >= 24`.

## 3. Findings per item

### 3.1 Order of the lowest correction

Every node is untilted at linear order, as the parent certified. The
lowest correction has relative order `t` (a `beta` term) exactly in the
rows whose `G_walk` lacks inversion: L5a, L5b, L4 (`T_d`-type, 24
elements), L6a and L6b (`D_3`), and L3s4. In every row whose `G_walk`
contains `k -> -k` (L1, L2, L6e, L3, L6c, L6d, L6f), `omega^2` has no odd
terms through the computed order and the lowest correction is `alpha`.
The draft charter assumed evenness; the frozen contract required it to be
checked, and six of the thirteen rows are not even.

### 3.2 Angular pattern and the walk's group

The harmonic content matches `G_walk` in every row:

- `D_6` rows (L6c, L6d, L6f): `alpha` isotropic and `cos 6θ` first at
  relative order `t^4`, as the degree argument of contract Sec. 1 forces.
- `D_3` rows (L6a, L6b): `cos 3θ` at relative order `t`. The `cos 6θ` in
  `alpha` comes from `beta^2`; the degree-4 part of `omega^2` is
  isotropic (`Q4 = -1/96` for L6a).
- `D_4` rows (L2, L6e): `cos 4θ` at `t^2`.
- `O_h` row (L3): `K4` at `t^2`.
- 24-element cubic rows: `n1 n2 n3` at `t`, then `1, K4, K6` at `t^2`.

The three ADMP/JDW hexagonal walks with `c_0 = 3/4` have the full `D_6`.
ADMP's L6a has only `D_3`, and so has L6b, which realises L6a's dispersion
after three updates.

### 3.3 Sign

- `alpha <= 0` pointwise in L2, L6e, L3, L5a, L5b, L4 (closed forms in
  Sec. 1), vanishing only along the coordinate axes. `alpha < 0` pointwise
  in L6a, L6b (`-46/1728 <= alpha <= -36/1728` for L6a), L6c, L6d, L6f.
- In L5a, L5b, L4, L6a and L6b, `beta` is odd under `n̂ -> -n̂`, so the
  lowest correction takes both signs. These rows are not "subluminal at
  short wavelength" in every direction even though `alpha_0 < 0`. The
  phase speed of the upper branch exceeds `c_0` near the node where
  `beta(n̂) > 0`, for example along `n1 n2 n3 > 0` in L5a.
- In L3s4, `beta = beta_0 + beta_3 n1 n2 n3` with `beta_0 != 0`, so it is
  not odd. Since `|n1 n2 n3| <= 1/(3 sqrt3)`, `beta` keeps the sign of
  `beta_0` on the whole sphere iff `a^2 < (19 - 6 sqrt3)/11`, and takes
  both signs above that threshold. The sign of `beta_0` depends on the
  cluster and reverses between the upper and lower branch (Sec. 3.4).
  The verifier checks the threshold exactly.
- L3s4: `alpha_0` changes sign at `a*` (Sec. 1).

### 3.4 L3s4: a branch-dependent quadratic term

L3s4 is the only row with `phi != 0`. The two levels of each cluster move
together as `phi = ±(1 - a^2) t^2 / 6 + O(t^4)`, with opposite signs for
the clusters at `±pi/4`. This is consistent with second-order repulsion
between the clusters through the intersector coupling `b^2 = 1 - a^2`. It
gives `beta` an isotropic part `±sqrt3 (1-a^2)/(6a)` of opposite sign on
the upper and lower branch of a cluster; `alpha` is the same for both
branches and both clusters. `G_walk` has 8 elements, so `alpha` has
content outside `span(1, K4, K6)`. The verifier prints it; it is not
tabulated further here. At `a = 1` the isotropic part of `beta` vanishes,
and `beta = (sqrt3/3) n1 n2 n3` with `alpha_0 = -4/315`, the values of
L5a.

### 3.5 Group velocity at the node

`|grad eps_+| / c_0 = 1 + 2 beta(n̂) t + O(t^2)`, and `1 + 3 alpha(n̂) t^2
+ O(t^4)` where `beta = 0`. The coefficients through relative order `t^4`
(`d <= 2`) or `t^2` (`d = 3`) are printed per row by the verifier.
`V_grp^max` is `OPEN` for every row in `d >= 2`, as in the parent. For L1,
`omega = |k|` on the whole branch, so its group speed is 1 everywhere;
this follows from the symbol `exp(-i k sigma_z)` and is checked by the
script only through `t^5`.

### 3.6 Scale of validity

L1: the branches meet first at `|k| = pi` (exact). `d >= 2`: `OPEN`. The
exact minimisation of `|k|` on the branch-meeting set was not attempted,
as contract Sec. 3 item 6 allows.

## 4. Cross-checks and second route

- **L1** reproduces the exactly linear 1D massless walk: all corrections
  vanish through `t^5`.
- **Closed forms by hand.** For a symbol with `cos omega = prod_i cos p_i`
  and `p = k / sqrt d`, the expansion `log cos x = -x^2/2 - x^4/12 +
  O(x^6)` gives `omega^2 = |p|^2 - (1/3) sum_{i<j} p_i^2 p_j^2 + O(p^6)`,

  verifier asserts all three forms against its series output.
- **L6b vs L6a.** With each row's normalisation,

  `c_0` scales by `2/3`, `beta` by 2 and `alpha` by 4. All three are

  why `beta` changes sign between the two rows. The three orientation

- **L6c, L6d, L6f:** compared in Sec. 1.
- **L5b:** both Weyl blocks give the same `alpha` and opposite `beta`.

# THREE_VELOCITIES

## Purpose

This note fixes the vocabulary for propagation speeds in the project.

## 1. Microscopic causal geometry

For a finite one-step displacement set `N`, define

`C_micro = conv(N)`.

This is the primary causal object in more than one spatial dimension. It records which average velocities are geometrically compatible with repeated local moves.

For direction `n̂`, the support function is

`h_C(n̂) = sup_{v in C_micro} n̂·v`.

The directional causal speed is proportional to `h_C(n̂)` after restoring lattice/time units.

Two scalar summaries are useful but secondary:

- inradius: `r_in = min h_C`;
- maximal directional support: `V_causal^max = max h_C`.

## 2. Spectral group velocity

Let the Bloch unitary have eigenvalues

`exp[-i ω_s(k) Δt]`.

The group velocity of branch `s` is

`v_s(k) = ∇_k ω_s(k)`.

Define

`V_grp^max = sup_{s,k} ||v_s(k)||`.

This quantity belongs to the spectrum of a specific QCA. It is not identical by definition to the geometric boundary of `C_micro`.

## 3. Relativistic IR speed

`c_IR` belongs to the low-energy effective theory.

For a gapless node with isotropic linear dispersion,

`ω(k) = c_IR |k| + higher orders`,

so `c_IR` is the low-energy slope.

For a massive relativistic EFT,

`H_eff(k) = M β + c_IR α·k + ...`,

or, in the exact continuum relativistic form,

`ω^2 = M^2 + c_IR^2 |k|^2`.

On a finite lattice, higher-order Hamiltonian terms can contribute to the `|k|^2` coefficient of `ω^2`, so the two extraction procedures must be checked rather than assumed equivalent.

The completed standard Dirac gate establishes a strict difference for
`0 < m < 1`: with `F = arcsin(m) sqrt(1-m^2)/m`,
`c_H = r_in F < c_{ω^2} = r_in sqrt(F) < r_in`.
The quadratic mass-direction correction satisfies
`c_H^2 + 2 M b = c_{ω^2}^2`, where `M = arcsin(m)` and
`b = r_in^2 sqrt(1-m^2)(1-F)/(2m)`.

Thus an unspecified finite-lattice `c_IR` is ambiguous between these
extractions. Their common massless/continuum limit is verified for the standard
family; see the [canonical state](../state/CURRENT_STATE.md) for the claim ceiling.

## 4. Safe inequalities and unsafe identifications

The robust locality statement is that spectral propagation cannot outrun the microscopic causal geometry. In one dimension this reduces to a scalar Bernstein-type bound.

Unsafe universal identifications include:

`c_IR = V_grp^max`,

`V_grp^max = V_causal^max`,

and therefore

`c_IR = V_causal^max`.

Each equality requires an independent mechanism or proof.

## 5. Current geometric candidate

If the IR cone is isotropic and must fit inside `C_micro`, then

`c_IR <= r_in(C_micro)`.

The strongest isotropic cone compatible with the *one-step* microscopic causal body has radius exactly `r_in`.

**Correction (2026-09-14):** `r_in(C_micro)` is only an upper bound, and it
bounds the one-step body, not the propagation actually achievable after
repeated time steps. The object that should be compared against `c_IR` is the
*strict asymptotic* isotropic speed `c_strict^iso = min h_infty`, defined from
the actual long-run Fourier support in
[`CAUSAL_BODY_GEOMETRY.md`](CAUSAL_BODY_GEOMETRY.md) Sec. 6, which satisfies
`c_strict^iso <= r_in(C_micro)` in general and need not be an "inradius" at
all (a pure shift gives a negative value). The live hypothesis is therefore

`B_infty^*: c_0 = c_strict^iso`,

not the old `c_IR = r_in(C_micro)`. The standard Pavia Weyl family in d=3 is
the one baseline where the two targets are certified to coincide exactly
