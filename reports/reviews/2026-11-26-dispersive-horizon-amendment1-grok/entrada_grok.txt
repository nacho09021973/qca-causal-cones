\]
por lo que
\[
e^{-i\beta\sigma_y}
=I\cos\beta-i\sigma_y\sin\beta
=\begin{pmatrix}\cos\beta&-\sin\beta\\
\sin\beta&\cos\beta\end{pmatrix}.
\]

Los operadores actúan de derecha a izquierda. En consecuencia, las seis monedas de \(W^2\), en orden de aplicación, son
\[
(-2\theta,\theta,\theta,-2\theta,\theta,\theta).
\]
Esto sigue siendo cierto para un perfil variable: cada moneda se evalúa en el sitio ocupado durante esa etapa.

En coordenadas,
\[
(Sq)_\uparrow(x)=a(x-1),\qquad
(Sq)_\downarrow(x)=b(x+1).
\]

\[
(L_-q_7)(x)=q_7(x+1),
\]
la ecuación estacionaria es exactamente
\[
\boxed{q_7(x+1)=zq_1(x)}.
\]

\[

### 2. Derivación de la matriz y equivalencia — PASS

Escribo \(c_j=\cos\beta_j(x)\), \(s_j=\sin\beta_j(x)\). Aplicar primero la moneda en \(x\) y después el desplazamiento da

\]
\[
b_{j+1}(x-1)=s_ja_j(x)+c_jb_j(x). \tag{2}
\]

Para \(j=1,\ldots,5\), despejar (2) y sustituir en (1) produce
\[
b_j(x)=\frac{b_{j+1}(x-1)-s_ja_j(x)}{c_j},
\]
\[
a_{j+1}(x+1)=\frac{a_j(x)-s_jb_{j+1}(x-1)}{c_j}.
\]
Aquí se ha usado \(c_j^2+s_j^2=1\).

El cierre superior en \(x\) es
\[
za_1(x)=c_6(x)a_6(x)-s_6(x)b_6(x),

y, por tanto,
\[
\boxed{b_6(x)=\frac{c_6(x)a_6(x)-za_1(x)}{s_6(x)}}.
\]

Para el otro cierre hay que usar la moneda en \(x+1\). Escribiendo \(c_+=c_6(x+1)\), \(s_+=s_6(x+1)\),
\[
za_1(x+1)=c_+a_6(x+1)-s_+b_6(x+1),
\]
\[
zb_1(x-1)=s_+a_6(x+1)+c_+b_6(x+1).
\]
Multiplicar la primera por \(c_+\), la segunda por \(s_+\) y sumar elimina \(b_6(x+1)\):
\[
\boxed{a_1(x+1)=
\frac{a_6(x+1)/z-s_+b_1(x-1)}{c_+}}.
\]
Los coeficientes en \(x+1\) son necesarios.

Para explicitar las doce filas, sean
\[
u_j=a_j(x),\quad v_j=b_j(x-1),\qquad
u'_j=a_j(x+1),\quad v'_j=b_j(x).

\[
u'_1=\frac{u_5}{zc_+c_5}
-\frac{s_+}{c_+}v_1-\frac{s_5}{zc_+c_5}v_6,

\[
u'_{j+1}=\frac{u_j}{c_j}-\frac{s_j}{c_j}v_{j+1}
\quad(j=1,\ldots,5),
\]
\[
v'_j=-\frac{s_j}{c_j}u_j+\frac{v_{j+1}}{c_j}
\quad(j=1,\ldots,5),
\]

\[
P=\sum_{j=1}^5\frac{E_{j+1,j}}{c_j}
+\frac{E_{1,5}}{zc_+c_5},

La comparación por posiciones verifica las **144 entradas de (A) §6**: 25 entradas estructuralmente no nulas y 119 ceros.

**Equivalencia, incluida la ausencia de soluciones espurias.** Supónganse no nulos los denominadores y \(z\).

La dirección \(U\psi=z\psi\Rightarrow Y_{x+1}=M_xY_x\) resulta de los despejes anteriores.

Recíprocamente, dada una órbita de la recurrencia en toda \(\mathbb Z\), defínanse

\]
En \(x+1\), la misma fila y la fila de \(a_1(x+1)\) dan

\end{aligned}
\]
Esto es el cierre inferior en todos los sitios. Por tanto,

\boxed{Y_{x+1}=M_xY_x\iff U\psi=z\psi}

para soluciones formales en \(\mathbb Z\).

### 3. Determinante — PASS

Las cinco transformaciones de pares
\[

\]
tienen matriz

y determinante \(1\).

No aparecen factores de \(z\), ni factores de las primeras cinco monedas. Es una identidad para perfiles variables. En el perfil considerado es positiva; en el caso homogéneo vale \(1\).

### 4. Dispersión, multiplicidades y degeneraciones — PASS para (A); reparación en (B)

C(b) = exp(-i b sigma_y), S|x,up> = |x+1,up>, S|x,dn> = |x-1,dn>,
L_-|x,s> = |x-1,s>; each coin acts with the coin angle of the site where the
excitation sits at that stage.

Exact SymPy only (no floating point, no fitted tolerances). Fails closed: any
failed check raises and the process exits nonzero. Groups:

  T1  conventions: C(b) = exp(-i b sigma_y); coin order read off W's word
  T2  independent elimination of the raw stage + closure equations (general
      independent angles, reduced modulo c^2+s^2=1) vs the report's blocks
      P, Q, R, H, entry by entry (144 entries); uniqueness of the solution;
      consistency of the auxiliary unknown b_6(x+1) with row 12 of M_{x+1};
      two negative controls (sign flip; closure coefficients at x not x+1)
  T3  second route: iterate the report's M with site-dependent rational coins,
      rebuild psi, apply U from its definition, check U psi = z psi exactly
  T4  det M_x = cot beta_6(x) / cot beta_6(x+1), general angles, z-free
  T5  homogeneous symbol: tr W / 2 = A cos 3k + (1-A) cos k, det W = 1,

      symbolic theta and at three rational points

      W(pi/2)^2 = -I, two explicit independent eigenvectors of M,

  T7  microscopic support [-7, 5] with nonzero extreme coefficients

What it does NOT certify: see scripts/README.md.

def zero(label, value):
    entries = list(value) if isinstance(value, sp.MatrixBase) else [value]
    def z0(x):
        x = sp.expand(x)
        return sp.simplify(x) == 0 or sp.simplify(sp.expand(x.rewrite(sp.exp))) == 0
    ok(label, all(z0(x) for x in entries))


XMP = sp.symbols('X_minpoly')


def nonzero_alg(x):
    """Exact nonzero test for an algebraic number: minimal polynomial is not X."""
    return sp.minimal_polynomial(sp.expand(x), XMP) != XMP


def E(i, j):
    m = zeros(6, 6)
    m[i - 1, j - 1] = 1
    return m


def M_report(c, s, cp, sp_, z):
    """Blocks P, Q, R, H transcribed verbatim from report Sec. 6.
    c[j], s[j] (j = 1..6) at site x; cp, sp_ = c_6, s_6 at site x+1."""
    P = sum((E(j + 1, j) / c[j] for j in range(1, 6)), zeros(6, 6)) \
        + E(1, 5) / (z * cp * c[5])
    Q = -sum((s[j] / c[j] * E(j + 1, j + 1) for j in range(1, 6)), zeros(6, 6)) \
        - sp_ / cp * E(1, 1) - s[5] / (z * cp * c[5]) * E(1, 6)
    Rb = -sum((s[j] / c[j] * E(j, j) for j in range(1, 6)), zeros(6, 6)) \
        - z / s[6] * E(6, 1) + c[6] / s[6] * E(6, 6)
    H = sum((E(j, j + 1) / c[j] for j in range(1, 6)), zeros(6, 6))
    return Matrix(sp.BlockMatrix([[P, Q], [Rb, H]]))

def coin(b):
    return Matrix([[cos(b), -sin(b)], [sin(b), cos(b)]])

def is_zero_on_circle(expr):
    num, _ = sp.fraction(sp.cancel(sp.together(expr)))
    num = sp.expand(num)
    for sv, cv in CIRCLE:
        num = sp.rem(num, sv**2 + cv**2 - 1, sv)
    return sp.expand(num) == 0

def coin_cs(m, x):
    """cos, sin of m*theta_x for m in {1, -2} with rational cos/sin theta."""
    p, q = site[x]
    if m == 1:
        return p, q
    if m == -2:
        return p * p - q * q, -2 * p * q
    raise ValueError(m)


def apply_word(word, psi):
    """Apply a word of 'S', ('C', m), 'L' (right to left) to psi: {x: (up, dn)}.
    Sites whose value is not determined by the window are dropped."""
    for f in reversed(word):
        new = {}
        if f == 'S':
            for x in psi:
                if x - 1 in psi and x + 1 in psi:
                    new[x] = (psi[x - 1][0], psi[x + 1][1])
        elif f == 'L':
            for x in psi:
                if x + 1 in psi:
                    new[x] = psi[x + 1]
        else:
            for x, (up_, dn_) in psi.items():
                cc, ss = coin_cs(f[1], x)
                new[x] = (cc * up_ - ss * dn_, ss * up_ + cc * dn_)
        psi = new
    return psi

def boxed(AA):
    fl = AA / 2 * (lam**3 + lam**-3) + (1 - AA) / 2 * (lam + 1 / lam)
    return sp.expand(z**2 * lam**5 - z * lam**6 * (4 * fl**2 - 2) + lam**7)
