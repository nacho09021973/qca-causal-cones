## Decisión resultante

1. Para W9–W11, la comparación prioritaria es documental entre F8/F9/F11/F19/F20 y los claims de fuente, corriente, constraint y gauge. No se abre cálculo.
2. Para el sucesor elástico, la comparación prioritaria es F1–F4 con F13–F17; el objetivo es separar embedding, hopping y simetría Weyl. No se modifica el contrato.
3. F7/F10 quedan como arquitecturas de posible geometría dinámica, pero siguen sin regla CJWW completa; no son candidatos ejecutables.

## Prohibiciones conservadas

- No usar F8–F20 para promocionar W9, W10 o W11.
- No usar F12–F17 como prueba de universalidad métrica entre las cuatro especies.
- No usar F19/F20 como evidencia de una implementación QCA de gravedad.
- No reabrir W12 por analogía con F2, F14, F15 o F16.

## Resultado

El atlas ya se usa como filtro de claim ceiling y selección de comparadores.
El siguiente paso admisible, si se autoriza, es una auditoría documental de
una sola fila; no una ejecución física global.
