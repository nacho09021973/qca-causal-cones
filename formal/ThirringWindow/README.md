# Conditional window transfer

Run from formal/: `lake env lean ThirringWindow/Transfer.lean`.
Uses the existing pinned Mathlib/toolchain; no dependencies changed.

transfer_bound proves that an isometric evolution transfers an initial
comparison error and a final comparison error with their sum. All arguments
and hypotheses appear in its statement. It does not assume its conclusion.
No sorry or own axioms. build.txt records the successful axiom check.
failed-build-1.txt retains a corrected triangle-inequality API mistake;
its sorryAx was generated by the failed elaboration, not a valid certificate.
