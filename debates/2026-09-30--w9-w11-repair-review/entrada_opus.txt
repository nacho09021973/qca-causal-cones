"""W9 repaired algebraic gauge-variation check (2026-09-30, D1).

Explicit symmetric h,T and gauge parameter xi; Fourier integration by parts.
No division by a momentum component, no derivation of Weyl stress conservation,
no local-Lorentz Ward identity, and no microscopic W6 source matching.
"""

import sympy as sp


def symmetric(name):
    entries = {(i, j): sp.Symbol(f'{name}{i}{j}')
               for i in range(4) for j in range(i, 4)}
    return sp.Matrix(4, 4, lambda i, j: entries[min(i, j), max(i, j)])


def main():
    lam, eps = sp.symbols('lambda epsilon')
    k = sp.Matrix(sp.symbols('k0:4'))
    xi = sp.Matrix(sp.symbols('xi0:4'))
    h, T = symmetric('h'), symmetric('T')
    delta_h = sp.I * (k * xi.T + xi * k.T)

    def coupling(metric):
        return lam * sum(metric[i, j] * T[i, j]
                         for i in range(4) for j in range(4)) / 2

    variation = sp.expand(sp.diff(coupling(h + eps * delta_h), eps))
    divergence = T * k
    assert sp.expand(variation - sp.I * lam * xi.dot(divergence)) == 0
    # h and xi carry k, T carries -k. The derivative on T is therefore -i k.
    after_ibp = -lam * xi.dot(-sp.I * divergence)
    assert sp.expand(variation - after_ibp) == 0
    print('[PASS] symmetric h,T: factor 1/2 cancels; Fourier integration by parts checked')

    spatial = lam * sum(delta_h[i, j] * T[i, j]
                        for i in range(1, 4) for j in range(1, 4)) / 2
    split = sp.I * lam * sum(xi[j] * (divergence[j] - k[0] * T[0, j])
                            for j in range(1, 4))
    assert sp.expand(spatial - split) == 0
    residual = -sp.I * lam * k[0] * sum(xi[j] * T[0, j] for j in range(1, 4))
    assert residual.subs(k[0], 0) == 0
    print('[PASS] spatial variation = conserved-shell temporal residual; static residual gauge passes')
    print('VERDICT: algebraic on-shell O(lambda) consistency only; conservation and microscopic matching are inputs.')


if __name__ == '__main__':
    main()

import sympy as sp


def main():
    eta = sp.diag(-1, 1, 1, 1)
    d = sp.Matrix(sp.symbols('d0:4'))
    dup = eta * d
    hs = {(i, j): sp.Symbol(f'h{i}{j}') for i in range(4) for j in range(i, 4)}
    h = sp.Matrix(4, 4, lambda i, j: hs[min(i, j), max(i, j)])

    xi = sp.Matrix(sp.symbols('xi0:4'))

    # Two derivatives make the formal adjoint even under d -> -d. Differentiating

    L += lam * sum(h[i, j] * T[i, j] for i in range(4) for j in range(4)) / 2
    for (i, j), field in hs.items():

        assert sp.expand(sp.diff(L, field) - weight * (-Gup[i, j] + lam * T[i, j] / 2)) == 0
    print('[PASS] all ten variations: G^mu nu=lambda*T^mu nu/2; lapse/shift factors fixed')

    spatial_trace = sum(h[i, i] for i in range(1, 4))
    lap = sum(d[i]**2 for i in range(1, 4))

Since \(\det W=1\), a degeneracy is \(W=\pm I\). The condition
\(|a_0|=1\) forces every \(|c_i|=1\): the following eight nodes exhaust the
Brillouin torus (coordinates understood modulo \(2\pi\)). Define the frame by

\[
W(p_*+k)=s_*[(1-|k|^2/2)I+i\sigma^a E_{*a}{}^i k_i+O(|k|^3)],\qquad
H_*(k)=i\log[s_*W(p_*+k)]=-\sigma^a E_{*a}{}^ik_i+O(|k|^3).
\]

The Pauli-vector part has no quadratic term. The table uses the normalized
frame of \(s_*W\), including at the π nodes.

| \(p_*/\pi\) | \(s_*\) | \(\operatorname{diag}E_*\) | \(\det E_*\) | Hamiltonian chirality \(\operatorname{sgn}\det(-E_*)\) |
| --- | --- | --- | --- | --- |
| (0,0,0) | +1 | (1,−1,1) | −1 | +1 |

The review's signs −,+,−,+ refer to \(\det E_*\); with the Hamiltonian

have zero net chirality in the four zero-quasienergy species. F1 in §1

**Selected option A1(i): retain all four zero-quasienergy species.** Any
subsequent continuum coupling must use their sum
\(T^{\mu\nu}_{\mathrm{tot}}=\sum_{s_*=+1}T_*^{\mu\nu}\), each with its own
frame, and one common geometry/coupling. This is a required contract, not a
constructed microscopic coupling or a proof of universal coupling. A
single-species truncation is not licensed. The π sector remains explicitly
outside this low-quasienergy contract; its exclusion under coupled dynamics
and all species-dependent source kernels must be checked before a joint PASS.
No suppression of intervalley scattering is inferred from this node table.

### A2 — replace the energy surrogate by K

For the **one-particle free walk** \(U\), set

\[
K=\frac{i}{2}(U-U^\dagger),\qquad K(p)=-\boldsymbol a(p)\cdot\boldsymbol\sigma.
\]

This is Hermitian and exactly conserved: \([K,U]=0\). If
\((U\psi)_x=\sum_r A_r\psi_{x+r}\), then
\(B_r=i(A_r-A_{-r}^\dagger)/2\) are the hopping matrices of K and
\(B_{-r}=B_r^\dagger\). One local Hermitian density is

\[
\varepsilon_x^K=\frac12\sum_r
[\psi_x^\dagger B_r\psi_{x+r}+\psi_{x+r}^\dagger B_r^\dagger\psi_x],
\qquad \sum_x\varepsilon_x^K=\langle\psi,K\psi\rangle.
\]

It has the spatial range of the walk (at most one site per coordinate).
For a freely second-quantized walk the corresponding conserved bilinear is
\(d\Gamma(K)\); taking \(i(\Gamma(U)-\Gamma(U)^\dagger)/2\) instead is not
this local bilinear. No interacting QCA claim is made.

On the union of the four balls \(|k|\le\Lambda\le1/2\) around \(+I\) nodes,
let \(P_\Lambda\) be the band projector. Here \(\cos\theta=\prod_i\cos k_i>0\),
\(\sin^2\theta=1-\prod_i(1-\sin^2k_i)\le|k|^2\), hence
\(0\le\theta\le\arcsin\Lambda\). Spectral calculus gives
\(K=\sin H_{\rm eff}\) on this branch, so

\[
\|(K-H_{\rm eff})P_\Lambda\|
\le\frac{(\arcsin\Lambda)^3}{6},\qquad
\|(U^n-e^{-inK})P_\Lambda\|
\le |n|\frac{(\arcsin\Lambda)^3}{6}.
\]

The second estimate follows by telescoping/Duhamel for the two unitary
propagators. It is useful for \(|n|\Lambda^3\ll1\), and uses invariance of
\(P_\Lambda\) under the free walk. The projector is a restriction on states,
not a claim of finite-range band selection.

K still vanishes at **all eight nodes**. It is not the all-zone quasienergy,
not a positive energy, and not a continuous-time generator of U. Its exact
free conservation does not prove conservation after a geometry coupling.
The construction is established here algebraically; no checked primary
literature attribution for this particular energy surrogate is claimed.

The old \(H_{\rm IR}\) in §2 is superseded. Its commutator with W has a
nonzero quartic term. Near p=0 its mismatch with \(H_{\rm eff}\) is cubic,
not merely the loose quadratic bound quoted there. In fact
\(\|K-H_{\rm IR}\|\le\Lambda^3\) on the p=0 ball, from
\(|1-\cos u|\le u^2/2\), so its free dynamical error is bounded by
\(|n|[\Lambda^3+(\arcsin\Lambda)^3/6]\). On the p3 axis both surrogates
are \(-\sin p_3\sigma_3\), while \(H_{\rm eff}=-p_3\sigma_3\); the cubic
coefficient is \(1/6\). This also rejects the review's incorrect universal
cubic formula for \(H_{\rm eff}\) (repair B4).

### A3 / F2 — explicit downgrade of the local-stress claim

F2 now certifies K as an energy **charge** surrogate on the stated band,
the integrated canonical momentum near p=0, and the q=0 spatial
**tetrad-conjugate** structures from W5/W6. It does not certify all local
components of a symmetric Belinfante tensor. No longitudinal Ward identity
is inferred merely from the integrated charges. At another node,
\(\sin(p_{*i}+k_i)=(-1)^{p_{*i}/\pi}k_i+O(k_i^3)\); the original momentum
surrogate is therefore not one common envelope-momentum operator for all
four species without further matching.

The kernels at nonzero momentum transfer, spin improvement, frame
symmetrization and full four-species local source construction remain open.
This chooses the explicit downgrade permitted by A3. It supersedes the
claim in §§3,6 that all three local source types needed by W10 were supplied.

### C3 / F3 — obstruction for a continuous translation-invariant logarithm

For this particular two-component walk, suppose a periodic continuous
Hermitian \(H(p)\) on the connected Brillouin torus obeyed
\(e^{-iH(p)}=W(p)\). Then \(\operatorname{tr}H(p)\in2\pi\mathbb Z\) is
constant, since \(\det W=1\). Also \([H,W]=0\). Approaching any Weyl node
along k=tn and dividing that commutator by t gives
\([H(p_*),\sigma^aE_{*a}{}^in_i]=0\) for every n. The frames in the table
are invertible, so \(H(p_*)=c_*I\). At a +I node this requires
\(c_*\in2\pi\mathbb Z\), hence an even multiple of \(2\pi\) for the
trace. At a −I node it requires \(c_*\in(2\mathbb Z+1)\pi\), hence an odd
multiple. This contradicts constant trace.

Thus no such continuous logarithm exists, in particular none with
absolutely summable translation-invariant hopping matrices (which would
have a continuous symbol). This includes finite range. This proof uses
both kinds of nondegenerate Weyl node; it is not a no-go for all QCA, for
translation-breaking generators, or for time-dependent local circuits.
It is an author-side proof, not an independently reviewed promotion. Po et
al.'s chiral-edge result is not used as evidence for it.

### C3 / F4 and primary antecedent

The bond operator in §3 has total symbol \(\sin p_i I\), so its integrated
charge is **exactly conserved** by the free walk. The missing step in F4 is
a constructed local one-step current and its relation to the symmetric
stress, not global conservation. Both that current and the q≠0 Belinfante
identification remain open in this certificate.

Arnault–Cedzich, `biblioteca/arXiv-2208.14997.pdf` pp.1–2, construct a
(1+1)D single-particle discrete-time action and a lattice Noether theorem
for **internal** symmetries, including a U(1) charge current. These pages
were re-read for this addendum. This is a relevant antecedent; it is not a
result about gravitational energy-momentum or the CJWW stress tensor.

"""W11 A1/A2 repair certificate (2026-09-30).

Run: python3 scripts/verify_w11_ir_stress_source.py
Original first-order checker: git show 97592a4:scripts/verify_w11_ir_stress_source.py
Uses the original CJWW (5.15) symbol, extracts its real-space hopping matrices,
and checks conservation both in Bloch space and by real-space convolution.
Scope: free walk, integrated charges, all eight nodes; no q != 0 Belinfante
stress kernel, interacting constraint identity, or Floquet logarithm no-go.
"""

from itertools import product

import sympy as sp

from verify_directional_saturation import PAULI, P1, P2, P3, Z, laurent, walk2

PS = (P1, P2, P3)
I2 = sp.eye(2)
ZERO = sp.zeros(2)


def equal(left, right):
    assert all(sp.simplify(laurent(e)) == 0 for e in left - right)


def hopping(symbol):
    """symbol = sum_r A_r exp(i p.r); (A psi)_x = sum_r A_r psi_(x+r)."""
    out = {}
    for row in range(2):
        for col in range(2):
            poly = sp.Poly(sp.expand(laurent(symbol[row, col]) * sp.prod(Z)), *Z)
            for mono, coeff in poly.terms():
                if coeff != 0:
                    r = tuple(int(m) - 1 for m in mono)
                    out.setdefault(r, sp.zeros(2))[row, col] = coeff
    return out


def adjoint(hops):
    return {tuple(-x for x in r): a.H for r, a in hops.items()}


def convolution(left, right):
    out = {}
    for r, a in left.items():
        for s, b in right.items():
            rs = tuple(x + y for x, y in zip(r, s))
            out[rs] = out.get(rs, ZERO) + a * b
    return {r: a.applyfunc(sp.simplify) for r, a in out.items() if a != ZERO}


def equal_hops(left, right):
    for r in left.keys() | right.keys():
        assert (left.get(r, ZERO) - right.get(r, ZERO)).applyfunc(sp.simplify) == ZERO


def symbol(hops):
    return sum((a * sp.exp(sp.I * sum(p * x for p, x in zip(PS, r)))
                for r, a in hops.items()), sp.zeros(2))


def sig(v):
    return sum((x * s for x, s in zip(v, PAULI)), sp.zeros(2))


def main():
    W = walk2()
    equal(W.H * W, I2)
    assert sp.simplify(W.det()) == 1
    # Exact SU(2) decomposition, derived independently from the matrix entries.
    a0 = sp.prod(sp.cos(p) for p in PS)
    a = sp.Matrix([sp.sin(P1), -sp.cos(P1) * sp.sin(P2),
                   sp.cos(P1) * sp.cos(P2) * sp.sin(P3)])
    equal(W, a0 * I2 + sp.I * sig(a))
    assert sp.trigsimp(a.dot(a) + a0**2 - 1) == 0

    U = hopping(W)
    Ud = adjoint(U)
    Khops = {r: sp.I * (U.get(r, ZERO) - Ud.get(r, ZERO)) / 2
             for r in U.keys() | Ud.keys()}
    K = symbol(Khops)
    equal(K, sp.I * (W - W.H) / 2)
    equal(K, -sig(a))
    equal(K.H, K)
    equal(K * W, W * K)
    equal_hops(Khops, adjoint(Khops))
    equal_hops(convolution(Ud, U), {(0, 0, 0): I2})
    equal_hops(convolution(convolution(Ud, Khops), U), Khops)
    assert len(U) == 14
    assert max(max(abs(x) for x in r) for r in Khops) == 1
    print('[PASS] K built from the 14 CJWW hoppings: Hermitian, range <= 1 per coordinate', flush=True)
    print('[PASS] [K,W]=0 and U^dag K U=K, also by real-space convolution', flush=True)

    # W(p_star+k)=s[I+i sigma.E k+O(k^2)]; H_shift=-sigma.E k+...
    print('node/pi | W sign | diag(E), normalized by W sign | det(E) | chirality(H_shift)')
    plus_chiralities = []
    for bits in product((0, 1), repeat=3):
        at = dict(zip(PS, (b * sp.pi for b in bits)))
        signs = [(-1)**b for b in bits]
        s = sp.prod(signs)
        equal(W.subs(at), s * I2)
        E = sp.diag(signs[1] * signs[2], -signs[2], 1)
        shifted = {p: p + b * sp.pi for p, b in zip(PS, bits)}
        # Exact recentering, not just node derivatives: all +I neighborhoods
        # share the scalar dispersion and odd vector Taylor order.
        equal(s * W.subs(shifted, simultaneous=True),
              a0 * I2 + sp.I * sig(E * sp.diag(1, -1, 1) * a))
        for i, p in enumerate(PS):
            equal(sp.diff(W, p).subs(at), s * sp.I * sig(E[:, i]))
            equal(sp.diff(K, p).subs(at), -s * sig(E[:, i]))
        equal(K.subs(at), ZERO)
        chirality = (-E).det()
        if s == 1:
            plus_chiralities.append(chirality)
        print(f'{bits} | {int(s):+} | {tuple(E.diagonal())} | {int(E.det()):+} | {int(chirality):+}', flush=True)
    assert sorted(plus_chiralities) == [-1, -1, 1, 1]
    print('[PASS] four zero-quasienergy species, net chirality zero; four pi nodes', flush=True)
    # Completeness: W=+-I implies |a0|=1. Each |cos p_i|<=1, so all p_i=0 or pi.

    # Build the OLD H_IR and pi_i from their real-space bond coefficients.
    E0 = sp.diag(1, -1, 1)
    old_hops = {}
    for i in range(3):
        e = tuple(int(j == i) for j in range(3))
        minus_e = tuple(-x for x in e)
        M = sig(E0[:, i])
        old_hops[e], old_hops[minus_e] = sp.I * M / 2, -sp.I * M / 2
        pi_hops = {e: -sp.I * I2 / 2, minus_e: sp.I * I2 / 2}
        Pi = symbol(pi_hops)
        equal(Pi, sp.sin(PS[i]) * I2)
        equal_hops(convolution(convolution(Ud, pi_hops), U), pi_hops)
    Hir = symbol(old_hops)
    equal(Hir, -sig(E0 * sp.Matrix([sp.sin(p) for p in PS])))
    print('[PASS] old bond pi_i has exactly conserved integrated charge (not a Belinfante kernel)', flush=True)

    t = sp.symbols('t', real=True)
    v = sp.Matrix(sp.symbols('v1 v2 v3', real=True))
    ray = dict(zip(PS, t * v))

    def jet(expr, order):
        return sp.expand(sp.series(expr.subs(ray), t, 0, order).removeO())

    # H_eff=-(asin(|a|)/|a|)a.sigma near +I; ratio=1+|a|^2/6+O(|a|^4).
    K3 = (-a).applyfunc(lambda e: jet(e, 4))
    Heff3 = (-(1 + a.dot(a) / 6) * a).applyfunc(lambda e: jet(e, 4))
    Hir3 = (-E0 * sp.Matrix([sp.sin(p) for p in PS])).applyfunc(lambda e: jet(e, 4))
    for e in Heff3 - Hir3:
        assert e.coeff(t, 0) == e.coeff(t, 1) == e.coeff(t, 2) == 0
    expected = E0 * v * v.dot(v) * t**3 / 6
    assert (K3 - Heff3 - expected).applyfunc(sp.simplify) == sp.zeros(3, 1)
    comm4 = (Hir * W - W * Hir).applyfunc(lambda e: jet(e, 5))
    assert all(e.coeff(t, n) == 0 for e in comm4 for n in range(4))
    assert any(e.coeff(t, 4).subs(dict(zip(v, (1, 2, 3)))) != 0 for e in comm4)
    print('[PASS] arbitrary-direction jets: K-H_eff=O(|p|^3); old H_IR commutator has nonzero quartic term', flush=True)

    # Independent exact axis witness: W=exp(i p3 sigma3), H_eff=-p3 sigma3.
    equal(W.subs({P1: 0, P2: 0}), sp.diag(sp.exp(sp.I * P3), sp.exp(-sp.I * P3)))
    equal(K.subs({P1: 0, P2: 0}), -sp.sin(P3) * PAULI[2])
    assert sp.limit((P3 - sp.sin(P3)) / P3**3, P3, 0) == sp.Rational(1, 6)
    print('[PASS] exact p3-axis check: cubic energy error coefficient 1/6')
    print('VERDICT: A1/A2 checks pass for free integrated charges; full local stress and coupled gate OPEN.')


if __name__ == '__main__':
    main()
