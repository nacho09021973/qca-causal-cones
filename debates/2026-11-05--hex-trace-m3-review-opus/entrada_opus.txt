from fractions import Fraction as F
import json

import sympy as s


def multiply(z, w):
    return (z[0]*w[0]-z[1]*w[1], z[0]*w[1]+z[1]*w[0])


def power(z, n):
    if n < 0:
        return power((z[0], -z[1]), -n)
    result = (F(1), F(0))
    for _ in range(n):
        result = multiply(result, z)
    return result


def phase(t):
    if t is None:
        return (F(-1), F(0))
    return ((1-t*t)/(1+t*t), 2*t/(1+t*t))


def point_values(z, w):
    zw = multiply(z, (w[0], -w[1]))
    base = (power(z, 3)[0]+power(w, 3)[0]+power(zw, 3)[0]-1)/2
    delta = (1-z[0])*(1-w[0])*(1-zw[0])/8
    S1 = 2*(z[0]+w[0]+zw[0])
    return base, delta, S1


def restrictions():
    out = []
    # Rational points of the two-torus: cos and sin from stereographic t.
    ts = [F(0), F(1, 2), F(-1, 2), F(1), F(-1), F(2), F(-2), None]
    for t in ts:
        for u in ts:
            z, w = phase(t), phase(u)
            base, delta, S1 = point_values(z, w)
            if delta:
                data = {'point': 'rational_torus', 'z': z, 'w': w,
                        'base': base, 'delta': delta, 'S1': S1}
                out.append(dict(data, A=F(1), B=S1, C=(1-base)/delta, bound='upper'))
                out.append(dict(data, A=F(-1), B=-S1, C=(1+base)/delta, bound='lower'))
    # Vertex-axis slice p=2q, x=cos(q); every x in [-1,1] is realizable.
    x = s.symbols('x')
    base_poly = s.Poly((s.chebyshevt(6, x)+2*s.chebyshevt(3, x)-1)/2, x)
    for j in range(-16, 17):
        v = F(j, 16)
        base = F(base_poly.eval(s.Rational(v.numerator, v.denominator)))
        delta = (1-v*v)*(1-v)**2/4
        S1 = 4*v*v+4*v-2

            out.append(dict(data, A=F(-1), B=-S1, C=(1+base)/delta, bound='lower'))
    return out


def eliminate(rows):
    upper = [i for i, r in enumerate(rows) if r['A'] == 1]
    lower = [i for i, r in enumerate(rows) if r['A'] == -1]
    lo, hi = None, None
    for i in upper:
        for j in lower:
            B, C = rows[i]['B']+rows[j]['B'], rows[i]['C']+rows[j]['C']
            if B == 0:
                if C < 0:
                    return [(i, F(1)), (j, F(1))], None
                continue
            bound = C/B
            if B > 0 and (hi is None or bound < hi[0]):
                hi = bound, i, j, B
            if B < 0 and (lo is None or bound > lo[0]):
                lo = bound, i, j, B
    if lo is not None and hi is not None and lo[0] > hi[0]:
        return [(hi[1], 1/hi[3]), (hi[2], 1/hi[3]),

    beta = (lo[0]+hi[0])/2 if lo and hi else (lo[0] if lo else (hi[0] if hi else F(0)))

    alpha_hi = min(rows[i]['C']-rows[i]['B']*beta for i in upper)
    return None, (F(alpha_lo+alpha_hi, 2), beta)

    z, w = s.symbols('z w', nonzero=True)

    return all(s.simplify(expr.subs({z: zz, w: ww})-s.Rational(row[key])) == 0

## 1. The exact question

    f(t*n_j)=cos(r*t) on all six facet normals?

One may impose evenness and C6 invariance by averaging. D6 averaging

## 2. Hessian and transverse derivative: necessary conditions

These statements require only real boundedness, normal cosines and the
finite frequency support; not the full amplitude matrices.

First, the Hessian of f at zero is fixed. On three distinct facet-normal
lines its quadratic form is -r^2. A symmetric 2x2 matrix whose quadratic
form agrees with -r^2 I on three distinct unoriented lines equals -r^2 I:
their difference is a homogeneous quadratic vanishing on three lines,
so it is zero. Thus D^2 f(0)=-r^2 I. This does not require a separate
scalar isotropy assumption.

Fix a facet normal n and its unit tangent e. Put
g(t)=partial_e f(t*n). Then

    g(t)=0 for every real t.                                      (T)

Here is a finite-degree proof that applies to all lattice H_v. For the
facet joining v to Rv, set D=a^2+ab+b^2 and d=gcd(|a|,|b|). In lattice
coordinates its edge vector is (-a-b,a). A frequency h=(m*g1+l*g2)/L
has normalized projection

    (h.n)/r = [a*m+(a+b)*l]/D.

Therefore all normal frequencies are integer multiples of
delta=r*d/D, with maximal degree N=D/d (a positive integer). Rotation
gives the same property on the other facets. The proof needs only a
commensurate grid, not that every layer is populated.

Use theta=delta*t and write G(theta)=g(theta/delta), a real trigonometric
polynomial of degree at most N. At theta_j=j*pi/N, j=0,...,2N-1,
f((theta_j/delta)*n)=(-1)^j. Boundedness makes each such point a global
maximum or minimum in the full k-plane, so its transverse derivative is
zero: G(theta_j)=0. Multiplying G by z^N, z=exp(i*theta), gives an
ordinary polynomial of degree <=2N vanishing at all 2N-th roots of unity.
It is a constant multiple of z^(2N)-1, so reality implies
G(theta)=b*sin(N*theta) with b real. But

    G'(0)=partial_n partial_e f(0)/delta=0

by the Hessian identity above. Hence b=0 and (T) follows.

   `C - C = 2C`. For each edge `e` of `C` with outward normal `n_e`, the
   coefficients of `U U^dag` and `U^dag U` on the face of `2C` in direction
   `n_e` vanish (except at `0`, not on the face). With `E_e(x)` the edge
   polynomial of the top edge and `E_{-e}(x)` that of the opposite edge,
   this gives `E_e(x) E_{-e}(x)^dag = 0` and `E_{-e}(x)^dag E_e(x) = 0` as
   one-variable Laurent identities, together with `E_e(1) = P_+(n_e)`,
   `E_{-e}(1) = P_-(n_e)` from step 1.
3. Use 1–2 (and, if needed, the next-to-extreme faces) to restrict the
   edge coefficients to rank-one forms and eliminate unknowns, before any
   solver is run. Step 2 is a standard fact about Laurent polynomials
   (product of extreme coefficients); its use here is stated and proved in
   the report, not cited.

**Stage B — exact decision on a bounded support (`S13`, then `S19`).**

- Unknowns: the coefficients left after Stage A and the normal form of the
  hex-ceiling report Sec. 3, Step 2 (`A(n) = r_in n . sigma`, vertices at
  `k pi/3`).
- Equations: layer equations, node and isotropy, and unitarity
  `sum_h A_{h+d} A_h^dag = delta_{d0} I`, `sum_h A_h^dag A_{h+d} = delta_{d0} I`.
- **Infeasibility certificate (gap).** Accepted forms only, each checked
  exactly and quickly by the verifier without rerunning a solver:
  (i) a polynomial `p` in the ideal, given with explicit exact cofactors
  `p = sum_i h_i f_i`, whose absence of real zeros is itself certified
  exactly (e.g. a univariate polynomial with negative discriminant, as in
  T2, or a sum-of-squares-plus-positive-constant representation of `p`);
  or (ii) for the real system `f_1 = ... = f_m = 0`, an identity
  `-1 = sum_j q_j(x)^2 + sum_i h_i(x) f_i(x)` with exact rational
  coefficients, the verifier expanding both sides and checking equality. A Gröbner basis over `C`
  different from `{1}` decides nothing about real solvability and is not a
  verdict.
- **Witness.** Closed form, certified exactly: unitarity, composite `F`,
  regular hexagonal hull, node, isotropy, `c_0 = r_in`, and the product
  factorization (Sec. 2).
- Exploratory numerics (a versioned script labelled exploratory) may guide
  the search for a witness or for the certificate. **No numerical result,
  scan, optimisation or failed search enters a verdict**, and no rigidity
  is inferred from one.

## 0. Single question

> On the hexagonal substrate, can a two-component walk of the declared
> product class reach the ceiling `c_0 = r_in(C_micro)`? If not, what is
> `sup c_0 / r_in` over the class, and is it attained?

Origin: in the promoted `C_ACROSS_LATTICES` table (CURRENT_STATE Sec. 11)
every declared square, BCC/cubic and line walk has `c_0 = r_in`, and none
of the four declared hexagonal walks does (`c_0/r_in = 1/sqrt3` for ADMP,
`sqrt3/2` for JDW). The table cannot tell whether this is a property of
the substrate or of those four walks. This gate asks that question
directly, by proof or by explicit counterexample, never by a scan.

## 1. Declared class `W_hex`

Fixed for every conclusion of this gate:

- **Lattice.** `Lambda` = triangular lattice generated by `g_1 = (1,0)`,
  `g_2 = (1/2, sqrt3/2)`; the walk is translation invariant on `Lambda`.
- **Internal dimension.** `s = 2`. No larger `s` (s=4 is excluded; see
  Sec. 6).
- **Form of one update.**
  `U(k) = C_n D_n(k) C_{n-1} D_{n-1}(k) ... C_1 D_1(k)`, with `n >= 1`
  arbitrary, `C_j in U(2)` arbitrary, and
  `D_j(k) = diag(exp(-i k.a_j), exp(-i k.b_j))`, `a_j, b_j in Lambda`
  (a partial shift: each component moves by its own lattice vector). An
  optional final coin `C_{n+1}` is absorbed by conjugation and does not
  change the spectrum. This contains every encoded hexagonal row of the
  previous gate: ADMP L6a (`a_j = -b_j`, coins built from `tau_i`) and JDW
  L6c, L6d, L6f (antipodal or skew partial shifts).
- **Substrate condition.** `C_micro = conv F` is a regular hexagon centred
  at the origin, where `F` is the composite Fourier support of `U`
  (vectors with nonzero matrix coefficient, computed exactly, not the set
  of formally admissible sums).
- **Node condition.** `U(0) = e^{-i phi} I` (degenerate quasienergy at
  `k = 0`, massless node), and the linear term
  `A(k) = i dU/dk (0) . k` (with the global phase removed) is traceless
  and isotropic: `A(n)^2 = c_0^2 |n|^2 I`, `c_0 > 0`.
- **Normalisation.** Longest vector of `F` has length 1 (so
  `r_in = sqrt3/2`, `V_causal^max = 1`); one update per time unit.
- **Not assumed.** No representation-isotropy in the P17 sense
  (P17 p.7 Prop. 5 excludes the triangular lattice for that stronger
  notion; `W_hex` asks only for an isotropic cone). No irreducibility
  beyond the node condition; a reducible walk is admitted but must be
  reported as such.
