## 0. Single question

> For each declared row, how does the propagation speed depart from the
> constant `c_0` as the wavelength approaches the lattice scale: what is
> the exact lowest-order correction to the massless dispersion, its order,
> its sign, and what angular pattern the walk's symmetry imposes on it?

`c_0` is one number per row and says nothing about the shape of the
lattice beyond `r_in`. The first correction is where the substrate's
symmetry, as far as the walk keeps it, becomes visible in the dispersion.
This gate computes that correction exactly and tabulates it; it does not
interpret it physically.

  cubic group, the degree-4 cubic harmonic `k_x^4 + k_y^4 + k_z^4 -
  (3/5)|k|^4` is allowed.

## 3. Quantities per row (exact, SymPy, zero tolerance)

At the massless node of the row (at `k = 0` in every parent row, `U(0) = I`),
with `omega(k)` the quasienergy branch of the node and `k = |k| n̂`:

1. **Expansion.** `omega(k) = c_0 |k| [1 + beta(n̂) |k| + alpha(n̂) |k|^2
   + O(|k|^3)]`, obtained from the exact characteristic polynomial of the
   symbol along the ray `k = |k| n̂` (equivalently from `cos omega` or
   `omega^2` as the row's node structure allows), as functions of the
   direction cosines with radical coefficients. No series fitting. The
   first thing recorded is the **order of the lowest nonvanishing
   correction**: `beta` (relative order `|k|`, possible only if
   `omega(k) != omega(-k)` at the node) or `alpha` (relative order
   `|k|^2`). Evenness `omega(k) = omega(-k)` is checked per row, not
   assumed; the parent's "zero tilt" certifies only the linear term.
2. **Symmetry group of the walk.** For each row, the subgroup `G_walk`
   of the substrate point group under which the node dispersion is
   invariant, decided exactly by equality of characteristic polynomials
   of the symbol at `k` and `g k` (the test the L6b verifier used for the
   twelve isometries of the hexagon). `G_walk` may be smaller than the
   point group of the lattice; the harmonics allowed are those of
   `G_walk`, not of the substrate.
3. **Angular pattern.** Decompose the lowest nonvanishing correction into
   the harmonics allowed by `G_walk` (Sec. 1): `d = 1`: constant;
   `C_4`/`D_4`: `alpha_0 + alpha_4 cos 4 theta`; `C_3`: `beta_3 cos 3 theta`
   at relative order `|k|` (then `alpha` at the next order); `C_6`/`D_6`:
   `alpha_0` isotropic, no anisotropy possible at this order; cubic:
   isotropic part plus the degree-4 cubic harmonic. Record the isotropic
   part and every anisotropic coefficient exactly. For rows whose first
   correction is isotropic by symmetry (`C_6`), also compute the next
   order (relative `|k|^4`) to exhibit the first anisotropic coefficient
   `alpha_6`, if exactly feasible; otherwise record
   `ANISOTROPY_AT_HIGHER_ORDER_OPEN`. That no forbidden harmonic appears is
   a consistency check on the symbol, not a result.
4. **Sign.** For each row: sign of the isotropic coefficient of the lowest
   even correction `alpha_0` (`< 0`: subluminal at short wavelength; `= 0`;
   `> 0`), and whether the full correction changes sign with direction.
5. **Group velocity at the node.** `|grad_k omega|` to the same order, so
   the correction to `c_0` in the group speed, direction by direction;
   and, where exactly certifiable, `V_grp^max` of the node branch
   (otherwise `OPEN`, as in the parent).
6. **Scale of validity.** The smallest `|k|` at which the node branch
   meets another branch or `omega` stops being analytic, if finite and
   exactly computable; else `OPEN`.

Cross-checks: for L1 the result must reproduce the one-dimensional Dirac

## 2. Method (contract Sec. 3)

For each row the symbol is expanded exactly as a Taylor polynomial in `k`
to total degree `N` (`N = 6` in `d <= 2`, `N = 4` in `d = 3`). The node
branch is read from the quadratic factor `lambda^2 - s1 lambda + s2` of
the characteristic polynomial that carries the node:

- `s = 2` rows: the whole characteristic polynomial.
- L5b (`s = 4`): `Gamma = dP_X dP_Y dP_Z` commutes with every Fourier
  coefficient and `Gamma^2 = -I`; its two eigenspaces give two `2x2`
  Weyl blocks.
- L6b: the three `2x2` orientation blocks of `V = U^3`, as in the L6b
  verifier.
- L3s4: Hensel lifting of the quadratic factor at the double root
  `exp(∓ i pi/4)` of `A_a(0) = W`. The characteristic polynomial is
  computed from Newton's identities on truncated power traces; the script
  checks this route against the full characteristic polynomial on the
  `4x4` L5b symbol. The parameter is kept symbolic: `a` and
  `b = sqrt(1-a^2)` are independent symbols reduced with `b^2 = 1 - a^2`.
  This keeps the zero test exact, because `sqrt(1-a^2)` is not a rational
  function of `a`.

From `s1`, `s2`: `exp(-2i phi) = s2 / s2(0)` gives the common phase
`phi(k)` of the two node levels, and `cos^2 omega = s1^2/(4 s2)` gives
`omega^2(k)` as a power series with exact homogeneous parts. Then
`eps_± = eps_0 + phi ± omega`. No series is fitted; every coefficient is
an exact algebraic number or, for L3s4, an exact rational function of
`a`. The Taylor coefficients of `arccos(1-v)^2`, `log(1+v)`, `sqrt(1+v)`
and `1/(1+v)` are checked against SymPy's series.

`G_walk` is the set of point-group elements `g` of the substrate with
`charpoly U(g k) = charpoly U(k)` as Laurent identities. In characteristic
0 this equals equality of `tr U^m`, `m = 1..s`, and `tr U(gk)^m` is
`tr U^m` under the monomial substitution `z^h -> z^(Mh)`. The angular
content is read as a trigonometric polynomial in `d = 2` and projected on
`1, K4, K6` in `d = 3` (and `beta` on `1, n1 n2 n3`). A zero residual is
certified wherever `|G_walk| >= 24`.

## 3. Findings per item

### 3.1 Order of the lowest correction

Every node is untilted at linear order, as the parent certified. The
lowest correction has relative order `t` (a `beta` term) exactly in the
rows whose `G_walk` lacks inversion: L5a, L5b, L4 (`T_d`-type, 24
elements), L6a and L6b (`D_3`), and L3s4. In every row whose `G_walk`
contains `k -> -k` (L1, L2, L6e, L3, L6c, L6d, L6f), `omega^2` has no odd
terms through the computed order and the lowest correction is `alpha`.
The draft charter assumed evenness; the frozen contract required it to be
checked, and six of the thirteen rows are not even.

### 3.2 Angular pattern and the walk's group

The harmonic content matches `G_walk` in every row:

- `D_6` rows (L6c, L6d, L6f): `alpha` isotropic and `cos 6θ` first at
  relative order `t^4`, as the degree argument of contract Sec. 1 forces.
- `D_3` rows (L6a, L6b): `cos 3θ` at relative order `t`. The `cos 6θ` in
  `alpha` comes from `beta^2`; the degree-4 part of `omega^2` is
  isotropic (`Q4 = -1/96` for L6a).
- `D_4` rows (L2, L6e): `cos 4θ` at `t^2`.
- `O_h` row (L3): `K4` at `t^2`.
- 24-element cubic rows: `n1 n2 n3` at `t`, then `1, K4, K6` at `t^2`.

The three ADMP/JDW hexagonal walks with `c_0 = 3/4` have the full `D_6`.
ADMP's L6a has only `D_3`, and so has L6b, which realises L6a's dispersion
after three updates.

### 3.3 Sign

- `alpha <= 0` pointwise in L2, L6e, L3, L5a, L5b, L4 (closed forms in
  Sec. 1), vanishing only along the coordinate axes. `alpha < 0` pointwise
  in L6a, L6b (`-46/1728 <= alpha <= -36/1728` for L6a), L6c, L6d, L6f.
- In the rows with `beta != 0`, the lowest correction takes both signs: it
  is odd under `n̂ -> -n̂`. These rows are not "subluminal at short
  wavelength" in every direction even though `alpha_0 < 0`. The phase
  speed of the upper branch exceeds `c_0` near the node where
  `beta(n̂) > 0`, for example along `n1 n2 n3 > 0` in L5a.
- L3s4: `alpha_0` changes sign at `a*` (Sec. 1).

### 3.4 L3s4: a branch-dependent quadratic term

L3s4 is the only row with `phi != 0`. The two levels of each cluster move
together as `phi = ±(1 - a^2) t^2 / 6 + O(t^4)`, with opposite signs for
the clusters at `±pi/4`. This is consistent with second-order repulsion
between the clusters through the intersector coupling `b^2 = 1 - a^2`. It
gives `beta` an isotropic part `±sqrt3 (1-a^2)/(6a)` of opposite sign on
the upper and lower branch of a cluster; `alpha` is the same for both
branches and both clusters. `G_walk` has 8 elements, so `alpha` has
content outside `span(1, K4, K6)`. The verifier prints it; it is not
tabulated further here. At `a = 1` the isotropic part of `beta` vanishes,
and `beta = (sqrt3/3) n1 n2 n3` with `alpha_0 = -4/315`, the values of
L5a.

### 3.5 Group velocity at the node

`|grad eps_+| / c_0 = 1 + 2 beta(n̂) t + O(t^2)`, and `1 + 3 alpha(n̂) t^2
+ O(t^4)` where `beta = 0`. The coefficients through relative order `t^4`
(`d <= 2`) or `t^2` (`d = 3`) are printed per row by the verifier.
`V_grp^max` is `OPEN` for every row in `d >= 2`, as in the parent. For L1,
`omega = |k|` on the whole branch, so its group speed is 1 everywhere;
this follows from the symbol `exp(-i k sigma_z)` and is checked by the
script only through `t^5`.

### 3.6 Scale of validity

L1: the branches meet first at `|k| = pi` (exact). `d >= 2`: `OPEN`. The
exact minimisation of `|k|` on the branch-meeting set was not attempted,
as contract Sec. 3 item 6 allows.

## 4. Cross-checks and second route

- **L1** reproduces the exactly linear 1D massless walk: all corrections
  vanish through `t^5`.
- **Closed forms by hand.** For a symbol with `cos omega = prod_i cos p_i`
  and `p = k / sqrt d`, the expansion `log cos x = -x^2/2 - x^4/12 +
  O(x^6)` gives `omega^2 = |p|^2 - (1/3) sum_{i<j} p_i^2 p_j^2 + O(p^6)`,
  hence `alpha = -sum_{i<j} n_i^2 n_j^2 / (6d)`. This is `-n1^2 n2^2/12`
  for L2 and `-sigma2/18` for L3. For the chiral BCC rows,
  `alpha = (3/2) Q4 - Q3^2/(8 c_0^4)` with `Q4 = -sigma2/27` and
  `Q3 = (2 sqrt3/9) n1 n2 n3` gives `-sigma2/18 - n1^2 n2^2 n3^2/6`. The
  verifier asserts all three forms against its series output.
- **L6b vs L6a.** With each row's normalisation,
  `eps_L6b(k) = eps_L6a(2 R k) / 3` for a 60° rotation `R`. So
  `c_0` scales by `2/3`, `beta` by 2 and `alpha` by 4. All three are
  asserted exactly. The rotation reverses the sign of `cos 3θ`, which is
  why `beta` changes sign between the two rows. The three orientation
  blocks of L6b give identical results.
- **L6c, L6d, L6f:** compared in Sec. 1.
- **L5b:** both Weyl blocks give the same `alpha` and opposite `beta`.
  **L3s4:** both clusters give the same `alpha`.

## 5. Corrections made during the execution

- The first runs used the full characteristic polynomial; for L3s4 with
  symbolic `a` it did not finish in an hour. It was replaced by Newton's
  identities on truncated power traces, cross-checked as stated.
- A rational parametrisation of `a` was tried and abandoned: SymPy merged
  `1 + u^2` with negative powers of `z`. The independent-symbol reduction
  replaced it.
- The first cross-check of L6b against L6a compared `alpha` without the
  scale factor 4. The second route above derived the factor, and the
  check was corrected before any passing run.
- Two per-row assertions assumed that `beta` is purely `n1 n2 n3` and that
  `alpha` is cubic-invariant. Both fail for L3s4, whose group has 8
  elements. They now apply only where `|G_walk| >= 24` and are reported
  descriptively otherwise.

## 6. What this does not claim

- No physical interpretation of `alpha` or `beta`, no observational
  comparison, no statement about our universe (contract Secs. 5, 7).
- Hf's refutation by L2 and L6e is one coincidence on one substrate. It is
  not evidence that the substrate fixes the correction in general; the
  hexagon and BCC substrates carry rows with different corrections.
- The observation that `alpha <= 0` pointwise in every row with
  `d >= 2` except L3s4 is a pattern in the declared list, found after
  solving. It is not a hypothesis of this gate and not a law.
- Not human review. No novelty claim.

def reduce_b(e):
    """Reduce modulo b^2 = 1 - a^2, leaving b to degree <= 1. Since
    sqrt(1-a^2) is not a rational function of a, c0(a) + c1(a) b vanishes
    identically on 0 < a < 1 iff c0 = c1 = 0: the zero test stays exact."""
    if not e.has(B_SYM):
        return e
    poly = sp.Poly(sp.expand(e), B_SYM)
    return sp.expand(sum((c * (1 - A_SYM ** 2) ** (j // 2) * B_SYM ** (j % 2)
                          for (j,), c in poly.terms()), sp.Integer(0)))


def canon(e):
    """Canonical radical form for a scalar; zero iff the scalar is zero."""
    return sp.radsimp(sp.simplify(sp.expand_complex(reduce_b(sp.expand(e)))))


def zero(e):
    e = reduce_b(sp.expand(e))
    return e == 0 or canon(e) == 0      # fast path when expansion already gives 0


def czero(expr, syms):
    """Zero test for a polynomial in syms with radical coefficients."""
    expr = sp.expand(expr)
    if expr == 0:
        return True
    return all(zero(c) for c in sp.Poly(expr, *syms).coeffs())

def trunc(expr, ks, N):
    expr = sp.expand(expr)
    if expr == 0:
        return sp.Integer(0)
    poly = sp.Poly(expr, *ks)
    return sum((reduce_b(c) * sp.prod([k ** e for k, e in zip(ks, exps)])
                for exps, c in poly.terms() if sum(exps) <= N), sp.Integer(0))


def homog(expr, ks, m):
    expr = sp.expand(expr)
    if expr == 0:
        return sp.Integer(0)
    poly = sp.Poly(expr, *ks)
    return sum((c * sp.prod([k ** e for k, e in zip(ks, exps)])
                for exps, c in poly.terms() if sum(exps) == m), sp.Integer(0))


def compose(coeffs, x, ks, N):
    """sum_j coeffs[j] x^j truncated at total degree N; x has no constant term."""
    out = sp.Integer(coeffs[0])
    power = sp.Integer(1)
    for j in range(1, len(coeffs)):
        power = trunc(power * x, ks, N)
        if power == 0:
            break
        out += coeffs[j] * power
    return trunc(out, ks, N)


def taylor_symbol(support, gens, scale, sigma, ks, N):
    """U(k) = sum_h A_h exp(sigma i k.h_cart / scale), Taylor polynomial of degree N."""
    d = len(ks)
    U = sp.zeros(next(iter(support.values())).rows)
    for h, A in support.items():
        cart = [sum(a * sp.Matrix(g)[i] for a, g in zip(h, gens)) for i in range(d)]
        phase = sigma * sp.I * sum(k * c for k, c in zip(ks, cart)) / scale
        e = sum((phase ** m / sp.factorial(m) for m in range(N + 1)), sp.Integer(0))
        U += A.applyfunc(canon) * e
    return U.applyfunc(lambda e: trunc(e, ks, N))

def node_from_quadratic(s1, s2, ks, N):
    """Given the quadratic factor lambda^2 - s1 lambda + s2 carrying the node
    (truncated at degree N), return (phi, omega2, lambda0): the common phase
    phi(k) with exp(-2 i phi) = s2/s2(0), and omega^2(k) with
    cos^2 omega = s1^2/(4 s2), both as polynomials in k of degree <= N."""
    at0 = {k: 0 for k in ks}
    s20 = canon(s2.subs(at0))
    s10 = canon(s1.subs(at0))
    lam0 = canon(s10 / 2)                     # double root at k = 0
    record_quiet = zero(lam0 ** 2 - s20)
    if not record_quiet:
        raise ValueError("node factor is not a double root at k = 0")
    x = trunc(s2 / s20 - 1, ks, N)
    phi = trunc(sp.I / 2 * compose(LOG1P, x, ks, N), ks, N)
    inv_s2 = trunc(compose(INV1P, x, ks, N) / s20, ks, N)
    g = trunc(s1 ** 2 * inv_s2 / 4, ks, N)
    v = trunc(2 * (1 - g), ks, N)             # 1 - cos(2 omega)
    omega2 = trunc(compose(ACOS2, v, ks, N) / 4, ks, N)
    return phi, omega2, lam0


def reduce_sphere(expr, ns):
    """Reduce a polynomial in n modulo |n|^2 = 1 (last variable eliminated)."""
    expr = sp.expand(expr)
    if expr == 0 or len(ns) == 1:
        return sp.expand(expr.subs(ns[0] ** 2, 1)) if len(ns) == 1 else expr
    last = ns[-1]
    rest = 1 - sum(n ** 2 for n in ns[:-1])
    poly = sp.Poly(expr, last)
    out = sp.Integer(0)
    for (j,), c in poly.terms():
        out += c * last ** (j % 2) * rest ** (j // 2)
    return sp.expand(out)


def ray_expansion(phi, omega2, ks, ns, N, divisor=1):
    """Upper node branch along k = t n, |n| = 1:
    eps_+ - eps_0 = (phi + omega)/divisor = sum_j E_j(n) t^j.
    Returns c0 and the dict {j: E_j(n)} (sphere-reduced), j = 1..N-1,
    together with the homogeneous parts Q_m(n) of omega^2 and Phi_m of phi."""
    sub = {k: T * n for k, n in zip(ks, ns)}
    om2_t = sp.expand(omega2.subs(sub))
    Q = {m: reduce_sphere(om2_t.coeff(T, m), ns) for m in range(0, N + 1)}
    ph_t = sp.expand(phi.subs(sub))
    Phi = {m: reduce_sphere(ph_t.coeff(T, m), ns) for m in range(0, N + 1)}
    c0sq = canon(Q[2])
    c0 = sp.radsimp(sp.sqrt(c0sq))
    x = sum((Q[m] / c0sq * T ** (m - 2) for m in range(3, N + 1)), sp.Integer(0))
    sq = compose(SQRT1P, x, [T], N - 2)
    om_t = sp.expand(c0 * T * sq)
    eps_t = sp.expand((om_t + ph_t) / divisor)
    E = {j: reduce_sphere(eps_t.coeff(T, j), ns) for j in range(1, N)}
    return c0 / divisor, E, Q, Phi


def group_velocity(phi, omega2, ks, ns, N, c0, divisor=1):
    """|grad eps_+| along k = t n to relative order t^(N-2): returns the
    coefficients gamma_j with |grad eps_+| = c0 [1 + sum_j gamma_j t^j]."""
    sub = {k: T * n for k, n in zip(ks, ns)}
    grad_om2 = [sp.expand(sp.diff(omega2, k).subs(sub)) for k in ks]
    grad_phi = [sp.expand(sp.diff(phi, k).subs(sub)) for k in ks]
    om2_t = sp.expand(omega2.subs(sub))
    c0full = c0 * divisor
    c0sq = c0full ** 2
    x = sp.expand(sum((reduce_sphere(om2_t.coeff(T, m), ns) / c0sq * T ** (m - 2)
                       for m in range(3, N + 1)), sp.Integer(0)))
    inv_sqrt = compose(SQRT1P, x, [T], N - 2)     # sqrt(1+x)
    inv_sqrt = compose(INV1P, sp.expand(inv_sqrt - 1), [T], N - 2)  # 1/sqrt(1+x)
    comps = []
    for a in range(len(ks)):
        g = sp.expand(grad_om2[a])
        # grad omega = grad omega2 / (2 omega), omega = c0full t sqrt(1+x)
        g_over_t = sp.expand(sum(reduce_sphere(g.coeff(T, m), ns) * T ** (m - 1) for m in range(1, N)))
        val = sp.expand(g_over_t * inv_sqrt / (2 * c0full) + grad_phi[a])
        comps.append(trunc(val, [T], N - 2))
    v2 = trunc(sum(c ** 2 for c in comps), [T], N - 2)
    v2 = sp.expand(sum(reduce_sphere(v2.coeff(T, m), ns) * T ** m for m in range(0, N - 1)))
    lead = canon(v2.coeff(T, 0))
    if not zero(lead - c0sq):
        raise ValueError(f"group speed at the node is not c0: {lead} vs {c0sq}")
    y = trunc(v2 / c0sq - 1, [T], N - 2)
    vg = compose(SQRT1P, y, [T], N - 2)
    return {j: reduce_sphere(sp.expand(vg).coeff(T, j), ns) for j in range(1, N - 1)}

def fourier2(f, ns):
    """Trigonometric content of f(cos th, sin th): returns {m: (a_m, b_m)} with
    f = a_0 + sum_{m>0} a_m cos(m th) + b_m sin(m th), exactly."""
    sub = {ns[0]: (W + 1 / W) / 2, ns[1]: (W - 1 / W) / (2 * sp.I)}
    g = sp.expand(f.subs(sub))
    out = {}
    if g == 0:
        return {0: (sp.Integer(0), sp.Integer(0))}
    shift = W ** 40
    poly = sp.Poly(sp.expand(g * shift), W)
    c = {}
    for (e,), coeff in poly.terms():
        c[e - 40] = canon(coeff)
    ms = sorted({abs(m) for m in c})
    for m in ms:
        cp, cm = c.get(m, 0), c.get(-m, 0)
        if m == 0:
            out[0] = (canon(cp), sp.Integer(0))
        else:
            out[m] = (canon(cp + cm), canon(sp.I * (cp - cm)))
    return out


def dfact(n):
    return sp.Integer(1) if n <= 0 else sp.Integer(n) * dfact(n - 2)


def sphere_average(f, ns):
    """Exact average over the unit sphere S^2 of a polynomial in n."""
    f = sp.expand(f)
    if f == 0:
        return sp.Integer(0)
    poly = sp.Poly(f, *ns)
    out = sp.Integer(0)
    for exps, c in poly.terms():
        if any(e % 2 for e in exps):
            continue
        out += c * sp.prod([dfact(e - 1) for e in exps]) / dfact(sum(exps) + 1)
    return canon(out)


def cubic_content(f, ns):
    """f on S^2 = a0 + b4 K4 + b6 K6 + residual, with K4 = sum n^4 - 3/5 and K6
    the part of n1^2 n2^2 n3^2 orthogonal (L^2(S^2)) to 1 and K4. 1, K4, K6
    span the cubic (O_h) invariants of degree <= 6 on S^2. A zero residual
    certifies that f has only cubic-invariant content up to degree 6."""
    def avg(x):
        return sphere_average(reduce_sphere(x, ns), ns)
    K4 = reduce_sphere(sum(n ** 4 for n in ns) - sp.Rational(3, 5), ns)
    m6 = reduce_sphere(sp.prod([n ** 2 for n in ns]), ns)
    K6 = reduce_sphere(m6 - avg(m6) - avg(m6 * K4) / avg(K4 * K4) * K4, ns)
    a0 = avg(f)
    b4 = canon(avg(f * K4) / avg(K4 * K4))
    b6 = canon(avg(f * K6) / avg(K6 * K6))
    residual = reduce_sphere(f - a0 - b4 * K4 - b6 * K6, ns)
    return a0, b4, b6, residual


# ------------------------------------------------------------ symmetry group
def rot2(angle):
    return sp.Matrix([[sp.cos(angle), -sp.sin(angle)], [sp.sin(angle), sp.cos(angle)]])


def point_group(name):
    if name == "line":
        return {"+1": sp.Matrix([[1]]), "-1": sp.Matrix([[-1]])}
    F = sp.diag(1, -1)
    if name == "square":
        g = {}
        for j in range(4):
            g[f"R{90 * j}"] = rot2(sp.pi * j / 2)
            g[f"R{90 * j}F"] = rot2(sp.pi * j / 2) * F
        return g
    if name == "hexagon":
        g = {}
        for j in range(6):
            g[f"R{60 * j}"] = rot2(sp.pi * j / 3)
            g[f"R{60 * j}F"] = rot2(sp.pi * j / 3) * F
        return g
    if name == "cubic":
        g = {}
        for perm in itertools.permutations(range(3)):
            for signs in itertools.product((1, -1), repeat=3):
                m = sp.zeros(3)
                for i in range(3):
                    m[i, perm[i]] = signs[i]
                g[f"P{perm}S{signs}"] = m
        return g
    raise ValueError(name)


def lp_equal(a, b, zs):
    shift = sp.prod([z ** 12 for z in zs])
    diff = sp.expand((a - b) * shift)
    if diff == 0:
        return True
    return all(zero(c) for c in sp.Poly(diff, *zs).coeffs())


def power_traces(symbol, n):
    """tr(U^m), m = 1..n, exact Laurent polynomials."""
    out, M = [], sp.eye(symbol.rows)
    for _ in range(n):
        M = (M * symbol).applyfunc(sp.expand)
        out.append(sp.expand(M.trace()))
    return out


def walk_group(symbol, zs, gens, group):
    """Elements g of the substrate point group with charpoly U(g k) = charpoly U(k).
    In characteristic 0 the characteristic polynomial of an s x s matrix is
    determined by tr(U^m), m = 1..s (Newton identities), and tr(U(g k)^m) is
    tr(U^m) with the monomial substitution z^h -> z^(M h), M the integer
    matrix of g in generator coordinates (k.h is invariant)."""
    d = len(gens[0])
    G = sp.Matrix([[sp.Matrix(g)[i] for g in gens] for i in range(d)])
    Ginv = G.inv()
    traces = power_traces(symbol, symbol.rows)
    members, non_lattice = [], []
    for name, g in group.items():
        M = (Ginv * g.T * G).applyfunc(canon)
        if not all(x.is_integer for x in M):
            non_lattice.append(name)
            continue
        sub = {zs[i]: sp.prod([zs[j] ** int(M[j, i]) for j in range(d)]) for i in range(d)}
        if all(lp_equal(sp.expand(tr.subs(sub, simultaneous=True)), tr, zs) for tr in traces):
            members.append(name)
    return members, non_lattice


def truncated_charpoly(Uk, ks, N):
    """Coefficients (low to high in lambda) of det(lambda - U(k)) truncated at
    total degree N in k, from Newton's identities on truncated power traces."""
    n = Uk.rows
    p, M = [], sp.eye(n)
    for _ in range(n):
        M = (M * Uk).applyfunc(lambda e: trunc(e, ks, N))
        p.append(trunc(M.trace(), ks, N))
    e = [sp.Integer(1)]
    for m in range(1, n + 1):
        acc = sum(((-1) ** (i - 1) * e[m - i] * p[i - 1] for i in range(1, m + 1)), sp.Integer(0))
        e.append(trunc(acc / m, ks, N))
    coeffs = [sp.Integer(0)] * (n + 1)
    for m in range(n + 1):
        coeffs[n - m] = (-1) ** m * e[m]
    return coeffs


def describe_group(members, dim):
    rot = [m for m in members if not m.endswith("F")] if dim == 2 else None
    if dim == 1:
        return f"{{{', '.join(members)}}}"
    if dim == 2:
        refl = [m for m in members if m.endswith("F")]
        return f"{len(members)} elements: rotations {sorted(rot)}, reflections {len(refl)}"
    if len(members) == 48:
        return "48 of 48 signed permutations (O_h)"
    return f"{len(members)} of 48 signed permutations: {sorted(members)}"

def row_L3s4_symbol(a, zs):
    """A_a(k) of CURRENT_STATE Sec. 4.1 at theta = pi/4: W exp(-i q.Gamma) with
    q_i = k_i/sqrt3 and z_i <-> exp(-i q_i), i.e. generators e_i/sqrt3, sigma=-1.
    The radical b = sqrt(1-a^2) built inside core() is replaced by the symbol
    B_SYM, reduced with b^2 = 1 - a^2 (reduce_b)."""
    b, w, ts, gammas, rs = AA.core(a, sp.pi / 4)
    gammas = tuple(g.xreplace({b: B_SYM}) for g in gammas)
    if any(e.has(sp.sqrt(1 - a ** 2)) for g in gammas for e in g):
        raise ValueError("L3s4: sqrt(1-a^2) survived the substitution")
    U = w
    for z, gam in zip(zs, gammas):
        cosq = (z + 1 / z) / 2
        sinq = (1 / z - z) / (2 * sp.I)     # z = exp(-i q)
        U = U * (cosq * sp.eye(4) - sp.I * sinq * gam)
    return U.applyfunc(sp.expand)


def hensel_quadratic(coeffs, lam0, ks, N):
    """coeffs: monic polynomial sum_j coeffs[j] lambda^j (coeffs[-1] = 1) with
    entries polynomials in k of degree <= N. At k = 0, lam0 is a double root
    and the cofactor is coprime to (lambda - lam0)^2. Returns (s1, s2) with
    the lifted quadratic factor lambda^2 - s1 lambda + s2, exact to degree N."""
    n = len(coeffs) - 1
    at0 = {k: 0 for k in ks}
    P0 = sp.Poly(sum(canon(c.subs(at0)) * LAM ** j for j, c in enumerate(coeffs)), LAM)
    Q0 = sp.Poly(sp.expand((LAM - lam0) ** 2), LAM)
    R0, rem = sp.div(P0, Q0)
    if not all(zero(c) for c in rem.all_coeffs()):
        raise ValueError("lam0 is not a double root at k = 0")
    R0 = sp.Poly([canon(c) for c in R0.all_coeffs()], LAM)
    # Unknowns u = (q0, q1, r0, ..., r_{n-3}); linear map u -> Q0 * r + R0 * q.
    us = sp.symbols(f"u0:{n}")
    qpoly = sp.Poly(us[0] + us[1] * LAM, LAM)
    rpoly = sp.Poly(sum(us[2 + i] * LAM ** i for i in range(n - 2)), LAM)
    lin = (Q0 * rpoly + R0 * qpoly).as_expr()
    S = sp.Matrix([[sp.expand(lin).coeff(LAM, j).coeff(u) for u in us] for j in range(n)])
    Sinv = S.inv().applyfunc(canon)
    Qparts = {0: Q0.as_expr()}
    Rparts = {0: R0.as_expr()}
    for m in range(1, N + 1):
        Pm = sum(homog(c, ks, m) * LAM ** j for j, c in enumerate(coeffs))
        conv = sum((Qparts[i] * Rparts[m - i] for i in range(1, m)), sp.Integer(0))
        rhs_poly = sp.expand(Pm - conv)
        rhs = sp.Matrix([rhs_poly.coeff(LAM, j) for j in range(n)])
        sol = (Sinv * rhs).applyfunc(sp.expand)
        Qparts[m] = sol[0] + sol[1] * LAM
        Rparts[m] = sum(sol[2 + i] * LAM ** i for i in range(n - 2))
    Q = sp.expand(sum(Qparts.values()))
    q1 = sp.expand(Q.coeff(LAM, 1))
    q0 = sp.expand(Q.coeff(LAM, 0))
    return -q1, q0


def analyse_block(label, s1, s2, ks, ns, N, divisor, results, expected_c0):
    """From the node quadratic factor to the tabulated quantities."""
    phi, omega2, lam0 = node_from_quadratic(s1, s2, ks, N)
    c0, E, Q, Phi = ray_expansion(phi, omega2, ks, ns, N, divisor)
    dim = len(ks)
    record(f"{label}: omega^2 has no terms of degree 0 or 1 and its degree-2 part is c0^2 |k|^2",
           czero(Q[0], ns) and czero(Q[1], ns) and zero(Q[2] - c0 ** 2 * divisor ** 2))
    record(f"{label}: c0 = {c0} agrees with the parent table", zero(c0 - expected_c0))
    record(f"{label}: no linear phase (phi has no degree-1 part: untilted node)", czero(Phi[1], ns))
    odd = {m: czero(Q[m], ns) for m in range(3, N + 1, 2)}
    even_phi = {m: czero(Phi[m], ns) for m in range(2, N + 1)}
    beta = sp.expand(E[2] / c0)
    alpha = sp.expand(E[3] / c0)
    print(f"  {label}: node eigenvalue at k=0: {lam0}; eps_0 = {canon(sp.I * sp.log(lam0))}")
    print(f"  {label}: Q3 = {Q[3]}; Q4 = {Q[4]}")
    if N >= 6:
        print(f"  {label}: Q5 = {Q[5]}; Q6 = {Q[6]}")
    print(f"  {label}: phi: Phi2 = {Phi[2]}, Phi3 = {Phi[3]}, Phi4 = {Phi[4]}")
    print(f"  {label}: beta(n) = {beta}")
    print(f"  {label}: alpha(n) = {alpha}")
    gam = group_velocity(phi, omega2, ks, ns, N, c0, divisor)
    print(f"  {label}: |grad eps_+| / c0 - 1 = " + " + ".join(f"({g}) t^{j}" for j, g in gam.items()))
    info = dict(c0=c0, beta=beta, alpha=alpha, E=E, Q=Q, Phi=Phi, gamma=gam, dim=dim,
                odd_zero=all(odd.values()), phi_zero=all(even_phi.values()))
    if dim == 1:
        info["alpha0"] = canon(alpha)
        info["aniso"] = sp.Integer(0)
        info["pattern"] = f"constant alpha = {info['alpha0']}"
    elif dim == 2:
        fb = fourier2(beta, ns)
        fa = fourier2(alpha, ns)
        info["fourier_beta"], info["fourier_alpha"] = fb, fa
        info["alpha0"] = fa.get(0, (sp.Integer(0),))[0]
        info["aniso"] = {m: v for m, v in fa.items() if m > 0 and not (zero(v[0]) and zero(v[1]))}
        info["pattern"] = (f"beta: {fb}; alpha: {fa}")
        if N >= 6:
            f5 = fourier2(sp.expand(E[5] / c0), ns)
            info["fourier_E5"] = f5
            print(f"  {label}: E5/c0 (relative order t^4) harmonics: {f5}")
    else:
        a0, b4, b6, res = cubic_content(alpha, ns)
        info["alpha0"] = a0
        info["aniso"] = {4: b4, 6: b6} if not (zero(b4) and zero(b6)) else {}
        info["cubic_residual"] = res
        n123 = sp.prod(ns)
        b0 = sphere_average(beta, ns)
        b3 = canon(sphere_average(reduce_sphere(beta * n123, ns), ns)
                   / sphere_average(reduce_sphere(n123 ** 2, ns), ns))
        info["beta0"], info["beta3"] = b0, b3
        info["beta_residual"] = reduce_sphere(beta - b0 - b3 * n123, ns)
        info["pattern"] = (f"beta = {b0} + ({b3}) n1 n2 n3 [+ residual "
                           f"{'0' if czero(info['beta_residual'], ns) else 'nonzero'}]; "
                           f"alpha = {a0} + ({b4}) K4 + ({b6}) K6 [+ residual "
                           f"{'0' if czero(res, ns) else 'nonzero'}]")
    if dim == 1:
        info["lowest"] = "beta" if not czero(beta, ns) else ("alpha" if not czero(alpha, ns) else "none (to t^%d)" % (N - 2))
    else:
        info["lowest"] = "beta" if not czero(beta, ns) else ("alpha" if not czero(alpha, ns) else "none")
    if info["lowest"] == "beta":
        if dim == 2:
            info["lowest_aniso"] = any(m > 0 and not (zero(v[0]) and zero(v[1])) for m, v in info["fourier_beta"].items())
        else:
            info["lowest_aniso"] = not zero(info["beta3"]) or not czero(info["beta_residual"], ns)
    elif info["lowest"] == "alpha":
        info["lowest_aniso"] = bool(info["aniso"]) or (dim == 3 and not czero(info["cubic_residual"], ns))
    else:
        info["lowest_aniso"] = False
    print(f"  {label}: lowest nonvanishing correction: {info['lowest']}; anisotropic: {info['lowest_aniso']}")
    print(f"  {label}: lowest corrections: beta == 0: {czero(beta, ns)}; alpha0 = {info['alpha0']}; "
          f"angular content: {info['pattern']}")
    results[label] = info
    return info


def validity_scale_1d(s1, ks):
    """d = 1: smallest |k| > 0 where the two branches meet (cos omega = +-1)."""
    k = ks[0]
    sols = []
    for sgn in (1, -1):
        try:
            sol = sp.solveset(sp.Eq(s1 / 2, sgn), k, domain=sp.Interval.open(0, 4 * sp.pi))
            if isinstance(sol, sp.FiniteSet):
                sols += [s for s in sol if s.is_real]
        except Exception:
            pass
    return min(sols, key=lambda x: float(x)) if sols else None

def laurent_support(matrix, zs, bound=8):
    """Displacements h (integer generator coordinates) with nonzero
    coefficient matrix, for a symbol written with z^h <-> exp(-i k.h)."""
    shift = sp.prod([z ** bound for z in zs])
    coefficients = {}
    for r in range(matrix.rows):
        for c in range(matrix.cols):
            expr = sp.expand(shift * matrix[r, c])
            if expr == 0:
                continue
            poly = sp.Poly(expr, *zs)
            for powers, coeff in poly.terms():
                h = tuple(p - bound for p in powers)
                coefficients.setdefault(h, sp.zeros(matrix.rows, matrix.cols))
                coefficients[h][r, c] += coeff
    return {h: m for h, m in coefficients.items() if not is_zero_matrix(m)}

def lattice_index(vectors):

    relative to the generator lattice (1 = they generate all of it)."""
    d = len(vectors[0])

    from sympy.matrices.normalforms import smith_normal_form
    snf = smith_normal_form(m, domain=sp.ZZ)
    return sp.prod([abs(snf[i, i]) for i in range(d)])

def jdw_shift(zs, read_L, read_R):
    """(S Psi)(X) = (psi^L(X+read_L), psi^R(X+read_R)): L moves by -read_L."""
    return monomial(zs, neg(read_L)) * PROJ_L + monomial(zs, neg(read_R)) * PROJ_R

# Massless geometry and speeds at the declared node k = 0.
#
# Normalisation (contract Sec. 2): Cartesian positions divided by the longest
# |h| in F, one complete update per time unit. U(k) is obtained from the
# Laurent symbol by z_j = exp(sigma * i * k.g_j / L), sigma = -1 for the
# symbols built above (z <-> exp(-i k.g)) and +1 for the published standard
# symbols (z = exp(i k)). Signs of nonzero algebraic numbers are decided by
# SymPy's exact relational evaluation on radicals; zero tests are symbolic.

def positive(x):
    v = sp.radsimp(sp.simplify(x))
    if v == 0:
        return 0
    return 1 if bool(v > 0) else -1


def hull(points):
    """Facets (unit outward normal, distance) and vertex set of conv(points),
    for points spanning R^d with the origin in the interior."""
    import itertools
    d = points[0].rows
    facets = {}
    for combo in itertools.combinations(range(len(points)), d):
        base = points[combo[0]]
        if d == 1:
            normal = sp.Matrix([1])
        else:
            diff = sp.Matrix([list((points[i] - base).T) for i in combo[1:]])
            ns = diff.nullspace()
            if len(ns) != 1:
                continue
            normal = ns[0]
        offset = (normal.T * base)[0]
        if offset == 0 or positive(offset) == 0:
            continue
        if positive(offset) < 0:
            normal, offset = -normal, -offset
        if all(positive(offset - (normal.T * q)[0]) >= 0 for q in points):
            norm = sp.sqrt((normal.T * normal)[0])
            unit = (normal / norm).applyfunc(lambda e: sp.radsimp(sp.simplify(e)))
            facets[tuple(unit)] = sp.radsimp(sp.simplify(offset / norm))
    verts = []
    for idx, q in enumerate(points):
        on = [sp.Matrix(n) for n, dist in facets.items()
              if positive((sp.Matrix(n).T * q)[0] - dist) == 0]
        if on and sp.Matrix.hstack(*on).rank() == d:
            verts.append(idx)
    return facets, verts


def node_speeds(symbol, zs, gens, scale, sigma, dim):
    k = sp.symbols(f"k1:{dim + 1}", real=True)
    subs = {}
    for z, g in zip(zs, gens):
        phase = sum((k[a] * g[a] for a in range(dim)), 0) / scale
        subs[z] = sp.exp(sigma * sp.I * phase)
    U = symbol.subs(subs)
    at0 = U.subs({ka: 0 for ka in k}).applyfunc(lambda e: sp.radsimp(sp.simplify(e)))
    s_dim = symbol.rows
    A = [(sp.I * U.diff(ka)).subs({kb: 0 for kb in k}).applyfunc(
        lambda e: sp.radsimp(sp.simplify(sp.expand_complex(e)))) for ka in k]
    tilt = [sp.simplify(Ai.trace() / s_dim) for Ai in A]
    T = [Ai - t * sp.eye(s_dim) for Ai, t in zip(A, tilt)]
    c2 = sp.radsimp(sp.simplify((T[0] * T[0])[0, 0]))
    iso = all(is_zero_matrix(T[a] * T[a] - c2 * sp.eye(s_dim)) for a in range(dim)) and all(
        is_zero_matrix(T[a] * T[b] + T[b] * T[a]) for a in range(dim) for b in range(a + 1, dim))
    herm = all(is_zero_matrix(Ai - Ai.H) for Ai in A)
    return at0, A, tilt, c2, iso, herm


def nilpotent(m):
    return is_zero_matrix(m ** m.rows)


def analyse(label, symbol, zs, support, gens, sigma, results):
    dim = len(gens[0])
    cart = {h: sum((a * sp.Matrix(g) for a, g in zip(h, gens)), sp.zeros(dim, 1)) for h in support}
    L = max((sp.sqrt((v.T * v)[0]) for v in cart.values()), key=lambda x: float(x))
    L = sp.radsimp(sp.simplify(L))
    keys = sorted(support)
    pts = [(cart[h] / L).applyfunc(sp.radsimp) for h in keys]
    facets, verts = hull(pts)
    r_in = min(facets.values(), key=lambda x: float(x))
    at0, A, tilt, c2, iso, herm = node_speeds(symbol, zs, gens, L, sigma, dim)
    record(f"{label}: U(0) = I (node at k = 0, all quasienergies 0)", is_zero_matrix(at0 - sp.eye(symbol.rows)))
    record(f"{label}: linear generators i dU/dk_a(0) are Hermitian", herm)
    record(f"{label}: no tilt at the node (trace parts vanish)", all(t == 0 for t in tilt))
    record(f"{label}: isotropic untilted cone, {{T_a, T_b}} = 2 c0^2 delta_ab", iso)
    c0 = sp.radsimp(sp.sqrt(c2))
    survive = {keys[i]: not nilpotent(support[keys[i]]) for i in verts}
    all_survive = all(survive.values())
    record(f"{label}: every vertex coefficient is non-nilpotent (C_infty^strict = C_micro)",
           all_survive, f"{sum(survive.values())}/{len(survive)} vertices survive")
    c_strict = r_in if all_survive else None
    ratio = sp.radsimp(sp.simplify(c0 / r_in))
    print(f"  {label}: L = {L}; |vertices| = {len(verts)}; |facets| = {len(facets)}; "

    results[label] = dict(s=symbol.rows, d=dim, r_in=r_in, c0=c0, ratio=ratio,
                          c_strict=c_strict, iso=iso, nverts=len(verts))
    return results[label]

# Massive rows. With U(0) = exp(-i theta Q), Q^2 = I, Duhamel's formula gives
# i dU U(0)^dag = X_par + (sin theta/theta) X_perp exp(i theta Q), where
# X_par / X_perp are the parts of dH commuting / anticommuting with Q
# (corrected 2026-11-01 after both reviews; the earlier comment omitted the
# unitary factor). The code forms B = Y_par + (theta/sin theta) Y_perp from
# Y = i dU U(0)^dag, i.e. B = X_par + X_perp exp(i theta Q). When X_par = 0
# (asserted), B is Hermitian, anticommutes with Q, and {B_a, B_b} =
# {X_a, X_b}: its Gram matrix is that of dH, which defines c_H (linear
# spatial coefficient of H = i log U at fixed mass, as in the Weyl/Dirac
# gate). B itself is not dH. With
# G = (U + U^dag)/2 scalar at k = 0 and zero linear term, cos omega_j(k) are
# cos theta + eig(G_2(k)) + O(k^3), so omega_j^2 = theta^2 + (theta/sin theta)
# q_j |k|^2 with G_2 = -(q/2)|k|^2 (c_omega2^2 = theta q / sin theta).

THETA = sp.Symbol("theta", positive=True)


def massive(label, symbol, zs, gens, scale, dim, Q, c0, theta_note):
    """Certify the exact first-order Hamiltonian Gram matrix g_ab
    ({B_a, B_b} = 2 g_ab I, c_H(n)^2 = n.g.n) and the exact decomposition
    Hess_k cos(omega)(0) = -c_0^2 cos(theta) I + sin(theta) K. Isotropy is
    reported, not assumed."""
    k = sp.symbols(f"k1:{dim + 1}", real=True)
    subs = {z: sp.exp(-sp.I * sum((k[a] * g[a] for a in range(dim)), 0) / scale)
            for z, g in zip(zs, gens)}
    s_dim = symbol.rows
    ident = sp.eye(s_dim)
    U = symbol.subs(subs)
    zero = {ka: 0 for ka in k}
    simp = lambda e: sp.simplify(sp.expand_complex(sp.expand(e)))
    U0 = U.subs(zero).applyfunc(simp)
    expected = sp.cos(THETA) * ident - sp.I * sp.sin(THETA) * Q
    record(f"{label} massive: U(0) = exp(-i theta Q), Q^2 = I ({theta_note})",
           is_zero_matrix(U0 - expected) and is_zero_matrix(Q * Q - ident))
    B = []
    par_zero = True
    for a in range(dim):
        Y = ((sp.I * U.diff(k[a])).subs(zero) * expected.H).applyfunc(simp)
        Xpar = (Y + Q * Y * Q) / 2
        Xperp = (Y - Q * Y * Q) / 2
        par_zero = par_zero and is_zero_matrix(Xpar)
        B.append((Xpar + THETA / sp.sin(THETA) * Xperp).applyfunc(sp.simplify))
    record(f"{label} massive: linear dH anticommutes with the mass term (X_par = 0)", par_zero)
    gram = sp.zeros(dim, dim)
    scalar = True
    for a in range(dim):
        for b in range(dim):
            anti = ((B[a] * B[b] + B[b] * B[a]) / 2).applyfunc(sp.simplify)
            gram[a, b] = sp.simplify(anti[0, 0])
            scalar = scalar and is_zero_matrix(anti - gram[a, b] * ident)
    record(f"{label} massive: {{B_a, B_b}} = 2 g_ab I (scalar Gram matrix)", scalar)
    g_rel = (gram / (c0 ** 2 * (THETA / sp.sin(THETA)) ** 2)).applyfunc(sp.simplify)
    iso_H = is_zero_matrix(g_rel - g_rel[0, 0] * sp.eye(dim))  # Gram proportional to I
    Ud = U.H.applyfunc(lambda e: e.subs({sp.conjugate(THETA): THETA}))
    G = (U + Ud) / 2
    record(f"{label} massive: grad cos(omega)(0) = 0 (no linear dispersion term)",
           all(is_zero_matrix(G.diff(ka).subs(zero).applyfunc(simp)) for ka in k))
    K = {}
    decomposed = True
    for a in range(dim):
        for b in range(dim):
            hab = G.diff(k[a]).diff(k[b]).subs(zero).applyfunc(simp)
            rest = (hab + (c0 ** 2 * sp.cos(THETA) if a == b else 0) * ident).applyfunc(
                lambda e: sp.simplify(e / sp.sin(THETA)))
            decomposed = decomposed and all(not e.has(THETA) for e in rest)
            K[(a, b)] = rest
    record(f"{label} massive: Hess cos(omega)(0) = -c_0^2 cos(theta) I + sin(theta) K, "
           f"K independent of theta", decomposed)
    iso_W = all(is_zero_matrix(m) for m in K.values())
    print(f"  {label}: c_H Gram / (c_0 theta/sin theta)^2 = {g_rel.tolist()} -> "
          f"{('ISOTROPIC c_H, c_H^2/c_0^2 = ' + str(sp.simplify(g_rel[0, 0] * (THETA / sp.sin(THETA)) ** 2))) if iso_H else 'ANISOTROPIC c_H(n) at finite mass'}")
    Kshow = {ab: (m[0, 0] if is_zero_matrix(m - m[0, 0] * ident) else m.tolist()) for ab, m in K.items()}
    print(f"  {label}: curvature correction K_ab = {Kshow} -> "
          f"{'ISOTROPIC c_omega2 = c_0 sqrt(theta cot theta)' if iso_W else 'NO isotropic c_omega2 at finite mass (anisotropic and/or band-split, O(sin theta))'}")
    return dict(iso_H=iso_H, iso_W=iso_W, gram=g_rel, K=K)

def residual(expression):

def check_zero(label, expression):

def laurent_adjoint(matrix, variables):
    return matrix.H.subs({variable: 1 / variable for variable in variables}, simultaneous=True)


def published_symbol(dimension, chirality, variables):
    cosines = [(variable + 1 / variable) / 2 for variable in variables]
    sines = [(variable - 1 / variable) / (2 * sp.I) for variable in variables]
    if dimension == 1:
        scalar = cosines[0]
        vector = (0, 0, sines[0])
    elif dimension == 2:
        cos_x, cos_y = cosines
        sin_x, sin_y = sines
        scalar = cos_x * cos_y
        vector = (sin_x * cos_y, cos_x * sin_y, sin_x * sin_y)
    else:
        cos_x, cos_y, cos_z = cosines
        sin_x, sin_y, sin_z = sines
        scalar = cos_x * cos_y * cos_z + chirality * sin_x * sin_y * sin_z
        vector = (
            sin_x * cos_y * cos_z - chirality * cos_x * sin_y * sin_z,
            -chirality * cos_x * sin_y * cos_z - sin_x * cos_y * sin_z,
            cos_x * cos_y * sin_z - chirality * sin_x * sin_y * cos_z,
        )
    matrix = scalar * IDENTITY
    for component, pauli in zip(vector, PAULI):
        matrix -= sp.I * component * pauli
    return matrix.applyfunc(sp.expand), sp.expand(scalar)


def rotation_product(dimension, chirality, variables):
    axes = (2,) if dimension == 1 else tuple(range(dimension))
    signs = (1, -chirality, 1) if dimension == 3 else (1,) * dimension
    matrix = IDENTITY
    for variable, axis, sign in zip(variables, axes, signs):
        positive = (IDENTITY - sign * PAULI[axis]) / 2
        negative = (IDENTITY + sign * PAULI[axis]) / 2
        matrix = matrix * (variable * positive + negative / variable)
    return matrix.applyfunc(sp.expand)


def fourier_support(matrix, variables):
    shift = sp.prod(variables)
    coefficients = {}
    for row in range(matrix.rows):
        for column in range(matrix.cols):
            polynomial = sp.Poly(sp.expand(shift * matrix[row, column]), *variables)
            for powers, coefficient in polynomial.terms():
                displacement = tuple(1 - power for power in powers)
                coefficients.setdefault(displacement, sp.zeros(matrix.rows, matrix.cols))
                coefficients[displacement][row, column] += coefficient
    return {
        displacement: coefficient
        for displacement, coefficient in coefficients.items()
        if any(sp.expand(entry) != 0 for entry in coefficient)
    }


def hull_geometry(support, dimension):
    vertices = [sp.Matrix(displacement) / sp.sqrt(dimension) for displacement in support]
    facets = set()
    for selected in itertools.combinations(vertices, dimension):
        differences = sp.Matrix(dimension - 1, dimension, lambda row, column:
                                selected[row + 1][column] - selected[0][column])
        normals = differences.nullspace()
        if len(normals) != 1:
            continue
        normal = normals[0]
        offset = normal.dot(selected[0])
        if offset == 0:
            continue
        normalized = normal / offset
        distances = [sp.simplify(normalized.dot(vertex) - 1) for vertex in vertices]
        if all(distance <= 0 for distance in distances):
            facets.add(tuple(normalized))
    if not facets:
        raise ValueError("Hull has no certified facets")
    inradius = min(sp.simplify(1 / sp.sqrt(sum(value**2 for value in facet)))
                   for facet in facets)
    maximum = max(sp.sqrt(vertex.dot(vertex)) for vertex in vertices)
    return inradius, maximum, len(facets)

def jump_set(W):
    """Exact Fourier support F = {x : W_x != 0}.

    Both symbols have jump length 1 per coordinate, so multiplying by z1 z2 z3
    clears all negative powers and the monomials can be read off directly.
    """
    support = set()
    for entry in W:
        poly = sp.Poly(sp.expand(laurent(entry) * Z[0] * Z[1] * Z[2]), *Z)
        for mono, coeff in poly.terms():
            if sp.simplify(coeff) != 0:
                support.add(tuple(int(m) - 1 for m in mono))
    return support

# SUBSTRATE_CONE_OBSERVABILITY gate
# (theory/SUBSTRATE_CONE_OBSERVABILITY_GATE.md).
#
# Free-fermion (CAR) lift of walk (5.15).  On the one-particle sector the
# Bogoliubov automorphism gives alpha_t(n_x) = W^t P_x W^{t dag}, so
#
#     [alpha_t(n_x), n_y]  has (y,y') block  (W^t)_{y,x} ((W^t)_{y',x})^dag
#
# for y' != y.  Hence the commutator is nonzero exactly when the single-particle
# kernel (W^t)_{y,x} is, and the operational causal structure of the lift is the
# strict support of W^t.  Kernels are computed in EXACT Gaussian integers by
# scaling W by 4 (every entry of 4*W_x lies in Z[i]).
# ---------------------------------------------------------------------------


def scaled_blocks():
    """{x: 4*W_x} as exact Gaussian-integer 2x2 blocks, for walk (5.15)."""
    out = {}
    for i in range(2):
        for j in range(2):
            poly = sp.Poly(sp.expand(laurent(walk2()[i, j]) * Z[0] * Z[1] * Z[2]), *Z)
            for mono, coeff in poly.terms():
                x = tuple(int(m) - 1 for m in mono)
                c = sp.nsimplify(sp.simplify(coeff * 4))
                if c == 0:
                    continue
                if c != sp.re(c) + sp.I * sp.im(c) or sp.re(c) != int(sp.re(c)) or sp.im(c) != int(sp.im(c)):
                    raise ValueError(f"4*W_{x}[{i},{j}] = {c} is not a Gaussian integer")
                out.setdefault(x, [[0, 0], [0, 0]])[i][j] = complex(int(sp.re(c)), int(sp.im(c)))
    return {x: [[b[0][0], b[0][1]], [b[1][0], b[1][1]]] for x, b in out.items()}


def mat_mul(A, B):
    return [[A[0][0] * B[0][0] + A[0][1] * B[1][0], A[0][0] * B[0][1] + A[0][1] * B[1][1]],
            [A[1][0] * B[0][0] + A[1][1] * B[1][0], A[1][0] * B[0][1] + A[1][1] * B[1][1]]]


def nonzero(A):
    return any(v != 0 for row in A for v in row)


def kernel_power(nsteps):
    """Strict support and blocks of (4W)^n, exactly."""
    base = scaled_blocks()
    ker = {(0, 0, 0): [[1, 0], [0, 1]]}
    for _ in range(nsteps):
        nxt = {}
        for y, A in ker.items():
            for d, B in base.items():
                z = (y[0] + d[0], y[1] + d[1], y[2] + d[2])
                P = mat_mul(B, A)
                if z in nxt:
                    nxt[z] = [[nxt[z][i][j] + P[i][j] for j in range(2)] for i in range(2)]
                else:
                    nxt[z] = P
        ker = {y: A for y, A in nxt.items() if nonzero(A)}
    return ker

#!/usr/bin/env python3
"""Reproducible certificate for the BCC s=4 family A_{a,theta}.

SymPy-only, zero tolerance. The accompanying analytic note carries the all-
parameter proofs; this script supplies exact algebraic spot checks of the
construction, the original six-point a panel, irreducibility, Weyl slope, and
the theta-deformed quantum-metric sum rule.
"""

from itertools import product
import sympy as sp

I = sp.I
SQRT3 = sp.sqrt(3)
I2 = sp.eye(2)
I4 = sp.eye(4)
SX = sp.Matrix([[0, 1], [1, 0]])
SY = sp.Matrix([[0, -I], [I, 0]])
SZ = sp.Matrix([[1, 0], [0, -1]])
PAULI = (SX, SY, SZ)


def kron(a, b):
    return sp.kronecker_product(a, b)


def dagger(m):
    return m.conjugate().T


def zmat(m):
    return all(sp.simplify(sp.expand_complex(x)) == 0 for x in m)


def core(a, theta):
    b = sp.sqrt(1 - a**2)
    ts = (
        b * SX + a * SZ,
        b * SY + a * SZ,
        -b * SX + a * SZ,
    )
    gammas = tuple(kron(s, t) for s, t in zip(PAULI, ts))
    wt = sp.diag(sp.cos(theta) - I * sp.sin(theta),
                 sp.cos(theta) + I * sp.sin(theta))
    w = kron(I2, wt)
    rs = tuple(kron(s, I2) for s in PAULI)
    return b, w, ts, gammas, rs


def coefficients(a, theta):
    b, w, ts, gammas, rs = core(a, theta)
    coeffs = {}
    for signs in product((1, -1), repeat=3):
        m = w
        for sign, gamma in zip(signs, gammas):
            m = m * (I4 + sign * gamma) / 2
        coeffs[signs] = m
    return b, w, ts, gammas, rs, coeffs


def vec(m):
    return sp.Matrix([m[r, c] for c in range(m.cols) for r in range(m.rows)])


def commutant_nullity(mats):
    basis = []
    for c in range(4):
        for r in range(4):
            e = sp.zeros(4)
            e[r, c] = 1
            basis.append(e)
    blocks = []
    for a in mats:
        blocks.append(sp.Matrix.hstack(*(vec(e*a-a*e) for e in basis)))
    return 16 - sp.Matrix.vstack(*blocks).rank()


def structural_check():
    a = sp.Rational(1, 2)
    theta = sp.pi / 4
    b, w, ts, gammas, rs, coeffs = coefficients(a, theta)

    for t in ts:
        assert zmat(dagger(t) - t)
        assert zmat(t*t - I2)
    for gamma in gammas:
        assert zmat(dagger(gamma) - gamma)
        assert zmat(gamma*gamma - I4)
    assert zmat(w*dagger(w)-I4)

    assert len(coeffs) == 8 and (0, 0, 0) not in coeffs
    total = sum(coeffs.values(), sp.zeros(4))
    assert zmat(total-w)

    transforms = (
        lambda s: (s[0], -s[1], -s[2]),
        lambda s: (-s[0], s[1], -s[2]),
        lambda s: (-s[0], -s[1], s[2]),
    )
    for rmat, tfm in zip(rs, transforms):
        for signs, ah in coeffs.items():
            assert zmat(rmat*ah*dagger(rmat)-coeffs[tfm(signs)])

    # If X commutes with every A_h, it commutes with W=sum A_h and with
    # W Gamma_i=sum s_i A_h. Hence scalar commutant of {W,Gamma_i} is enough.
    for axis, gamma in enumerate(gammas):
        weighted = sp.zeros(4)
        for signs, ah in coeffs.items():
            weighted += signs[axis] * ah
        assert zmat(weighted-w*gamma)
    assert commutant_nullity([w, *gammas]) == 1

    # Exact Weyl projection P_+ Gamma_i P_+ = a sigma_i on tau_z=+.
    p_tau = sp.diag(1, 0)
    p = kron(I2, p_tau)
    for sigma, gamma in zip(PAULI, gammas):
        assert zmat(p*gamma*p - a*kron(sigma, p_tau))


def original_a_panel_check():
    panel = (
        sp.Rational(1, 5), sp.Rational(2, 5), sp.Rational(1, 2),
        1/sp.sqrt(2), sp.Rational(4, 5), sp.Rational(99, 100),
    )
    theta = sp.pi / 4
    for a in panel:
        b, w, ts, gammas, rs, coeffs = coefficients(a, theta)
        for signs, ah in coeffs.items():
            parity = signs[0]*signs[1]*signs[2]
            expected = sp.sqrt(2)/4 * (1 + parity*a*(2*a**2-1))
            tr = sp.trace(ah)
            assert sp.simplify(sp.expand_complex(tr-expected)) == 0
            assert sp.simplify(expected) != 0
        assert commutant_nullity([w, *gammas]) == 1


def theta_metric_check():
    # The all-theta identity is proved in the note. Verify exact representative
    # points with independently variable theta.
    a = sp.Rational(1, 2)
    for theta in (sp.pi/6, sp.pi/4, sp.pi/3):
        b, w, ts, gammas, rs = core(a, theta)
        p = kron(I2, sp.diag(1, 0))
        q = I4-p
        lp = sp.cos(theta)-I*sp.sin(theta)
        lm = sp.cos(theta)+I*sp.sin(theta)
        gap_sq = sp.simplify((lp-lm)*sp.conjugate(lp-lm))
        assert sp.simplify(gap_sq-4*sp.sin(theta)**2) == 0
        for gamma in gammas:
            du = -I*w*gamma/SQRT3
            k = q*du*p/(lp-lm)
            gii = sp.simplify(sp.expand_complex(sp.trace(dagger(k)*k)))
            expected_g = sp.simplify(b**2/(6*sp.sin(theta)**2))
            assert sp.simplify(gii-expected_g) == 0
            lhs = sp.simplify(a**2/3 + 2*sp.sin(theta)**2*gii)
            assert sp.simplify(lhs-sp.Rational(1, 3)) == 0


def main():

    original_a_panel_check()
    theta_metric_check()

    print('a_panel=1/5,2/5,1/2,1/sqrt(2),4/5,99/100')
    print('theta_panel=pi/6,pi/4,pi/3 at a=1/2')
    print('backend=sympy_exact')
    print('tolerance=0')


if __name__ == '__main__':
    main()

f2 = (1/4, sqrt3/4), so every edge midpoint has integer coordinates. The up
triangle U_n (n in Z^2, coarse) has vertices 2n, 2n+(2,0), 2n+(0,2) and
edges h (bottom), b (right, "\\") and s (left, "/") with midpoints
2n + (1,0), 2n + (1,1), 2n + (0,1). Each edge lies in exactly one up
triangle, so a unit cell holds the three edges (n, h), (n, b), (n, s); with
C^2 per edge the walk is translation invariant with s = 6 (contract Sec. 1).
The down triangle D_m has edges (m, b), (m+(0,1), h), (m+(1,0), s).

Symbol convention as in the parent verifier: entry (target, source) carries
z^(x_target - x_source), z^h <-> exp(-i k.h), physical displacements.

Reuses, read-only, the reviewed helpers of
scripts/verify_c_across_lattices_gate.py (hull, node_speeds, nilpotent,
laurent_support, laurent_adjoint, row_L6a, ...). That file is not modified.

Fails closed: any failed check or exception exits nonzero.

def record(label, ok, detail=""):
    CHECKS.append((label, bool(ok), detail))
    print(("[PASS] " if ok else "[FAIL] ") + label + (f" -- {detail}" if detail else ""))


Z = P.is_zero_matrix
ORIENT = ("h", "b", "s")
OFFSET = {"h": (1, 0), "b": (1, 1), "s": (0, 1)}
GENS = [(sp.Rational(1, 2), 0), (sp.Rational(1, 4), sp.sqrt(3) / 4)]
ZS = sp.symbols("z1:3")


def add(*vs):
    return tuple(sum(c) for c in zip(*vs))


def pos(edge):
    n, o = edge
    return add((2 * n[0], 2 * n[1]), OFFSET[o])


def up_edges(n):
    return [(n, "h"), (n, "b"), (n, "s")]


def down_edges(m):
    return [(m, "b"), (add(m, (0, 1)), "h"), (add(m, (1, 0)), "s")]


def down_of(edge):
    """The down triangle containing an edge."""
    n, o = edge
    return {"b": n, "h": add(n, (0, -1)), "s": add(n, (-1, 0))}[o]


def cart(v):
    return sp.Matrix([v[0] * GENS[0][0] + v[1] * GENS[1][0], v[0] * GENS[0][1] + v[1] * GENS[1][1]])


def ccw_successor(vertices_edges):
    """Anticlockwise successor map on the three edges of one triangle, from
    exact geometry: order the edge midpoints by angle around the centroid."""
    mids = {o: cart(pos(e)) for e, o in vertices_edges}
    centre = sum(mids.values(), sp.zeros(2, 1)) / 3
    ang = {o: sp.atan2(*(list(m - centre)[::-1])) for o, m in mids.items()}
    order = sorted(ang, key=lambda o: float(ang[o]))
    return {order[i]: order[(i + 1) % 3] for i in range(3)}


# ---------------------------------------------------------------- Part 1
def part1_labelings():
    print("== Part 1: admissible labelings (contract Sec. 2)")
    n0 = (0, 0)
    succ_up = ccw_successor([(e, e[1]) for e in up_edges(n0)])
    succ_dn = ccw_successor([(e, e[1]) for e in down_edges(n0)])
    print(f"  anticlockwise successor, up triangle: {succ_up}; down triangle: {succ_dn}")
    record("same anticlockwise cyclic order of edge orientations in up and down triangles",
           succ_up == succ_dn)
    admissible = []
    for white in ("up", "down"):
        for perm_w in itertools.permutations(range(3)):
            for perm_g in itertools.permutations(range(3)):
                lam_w = dict(zip(ORIENT, perm_w))
                lam_g = dict(zip(ORIENT, perm_g))
                succ_w = succ_up if white == "up" else succ_dn
                succ_g = succ_dn if white == "up" else succ_up
                # (i) glued triangles share the side label (p.4: psi(t,v0,1) = psi(t,v1,1))
                glue = lam_w == lam_g
                # (ii) R: side k -> k+1 is the anticlockwise rotation in every triangle (p.4)
                rot = all(lam_w[succ_w[o]] == (lam_w[o] + 1) % 3 for o in ORIENT) and all(
                    lam_g[succ_g[o]] == (lam_g[o] + 1) % 3 for o in ORIENT)
                if glue and rot:
                    admissible.append((white, lam_w))
    print(f"  {len(admissible)} admissible of {2 * 36} candidate (colouring, label_white, label_grey):")
    for white, lam in admissible:
        print(f"    white = {white}, labels {lam}")
    record("exactly 6 admissible labelings: 2 colourings x 3 rotations of one cyclic labeling",
           len(admissible) == 6)
    fig1 = {"h": 2, "b": 0, "s": 1}  # Fig. 1 as read: bottom 2, right 0, left 1 (white, upward)
    record("the labeling read from Fig. 1 (white upward; bottom 2, right 0, left 1) is admissible",
           ("up", fig1) in admissible)
    # The step map only uses 'side k-1 -> side k', i.e. the anticlockwise
    # predecessor of the edge orientation; it is the same for all three
    # rotations of the labeling, so only the colouring can change the walk.
    preds = {}
    for white, lam in admissible:
        inv = {v: o for o, v in lam.items()}
        preds.setdefault(white, set()).add(tuple(inv[(lam[o] - 1) % 3] for o in ORIENT))
    record("for each colouring the predecessor map k-1 -> k is the same for all labelings",
           all(len(v) == 1 for v in preds.values()))
    return succ_up, admissible


# ---------------------------------------------------------------- Part 2
def coin(variant):
    """W of Eq. (9) with M = I. 'parent': the matrices used for row L6a in
    the reviewed parent verifier (alpha = -arccos(sqrt5/3), S^{-1}, recorded
    there as source sign issues). 'printed': Eq. (8)-(9) as printed
    (alpha = +arccos(sqrt5/3), S = e^{i pi/3} R_z(2pi/3))."""
    c_half = sp.sqrt((1 + sp.sqrt(5) / 3) / 2)
    s_half = sp.sqrt((1 - sp.sqrt(5) / 3) / 2)
    S = sp.diag(1, sp.exp(2 * sp.pi * sp.I / 3)).applyfunc(sp.expand_complex)
    if variant == "parent":
        U0 = sp.Matrix([[c_half, s_half], [-s_half, c_half]])
        S = S.H
    else:
        U0 = sp.Matrix([[c_half, -s_half], [s_half, c_half]])
    return (U0 * S * U0.H).applyfunc(lambda e: sp.radsimp(sp.expand(e))), U0, S


def step_symbol(white, succ, W):
    """6x6 symbol of one update, Eq. (12) on pre-encoded spinors.
    Basis index 2*o + c, o in (h, b, s), c = 0 (upper, white side), 1 (lower)."""
    pred = {v: k for k, v in succ.items()}
    n0 = (0, 0)
    R = sp.zeros(6, 6)
    hops = []
    for o in ORIENT:
        target = (n0, o)
        for c, colour in ((0, white), (1, "down" if white == "up" else "up")):
            tri = up_edges(n0) if colour == "up" else down_edges(down_of(target))
            source = [e for e in tri if e[1] == pred[o]][0]
            d = tuple(a - b for a, b in zip(pos(target), pos(source)))
            R[2 * ORIENT.index(o) + c, 2 * ORIENT.index(source[1]) + c] = P.monomial(ZS, d)
            hops.append((o, c, d))
    Wall = sp.diag(*[W] * 3)
    return sp.expand(Wall * R), hops


def orientation_blocks(V):
    off = all(V[2 * i + a, 2 * j + b] == 0 for i in range(3) for j in range(3) if i != j
              for a in range(2) for b in range(2))
    return off, [V[2 * i:2 * i + 2, 2 * i:2 * i + 2] for i in range(3)]


def h_of(points, nhat):
    return max((nhat.T * p)[0] for p in points)


def analyse(white, succ, variant):
    tag = f"[white={white}, W={variant}]"
    W, U0, S = coin(variant)
    record(f"{tag} W is unitary and W^3 = I", Z(W * W.H - P.I2) and Z(W ** 3 - P.I2))
    U, hops = step_symbol(white, succ, W)
    P.check_unitary(f"L6b {tag}", U, ZS)

    # Encoding (contract Sec. 2): psi~ = U_k psi with U_k fixed per edge class
    # is an on-site block-diagonal unitary E, constant in z, so the symbol is
    # conjugated: same support and same eigenphases.
    Us = [U0, U0 * S, U0 * S * S]
    E = sp.diag(*Us)
    Uenc = sp.expand(E.H * U * E)
    record(f"{tag} encoding E = diag(U_k) conjugates the symbol: same support, same char. polynomial",
           set(P.laurent_support(Uenc, ZS)) == set(P.laurent_support(U, ZS))
           and sp.expand((Uenc.charpoly().as_expr() - U.charpoly().as_expr())) == 0)

    # Step set F and C_micro of one update.
    support = P.laurent_support(U, ZS)
    pts_raw = [cart(h) for h in sorted(support)]
    ell = sp.radsimp(max((sp.sqrt((p.T * p)[0]) for p in pts_raw), key=lambda x: float(x)))
    record(f"{tag} F has 6 displacements, none zero, all of length 1/2 (half a side)",
           len(support) == 6 and (0, 0) not in support
           and all(sp.simplify(sp.sqrt((p.T * p)[0]) - sp.Rational(1, 2)) == 0 for p in pts_raw))
    pts = [(p / ell).applyfunc(sp.radsimp) for p in pts_raw]
    facets, verts = P.hull(pts)
    r_in = min(facets.values(), key=lambda x: float(x))
    print(f"  {tag} F (fine coords) = {sorted(support)}; longest step = {ell}; "
          f"|vertices| = {len(verts)}; r_in(C_micro) = {r_in} (normalised)")
    record(f"{tag} C_micro is the regular hexagon, r_in = sqrt3/2 (normalised)",
           len(verts) == 6 and sp.simplify(r_in - sp.sqrt(3) / 2) == 0)
    one_step_vertices_dead = all(P.nilpotent(support[h]) for h in support)
    record(f"{tag} every one-step vertex coefficient is nilpotent (the edge orientation changes each step)",
           one_step_vertices_dead)

    # Three updates: orientation-preserving, a Bravais walk with s = 6.
    V = sp.expand(U ** 3)
    off, blocks = orientation_blocks(V)
    record(f"{tag} U^3 is block diagonal in the edge orientation", off)
    k = sp.symbols("k1:3", real=True)
    subs0 = {z: 1 for z in ZS}
    U0k = U.subs(subs0)
    record(f"{tag} U(0) = P (x) W with P the cyclic permutation; U(0)^3 = I", Z(U0k ** 3 - sp.eye(6)))
    ev = U0k.eigenvals()
    one = sum(m for lam, m in ev.items() if sp.simplify(lam - 1) == 0)
    record(f"{tag} eigenvalue 1 of U(0) has multiplicity 2 (the declared node)", one == 2,
           f"spectrum {{{', '.join(f'{sp.nsimplify(l)}:{m}' for l, m in ev.items())}}}")

    # c_0 route A: three-update symbol, scale 1 (side units), per three updates.
    at0, A, tilt, c2, iso, herm = P.node_speeds(V, ZS, GENS, 1, -1, 2)
    record(f"{tag} route A: V(0) = I, Hermitian untilted isotropic cone", Z(at0 - sp.eye(6)) and herm
           and all(t == 0 for t in tilt) and iso)
    c0_V = sp.radsimp(sp.sqrt(c2))
    c0_A = sp.radsimp(c0_V / 3 / ell)  # per update, normalised
    # c_0 route B: one update, degenerate first order on the eigenvalue-1 space.
    Ek = U.subs({z: sp.exp(-sp.I * (k[0] * g[0] + k[1] * g[1])) for z, g in zip(ZS, GENS)})
    null = (U0k - sp.eye(6)).nullspace()
    Q, _ = sp.Matrix.hstack(*null).QRdecomposition()
    Q = Q.applyfunc(lambda e: sp.radsimp(sp.simplify(e)))
    gen = [(Q.H * (sp.I * U0k.H * Ek.diff(ka)).subs({kb: 0 for kb in k}) * Q).applyfunc(
        lambda e: sp.radsimp(sp.simplify(sp.expand_complex(e)))) for ka in k]
    tr = [sp.simplify(g.trace() / 2) for g in gen]
    T = [g - t * P.I2 for g, t in zip(gen, tr)]
    cB2 = sp.radsimp(sp.simplify((T[0] * T[0])[0, 0]))
    isoB = Z(T[0] * T[0] - cB2 * P.I2) and Z(T[1] * T[1] - cB2 * P.I2) and Z(T[0] * T[1] + T[1] * T[0])
    c0_B = sp.radsimp(sp.sqrt(cB2) / ell)
    record(f"{tag} route B (one update, node subspace): untilted isotropic cone",
           all(t == 0 for t in tr) and isoB)
    record(f"{tag} routes A and B give the same c_0", sp.simplify(c0_A - c0_B) == 0,
           f"c_0 = {c0_A} (normalised), {sp.radsimp(c0_A * ell)} per update in side units")

    # C_infty^strict: vertices of conv supp(U^3) and their survival.
    supV = P.laurent_support(V, ZS)
    ptsV = [cart(h) for h in sorted(supV)]
    keysV = sorted(supV)
    facV, vertV = P.hull(ptsV)
    survive = {keysV[i]: not P.nilpotent(supV[keysV[i]]) for i in vertV}
    record(f"{tag} every vertex coefficient of U^3 is non-nilpotent",
           all(survive.values()), f"{sum(survive.values())}/{len(survive)}; supp U^3 = {keysV}")
    r_in_V = min(facV.values(), key=lambda x: float(x))
    c_strict = sp.radsimp(r_in_V / 3 / ell) if all(survive.values()) else None
    # Check the zonotope picture by support functions in the two symmetry directions.
    print(f"  {tag} conv supp U^3: |vertices| = {len(vertV)}, inradius {r_in_V} (side units, per 3 updates)")
    record(f"{tag} c_strict^iso = r_in(conv supp U^3)/3 = 1/sqrt3 (normalised)",
           c_strict is not None and sp.simplify(c_strict - 1 / sp.sqrt(3)) == 0, f"c_strict^iso = {c_strict}")
    return dict(U=U, V=V, blocks=blocks, r_in=r_in, c0=c0_A, c_strict=c_strict, ell=ell,
                supV=supV, c0_V=c0_V, iso=iso and isoB)


# ---------------------------------------------------------------- Part 3
def part3_crosschecks(res):
    print("== Part 3: cross-checks against the source (contract Sec. 4)")
    r = res[("up", "parent")]
    # Source p.4: i d_t psi = (sqrt3/6)(sigma.p) psi with triangle side sqrt3
    # (it states the distance between side midpoints is sqrt3/2) and time
    # step epsilon = one update. Per update, in side units: c_0 * ell; with
    # side sqrt3: c_0 * ell * sqrt3.
    src = sp.radsimp(r["c0"] * r["ell"] * sp.sqrt(3))
    record("c_0 in the source's units (side sqrt3, one update) equals its coefficient sqrt3/6",
           sp.simplify(src - sp.sqrt(3) / 6) == 0, f"computed {src}")
    # Source: three updates equivalent to the honeycomb walk L6a.
    l6a, zs_a, sup_a, gens_a = P.row_L6a()
    sym_a = l6a.subs(dict(zip(zs_a, ZS)))
    # The 12 isometries of the hexagon in the triangular basis g1, g2:
    # rotation by 60 deg  h -> (-b, a+b); reflection  h -> (b, a).
    rot = sp.Matrix([[0, -1], [1, 1]])
    ref = sp.Matrix([[0, 1], [1, 0]])
    group = [rot ** i * ref ** j for i in range(6) for j in range(2)]

    def act(M, expr):
        # z^h -> z^{M h}: z1 -> z1^m11 z2^m21, z2 -> z1^m12 z2^m22
        return sp.expand(expr.subs({ZS[0]: ZS[0] ** M[0, 0] * ZS[1] ** M[1, 0],
                                    ZS[1]: ZS[0] ** M[0, 1] * ZS[1] ** M[1, 1]}, simultaneous=True))

    lam = sp.Symbol("lam")
    cp_a = sym_a.charpoly(lam).as_expr()
    strict, iso_match = [], []
    for B in r["blocks"]:
        cp_b = B.charpoly(lam).as_expr()
        strict.append(sp.expand(cp_b - cp_a) == 0)
        hits = [i for i, M in enumerate(group) if sp.expand(act(M, cp_b) - cp_a) == 0]
        iso_match.append(hits)
    print(f"  same orientation (identity isometry) matches: {strict}")
    print(f"  isometries (index i = 2*rot + ref) matching each block: {iso_match}")
    record("each orientation block of U^3 has the characteristic polynomial of the L6a symbol "
           "up to an isometry of the hexagon, with L6a's generators halved",
           all(len(h) > 0 for h in iso_match), f"blocks: {iso_match}")
    record("supp U^3 equals the L6a step set F (same integer coordinates, generators halved)",
           set(r["supV"]) == set(sup_a))


def main():
    print(f"contract sha256 {hashlib.sha256(CONTRACT.read_bytes()).hexdigest()}")
    digest = hashlib.sha256((ROOT / f"sources/{SOURCE}.pdf").read_bytes()).hexdigest()
    record(f"source {SOURCE}.pdf SHA256 matches sources/README.md", digest == P.SOURCES[SOURCE])
    succ, admissible = part1_labelings()
    print("== Part 2: row L6b, massless, per admissible colouring and both coin readings")
    res = {}
    for white in ("up", "down"):
        for variant in ("parent", "printed"):
            res[(white, variant)] = analyse(white, succ, variant)
    vals = {key: (r["r_in"], r["c0"], r["c_strict"]) for key, r in res.items()}
    record("r_in, c_0, c_strict^iso identical for both colourings and both coin readings",
           len({tuple(sp.nsimplify(x) for x in v) for v in vals.values()}) == 1, str(vals))
    part3_crosschecks(res)
    print("== Hypotheses (contract Sec. 5), row L6b")
    r = res[("up", "parent")]
    record("s = 6, so L6b is outside Ha's scope (Ha stays REFUTED_BY_ROW_L6a)", r["U"].rows == 6)
    hb = sp.simplify(r["c_strict"] - r["r_in"]) == 0
    hc = P.positive(r["c_strict"] - r["c0"]) >= 0
    print(f"  r_in = {r['r_in']}, c_0 = {r['c0']}, c_strict^iso = {r['c_strict']}, "
          f"c_0/r_in = {sp.radsimp(r['c0'] / r['r_in'])}, c_strict^iso/r_in = {sp.radsimp(r['c_strict'] / r['r_in'])}")
    record("Hb fails for L6b: c_strict^iso = 1/sqrt3 < r_in = sqrt3/2 (ratio 2/3)",
           (not hb) and sp.simplify(r["c_strict"] / r["r_in"] - sp.Rational(2, 3)) == 0)
    record("Hc holds for L6b: c_0 = 1/3 <= c_strict^iso = 1/sqrt3",
           hc and sp.simplify(r["c0"] - sp.Rational(1, 3)) == 0)
    failed = [c for c in CHECKS if not c[1]]
    print(f"{len(CHECKS) - len(failed)}/{len(CHECKS)} checks passed (L6b massless row).")
    return 1 if failed else 0
