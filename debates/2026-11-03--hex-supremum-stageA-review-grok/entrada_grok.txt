## 1. Stage A: two consequences of saturation valid for every support

Notation of the hex-ceiling report: `U(k) = sum_{h in F} A_h e^{-ik.h}`,
`C = conv F` a regular hexagon, `|vertex| = 1`, `r = r_in = sqrt3/2`,
normal form `A(n) = r n.sigma` (Step 2 there). Suppose `c_0 = r_in`.

**Lemma A1 (singleton layer).** Let `n_f` be a facet normal and `delta`
the spacing of the projections of `Lambda` onto `n_f` (they lie on a
uniform grid, L0 of the parent gate). If a layer strictly between the two
extreme ones contains exactly one point `h` of `C cap Lambda`, then
`A_h = 0`.

*Proof.* By facet-line rigidity (hex-ceiling report Sec. 3, Step 1:
Bernstein equality / Julia, prior art), `U(t n_f) = e^{-irt} P_+(n_f) +
e^{irt} P_-(n_f)`, so the sum of `A_h` over each intermediate layer is 0.
A layer with one point gives `A_h = 0`. ∎

**Lemma A2 (opposite vertices).** For every vertex `v` of `C`,
`A_v A_{-v}^dag = 0` and `A_{-v}^dag A_v = 0`.

*Proof.* The coefficient of `U U^dag` at displacement `2v` is
`sum_{h - h' = 2v} A_h A_{h'}^dag`. Since `C` is centrally symmetric,
`h - h' = 2v` with `h, h' in C` means `(h + (-h'))/2 = v` with both in `C`;
`v` is extreme, so `h = v`, `h' = -v`. The coefficient must vanish
(`2v != 0`); likewise for `U^dag U`. ∎

A2 is recorded for later stages; it is not used for S13. Neither lemma
alone gives a gap proof for `W_hex^sym`.

## 4. Method, named before any computation

**Stage A — structural reduction (by hand, checked by the verifier).**

1. Facet-line rigidity (hex-ceiling report Sec. 3, Step 1, reused): along
   each of the three facet-normal lines the top edge sums to `P_+(n_f)`,
   the bottom edge to `P_-(n_f)`, every intermediate layer to `0`.
2. Extreme-face identities. The Newton polytope of `U U^dag` lies in
   `C - C = 2C`. For each edge `e` of `C` with outward normal `n_e`, the
   coefficients of `U U^dag` and `U^dag U` on the face of `2C` in direction
   `n_e` vanish (except at `0`, not on the face). With `E_e(x)` the edge
   polynomial of the top edge and `E_{-e}(x)` that of the opposite edge,
   this gives `E_e(x) E_{-e}(x)^dag = 0` and `E_{-e}(x)^dag E_e(x) = 0` as
   one-variable Laurent identities, together with `E_e(1) = P_+(n_e)`,
   `E_{-e}(1) = P_-(n_e)` from step 1.
3. Use 1–2 (and, if needed, the next-to-extreme faces) to restrict the
   edge coefficients to rank-one forms and eliminate unknowns, before any
   solver is run. Step 2 is a standard fact about Laurent polynomials
   (product of extreme coefficients); its use here is stated and proved in
   the report, not cited.

def rot(a):
    return sp.Matrix([[sp.cos(a), -sp.sin(a)], [sp.sin(a), sp.cos(a)]])


def hexagon(v):
    """Lattice points of the closed regular hexagon with vertices R^j v,
    normalised so that |v| = 1. Returns (points, vertices, normals, r_in)."""
    L = sp.sqrt((v.T * v)[0])
    verts = [rot(sp.pi * j / 3) * v for j in range(6)]
    ang = sp.atan2(v[1], v[0])
    normals = [rot(ang + sp.pi / 6 + sp.pi * j / 3) * G1 for j in range(6)]

                pts.append(h)
    s = 1 / L
    return ([(p * s).applyfunc(sp.simplify) for p in pts],
            [(w * s).applyfunc(sp.simplify) for w in verts],
            [n.applyfunc(sp.simplify) for n in normals], sp.simplify(r * s))


def layers(pts, n, r, N):
    delta = r / N
    out = {}
    for i, p in enumerate(pts):
        q = sp.nsimplify(sp.simplify((p.T * n)[0] / delta))
        if not q.is_integer:
            return None
        out.setdefault(int(q), []).append(i)
    return out


def same(p, q):
    return all(sp.simplify(x - y) == 0 for x, y in zip(p, q))

    return res

    syms = []

    def gen(k):

## 1. L0 — the ceiling `c_0 <= r_in` on `W_hex`

*Real case.* Suppose `R'(s_0) > N`. Choose `0 < eps < 1` so small that

`D = C - R_eps` has `D(s_0) = 0`, `D'(s_0) < 0`; in particular `D` is not

           sp.simplify(c0.subs(g, sp.Rational(1, 3)) - sp.Rational(1, 2)) == 0
           and sp.simplify(c0.subs(g, -sp.Rational(1, 2)) - sp.Rational(3, 4)) == 0)


def t1_walk(tvecs):
    """U(k) = prod_{j=3..1} exp(-i (k.a_j) tau_j), a_j = u_0, u_1, u_2 (unit,
    120 deg), tau_j = t_j . sigma, as a Laurent symbol in z = exp(-i k.g)."""
    zs = sp.symbols("z1:3")
    u = [(1, 0), (-1, 1), (0, -1)]          # u_0, u_1, u_2 in (g1, g2)
    factors = []
    for (tx, ty, tz), uj in zip(tvecs, u):
        tau = tx * SX + ty * SY + tz * SZ
        plus, minus = (I2 + tau) / 2, (I2 - tau) / 2
        factors.append(base.monomial(zs, uj) * plus + base.monomial(zs, base.neg(uj)) * minus)
    return sp.expand(factors[2] * factors[1] * factors[0]), zs


def check_witness():
    tv = [(sp.cos(2 * sp.pi * j / 3), sp.sin(2 * sp.pi * j / 3), 0) for j in range(3)]
    tv = [tuple(sp.nsimplify(x) for x in t) for t in tv]
    overlaps = [sum(a * b for a, b in zip(tv[i], tv[j])) for i, j in ((0, 1), (0, 2), (1, 2))]
    record("witness: Bloch vectors are unit, coplanar, pairwise overlap -1/2",
           all(sp.simplify(sum(x ** 2 for x in t) - 1) == 0 for t in tv)
           and all(sp.simplify(o + sp.Rational(1, 2)) == 0 for o in overlaps))
    symbol, zs = t1_walk(tv)
    adj = base.laurent_adjoint(symbol, zs)
    record("witness: symbol is unitary", base.is_zero_matrix(sp.expand(symbol * adj) - I2))
    support = base.laurent_support(symbol, zs)
    expected = {(-2, 0), (-2, 2), (0, -2), (0, 0), (0, 2), (2, -2), (2, 0)}
    record("witness: composite F = {0, +-2 u_j} (zero coefficient tolerated only at 0)",
           set(support) - {(0, 0)} == expected - {(0, 0)})
    gens = [(1, 0), (sp.Rational(1, 2), R3 / 2)]
    keys = sorted(h for h in support)
    cart = {h: (h[0] * G1 + h[1] * G2) for h in keys}
    L = 2
    pts = [(cart[h] / L).applyfunc(sp.radsimp) for h in keys]
    facets, verts = base.hull(pts)
    r_in = min(facets.values(), key=lambda x: float(x))
    record("witness: hull is the regular hexagon (6 vertices, 6 facets, r_in = sqrt3/2)",
           len(verts) == 6 and len(facets) == 6 and sp.simplify(r_in - R3 / 2) == 0)
    record("witness: every vertex coefficient is non-nilpotent",
           all(not base.nilpotent(support[keys[i]]) for i in verts))
    at0, A, tilt, c2, iso, herm = base.node_speeds(symbol, zs, gens, L, -1, 2)
    c0 = sp.radsimp(sp.sqrt(c2))
    record("witness: U(0) = I, Hermitian untilted isotropic cone",
           base.is_zero_matrix(at0 - I2) and herm and all(t == 0 for t in tilt) and iso)
    record("witness: c0 = 3/4 and c0/r_in = sqrt3/2", c0 == sp.Rational(3, 4)
           and sp.simplify(c0 / r_in - R3 / 2) == 0)


def check_admp():
    xi = sp.sqrt(5) / 3
    tv = [(sp.Rational(2, 3), 0, xi), (-sp.Rational(1, 3), R3 / 3, xi), (-sp.Rational(1, 3), -R3 / 3, xi)]
    overlaps = [sp.simplify(sum(a * b for a, b in zip(tv[i], tv[j]))) for i, j in ((0, 1), (0, 2), (1, 2))]
    record("ADMP: tau_i of Eq. (5) have equal pairwise overlaps g = 1/3", overlaps == [sp.Rational(1, 3)] * 3)
    symbol, zs = t1_walk(tv)
    _, _, _, c2, iso, _ = base.node_speeds(symbol, zs, [(1, 0), (sp.Rational(1, 2), R3 / 2)], 2, -1, 2)
    record("ADMP: product-form symbol gives isotropic c0 = 1/2 (matches Sec. 11 row L6a)",
           iso and sp.radsimp(sp.sqrt(c2)) == sp.Rational(1, 2))


def check_T2_minimal():
    """Minimal-support subclass: F within {0} U vert(H), any s = 2 walk (no
    product form assumed). WLOG (Bloch rotation, joint spatial/Bloch
    rotation, scale): vertices v_k = (cos k pi/3, sin k pi/3), the isotropic
    linear term A(n) = r n.sigma with n in the xy Bloch plane. Saturation
    c_0 = r_in forces, along each facet normal n, U(t n) = e^{-irt} P_+ +
    e^{irt} P_- (report, Bernstein equality / Julia), i.e. layer sums:
    top edge -> P_+(n), bottom edge -> P_-(n), middle layer -> 0."""
    v = [sp.Matrix([sp.cos(sp.pi * k / 3), sp.sin(sp.pi * k / 3)]) for k in range(6)]
    normals = [sp.Matrix([sp.cos(a), sp.sin(a)]) for a in (sp.pi / 6, sp.pi / 2, 5 * sp.pi / 6)]
    layers = []
    for n in normals:
        proj = [sp.nsimplify((vk.T * n)[0]) for vk in v]
        top = [k for k in range(6) if proj[k] == R3 / 2]
        bot = [k for k in range(6) if proj[k] == -R3 / 2]
        mid = [k for k in range(6) if proj[k] == 0]
        layers.append((top, bot, mid))
    record("T2-min: along each facet normal the layers are {top edge, middle (2 vertices + 0), bottom edge}",
           all(len(t) == 2 and len(b) == 2 and len(m) == 2 for t, b, m in layers)
           and [l[0] for l in layers] == [[0, 1], [1, 2], [2, 3]])

    def proj(n, sign):
        return (I2 + sign * (n[0] * SX + n[1] * SY)) / 2
    Pp = [proj(n, 1).applyfunc(sp.nsimplify) for n in normals]
    Pm = [proj(n, -1).applyfunc(sp.nsimplify) for n in normals]
    # generic unknown coefficients for the 6 vertices and the origin
    syms = []
    def gen(name):
        e = sp.symbols(f"{name}_0:8", real=True)
        syms.extend(e)
        return sp.Matrix([[e[0] + sp.I * e[1], e[2] + sp.I * e[3]], [e[4] + sp.I * e[5], e[6] + sp.I * e[7]]])
    X = [gen(f"X{k}") for k in range(6)]
    Z = gen("Z")
    lin = []
    for (top, bot, mid), Pt, Pb in zip(layers, Pp, Pm):
        for M in (X[top[0]] + X[top[1]] - Pt, X[bot[0]] + X[bot[1]] - Pb, X[mid[0]] + X[mid[1]] + Z):
            for e in M:
                e = sp.expand(e)
                lin += [sp.expand(sp.re(e)), sp.expand(sp.im(e))]
    x0 = syms[:8]
    sol = sp.solve(lin, [s_ for s_ in syms if s_ not in x0], dict=True)
    record("T2-min: layer equations are consistent, with the X0 coefficient free", len(sol) == 1)
    sol = sol[0]
    Zs = Z.subs(sol)
    record("T2-min: layer equations force A_0 = -I/2", base.is_zero_matrix(Zs + I2 / 2))
    Xs = [Xk.subs(sol) for Xk in X]
    pts = [(v[k], Xs[k]) for k in range(6)] + [(sp.zeros(2, 1), Zs)]
    eqs = set()
    blocks = {}
    for h1, A1 in pts:
        for h2, A2 in pts:
            d = tuple(sp.nsimplify(c) for c in (h1 - h2))
            blocks.setdefault(d, [sp.zeros(2), sp.zeros(2)])
            blocks[d][0] += A1 * A2.H
            blocks[d][1] += A2.H * A1
    for d, (m1, m2) in blocks.items():
        target = I2 if all(c == 0 for c in d) else sp.zeros(2)
        for M in (m1 - target, m2 - target):
            for e in M:
                e = sp.expand(e)
                for part in (sp.expand(sp.re(e)), sp.expand(sp.im(e))):
                    if part != 0:
                        eqs.add(part)
    G = sp.groebner(list(eqs), *x0, order="lex")
    uni = [g for g in G.exprs if g.free_symbols == {x0[6]} and sp.degree(g, x0[6]) == 2]
    ok = False
    if uni:
        a2, a1, a0 = sp.Poly(uni[0], x0[6]).all_coeffs()
        disc = sp.simplify(a1 ** 2 - 4 * a2 * a0)
        ok = bool(disc < 0)
        print(f"  T2-min: Groebner element {uni[0]} = 0, discriminant {disc}")
    record("T2-min: unitarity + saturation imply a real quadratic with negative discriminant "
           "(no real solution): the ceiling is not attained with F in {0} U vert(H)", ok)


def check_T2_square_control():
    """Positive control for the saturation method: the square substrate
    F within {0} U {(+-1,+-1)}, facet normals x and y, A(n) = r n.sigma.
    The same layer + unitarity system must be consistent, and the known
    saturating walk exp(-i k_x sigma_x) exp(-i k_y sigma_y) must solve it."""
    verts = [(1, 1), (1, -1), (-1, 1), (-1, -1)]
    syms = []
    def gen(name):
        e = sp.symbols(f"{name}_0:8", real=True)
        syms.extend(e)
        return sp.Matrix([[e[0] + sp.I * e[1], e[2] + sp.I * e[3]], [e[4] + sp.I * e[5], e[6] + sp.I * e[7]]])
    X = {v: gen(f"Y{i}") for i, v in enumerate(verts)}
    Z = gen("W")
    Px, Pxm = (I2 + SX) / 2, (I2 - SX) / 2
    Py, Pym = (I2 + SY) / 2, (I2 - SY) / 2
    lin = []
    for M in (X[(1, 1)] + X[(1, -1)] - Px, X[(-1, 1)] + X[(-1, -1)] - Pxm,
              X[(1, 1)] + X[(-1, 1)] - Py, X[(1, -1)] + X[(-1, -1)] - Pym, Z):
        for e in M:
            e = sp.expand(e)
            lin += [sp.expand(sp.re(e)), sp.expand(sp.im(e))]
    free = syms[:8]
    sol = sp.solve(lin, [s_ for s_ in syms if s_ not in free], dict=True)[0]
    pts = [(sp.Matrix(v), X[v].subs(sol)) for v in verts] + [(sp.zeros(2, 1), Z.subs(sol))]
    eqs = set()
    blocks = {}
    for h1, A1 in pts:
        for h2, A2 in pts:
            d = tuple(h1 - h2)
            blocks.setdefault(d, [sp.zeros(2), sp.zeros(2)])
            blocks[d][0] += A1 * A2.H
            blocks[d][1] += A2.H * A1
    for d, (m1, m2) in blocks.items():
        target = I2 if all(c == 0 for c in d) else sp.zeros(2)
        for M in (m1 - target, m2 - target):
            for e in M:
                e = sp.expand(e)
                for part in (sp.expand(sp.re(e)), sp.expand(sp.im(e))):
                    if part != 0:
                        eqs.add(part)
    G = sp.groebner(list(eqs), *free, order="lex")
    record("CONTROL square: saturation system is consistent (Groebner basis != {1})", list(G.exprs) != [1])
    # known walk: (cos kx - i sin kx sx)(cos ky - i sin ky sy), coefficient of shift (a,b)
    # with z^h <-> exp(-i k.h): factor = z_x P_x^+ + z_x^{-1} P_x^-, same for y
    known = Px * Py  # coefficient at (1,1) = P_x^+ P_y^+
    vals = dict(zip(free, [sp.re(known[0, 0]), sp.im(known[0, 0]), sp.re(known[0, 1]), sp.im(known[0, 1]),
                           sp.re(known[1, 0]), sp.im(known[1, 0]), sp.re(known[1, 1]), sp.im(known[1, 1])]))
    record("CONTROL square: the saturating walk exp(-ik_x s_x) exp(-ik_y s_y) solves it",
           all(sp.simplify(e.subs(vals)) == 0 for e in eqs))

# HEX_CEILING — frozen contract

**Frozen:** 2026-11-01, before solving. Nothing in Secs. 3–4 has been
computed or proved.
**Authorization:** direct user instruction, 2026-11-01: «adelante con el
punto 3, redacta el charter», then approval of this text («si»),
including the scope choices `s = 2` only and `n` unrestricted in T2.
Reports cite the commit that adds this file as the preregistration commit.
**Initial scientific status: OPEN.**

## 0. Single question

> On the hexagonal substrate, can a two-component walk of the declared
> product class reach the ceiling `c_0 = r_in(C_micro)`? If not, what is
> `sup c_0 / r_in` over the class, and is it attained?

Origin: in the promoted `C_ACROSS_LATTICES` table (CURRENT_STATE Sec. 11)
every declared square, BCC/cubic and line walk has `c_0 = r_in`, and none
of the four declared hexagonal walks does (`c_0/r_in = 1/sqrt3` for ADMP,
`sqrt3/2` for JDW). The table cannot tell whether this is a property of
the substrate or of those four walks. This gate asks that question
directly, by proof or by explicit counterexample, never by a scan.

## 1. Declared class `W_hex`

Fixed for every conclusion of this gate:

- **Lattice.** `Lambda` = triangular lattice generated by `g_1 = (1,0)`,
  `g_2 = (1/2, sqrt3/2)`; the walk is translation invariant on `Lambda`.
- **Internal dimension.** `s = 2`. No larger `s` (s=4 is excluded; see
  Sec. 6).
- **Form of one update.**
  `U(k) = C_n D_n(k) C_{n-1} D_{n-1}(k) ... C_1 D_1(k)`, with `n >= 1`
  arbitrary, `C_j in U(2)` arbitrary, and
  `D_j(k) = diag(exp(-i k.a_j), exp(-i k.b_j))`, `a_j, b_j in Lambda`
  (a partial shift: each component moves by its own lattice vector). An
  optional final coin `C_{n+1}` is absorbed by conjugation and does not
  change the spectrum. This contains every encoded hexagonal row of the
  previous gate: ADMP L6a (`a_j = -b_j`, coins built from `tau_i`) and JDW
  L6c, L6d, L6f (antipodal or skew partial shifts).
- **Substrate condition.** `C_micro = conv F` is a regular hexagon centred
  at the origin, where `F` is the composite Fourier support of `U`
  (vectors with nonzero matrix coefficient, computed exactly, not the set
  of formally admissible sums).
- **Node condition.** `U(0) = e^{-i phi} I` (degenerate quasienergy at
  `k = 0`, massless node), and the linear term
  `A(k) = i dU/dk (0) . k` (with the global phase removed) is traceless
  and isotropic: `A(n)^2 = c_0^2 |n|^2 I`, `c_0 > 0`.
- **Normalisation.** Longest vector of `F` has length 1 (so
  `r_in = sqrt3/2`, `V_causal^max = 1`); one update per time unit.
- **Not assumed.** No representation-isotropy in the P17 sense
  (P17 p.7 Prop. 5 excludes the triangular lattice for that stronger
  notion; `W_hex` asks only for an isotropic cone). No irreducibility
  beyond the node condition; a reducible walk is admitted but must be
  reported as such.

## 2. Background taken as input

- Promoted table, CURRENT_STATE Sec. 11, with its scope.
- The matrix Bernstein inequality for unitary trigonometric polynomials
  is prior art. Its consequence needed here, `||A(n)|| <= h_{C_micro}(n)`
  at a node with `U(0)` scalar, hence `c_0 <= r_in`, is **not** assumed:
  the repo has it only for the N3 class (Sec. 7.2). It is lemma L0 below,
  to be proved in-repo or cited with page from a primary source read in
  this gate.

## 3. Targets

- **L0 (ceiling).** For every walk in `W_hex`, `c_0 <= r_in`.
- **T1 (subclass n = 3, antipodal).** `n = 3`, `b_j = -a_j`, the `a_j`
  three lattice vectors at 120° (the ADMP / JDW L6d form). Determine
  `sup c_0/r_in` exactly, whether it is attained, and by which coins.
  This also explains the ADMP–JDW difference within that subclass.
- **T2 (general class).** Either prove `c_0 < r_in` for all of `W_hex`
  (with the best bound obtained), or exhibit an explicit walk in `W_hex`
  with `c_0 = r_in`, certified exactly.

## 4. Hypotheses, stated before solving

- **HX0.** L0 holds.
- **HX1.** In the T1 subclass, `c_0 < r_in` for every walk.
- **HX2.** In all of `W_hex`, `c_0 < r_in` for every walk.

stated; the table only gives `sup >= sqrt3/2` (JDW).
