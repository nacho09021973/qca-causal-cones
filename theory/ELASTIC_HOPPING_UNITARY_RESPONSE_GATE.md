## 1. Frozen flat CJWW data

Let the exact CJWW (5.15) walk have Fourier decomposition

\[
W_0(p)=\sum_{h\in F}e^{ip\cdot h}W_h,
\]

with the already certified 14-vector support \(F\).

No new Pauli matrices, valley labels or species-dependent coefficients are
introduced. The matrices \(W_h\) are exactly the flat CJWW Fourier blocks.

Choose once and for all an orientation set \(F_+\) containing one member of
each pair \(\{h,-h\}\). The result may not depend on the arbitrary orientation
choice because the generator below contains each oriented term together with
its adjoint.

## 2. Common elastic geometry

Use one symmetric strain tensor

\[
u=u^T\in\mathrm{Sym}(3),
\]

shared by all matter species.

The physical embedding is

\[
X_\varepsilon(n)=a(I+\varepsilon u)n,

\[
p=a(I+\varepsilon u)^Tq.
\]

The same \(u\) also controls the hopping response.

## 3. Frozen unitary hopping-response rule

For each \(h\in F_+\), set

\[
\rho_h(u)=\frac{h^Tuh}{h^Th}.
\]

Define the finite-range Hermitian bond-response symbol

\[
K_u(p)
=
\sum_{h\in F_+}
\rho_h(u)
\left(
e^{ip\cdot h}W_h
+
e^{-ip\cdot h}W_h^\dagger
\right).
\]

By construction,

\[
K_u(p)^\dagger=K_u(p).
\]

The deformed one-step symbol is frozen as

\[
\boxed{
W_{\varepsilon,u}(q)
=
e^{-i\varepsilon K_u(p)}
W_0(p),
\qquad
p=a(I+\varepsilon u)^Tq.
}
\]

The overall material hopping-response coefficient is absorbed into
\(\varepsilon\); no coefficient will be tuned after execution.

This is a **minimal unitary elastic-response ansatz**:
the strain coefficient is a scalar property of a bond, while all internal
matrix structure is inherited from the pre-existing CJWW hop block on that
bond.

\[

\(\delta q_*\) such that the traceless constant term vanishes to first order,

from the metric.
