## 0. Single question

> On the hexagonal substrate, can a two-component walk of the declared
> product class reach the ceiling `c_0 = r_in(C_micro)`? If not, what is
> `sup c_0 / r_in` over the class, and is it attained?

Origin: in the promoted `C_ACROSS_LATTICES` table (CURRENT_STATE Sec. 11)
every declared square, BCC/cubic and line walk has `c_0 = r_in`, and none
of the four declared hexagonal walks does (`c_0/r_in = 1/sqrt3` for ADMP,
`sqrt3/2` for JDW). The table cannot tell whether this is a property of
the substrate or of those four walks. This gate asks that question
directly, by proof or by explicit counterexample, never by a scan.

## 1. Declared class `W_hex`

Fixed for every conclusion of this gate:

- **Lattice.** `Lambda` = triangular lattice generated by `g_1 = (1,0)`,
  `g_2 = (1/2, sqrt3/2)`; the walk is translation invariant on `Lambda`.
- **Internal dimension.** `s = 2`. No larger `s` (s=4 is excluded; see
  Sec. 6).
- **Form of one update.**
  `U(k) = C_n D_n(k) C_{n-1} D_{n-1}(k) ... C_1 D_1(k)`, with `n >= 1`
  arbitrary, `C_j in U(2)` arbitrary, and
  `D_j(k) = diag(exp(-i k.a_j), exp(-i k.b_j))`, `a_j, b_j in Lambda`
  (a partial shift: each component moves by its own lattice vector). An
  optional final coin `C_{n+1}` is absorbed by conjugation and does not
  change the spectrum. This contains every encoded hexagonal row of the
  previous gate: ADMP L6a (`a_j = -b_j`, coins built from `tau_i`) and JDW
  L6c, L6d, L6f (antipodal or skew partial shifts).
- **Substrate condition.** `C_micro = conv F` is a regular hexagon centred
  at the origin, where `F` is the composite Fourier support of `U`
  (vectors with nonzero matrix coefficient, computed exactly, not the set
  of formally admissible sums).
- **Node condition.** `U(0) = e^{-i phi} I` (degenerate quasienergy at
  `k = 0`, massless node), and the linear term
  `A(k) = i dU/dk (0) . k` (with the global phase removed) is traceless
  and isotropic: `A(n)^2 = c_0^2 |n|^2 I`, `c_0 > 0`.
- **Normalisation.** Longest vector of `F` has length 1 (so
  `r_in = sqrt3/2`, `V_causal^max = 1`); one update per time unit.
- **Not assumed.** No representation-isotropy in the P17 sense
  (P17 p.7 Prop. 5 excludes the triangular lattice for that stronger
  notion; `W_hex` asks only for an isotropic cone). No irreducibility
  beyond the node condition; a reducible walk is admitted but must be
  reported as such.

## 2. Background taken as input

- Promoted table, CURRENT_STATE Sec. 11, with its scope.
- The matrix Bernstein inequality for unitary trigonometric polynomials
  is prior art. Its consequence needed here, `||A(n)|| <= h_{C_micro}(n)`
  at a node with `U(0)` scalar, hence `c_0 <= r_in`, is **not** assumed:
  the repo has it only for the N3 class (Sec. 7.2). It is lemma L0 below,
  to be proved in-repo or cited with page from a primary source read in
  this gate.

## 3. Targets

- **L0 (ceiling).** For every walk in `W_hex`, `c_0 <= r_in`.
- **T1 (subclass n = 3, antipodal).** `n = 3`, `b_j = -a_j`, the `a_j`
  three lattice vectors at 120° (the ADMP / JDW L6d form). Determine
  `sup c_0/r_in` exactly, whether it is attained, and by which coins.
  This also explains the ADMP–JDW difference within that subclass.
- **T2 (general class).** Either prove `c_0 < r_in` for all of `W_hex`
  (with the best bound obtained), or exhibit an explicit walk in `W_hex`
  with `c_0 = r_in`, certified exactly.

## 4. Hypotheses, stated before solving

- **HX0.** L0 holds.
- **HX1.** In the T1 subclass, `c_0 < r_in` for every walk.
- **HX2.** In all of `W_hex`, `c_0 < r_in` for every walk.

Each refutation is a valid outcome. No expected value of the supremum is
stated; the table only gives `sup >= sqrt3/2` (JDW).

## 5. Method and stop rules

- Exact algebra and geometry first. Proofs are written in a report; any
  computation is a permanent traced verifier
  (`scripts/verify_hex_ceiling_gate.py`, fail-closed, exact).
- A witness walk (refuting HX1 or HX2) must be given in closed form and
  certified exactly: unitarity, composite `F`, regular hexagonal hull,
  node, isotropy, `c_0`.
- Numerical exploration may guide a construction or a proof idea only if
  done by a versioned script and labelled exploratory. **No numerical
  result, scan, optimisation or failed search may enter a verdict**, and
  no rigidity may be inferred from one.
- If a proof is obtained only for a restricted subclass (e.g. bounded
  `n`, antipodal shifts), the result is stated for that subclass only and
  not extrapolated.
- Stop when T1 and T2 each reach a verdict, or when T2 is recorded as
  `OPEN_AFTER_<analysis>` with the analysis that was done. Do not widen the
  class during execution.

## 6. Exclusions

`s > 2`, other lattices, inhomogeneous or encoded walks (e.g.
Arrighi–Facchini), masses, `V_grp^max`, new substrate classes, general QCA
laws, claims about our universe. No novelty claim (Bernstein is prior
art).
