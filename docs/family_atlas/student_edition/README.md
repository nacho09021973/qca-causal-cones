# Atlas QCA/QW — edición para estudiantes

Esta es la versión introductoria del [atlas de familias](../FAMILY_BIBLE.md).
Está pensada para estudiantes de física con mecánica cuántica básica y algo de
álgebra lineal.

La edición pedagógica explica intuiciones y ejemplos. El atlas canónico sigue
siendo la autoridad para estados, cuantificadores, fuentes y claim ceilings.
Cuando haya una diferencia de detalle, manda el atlas canónico y
[`CURRENT_STATE.md`](../../../state/CURRENT_STATE.md).

## Una advertencia importante

En este proyecto aparecen frases como «gravedad emergente», «gauge» o
«Lorentz». No siempre significan lo mismo. Una regla local puede producir una
ecuación parecida a Weyl en el infrarrojo sin producir una métrica dinámica,
una fuente gravitatoria o una simetría gauge microscópica.

La pregunta que acompaña cada resultado es:

> ¿Qué se ha demostrado exactamente, bajo qué hipótesis y qué no permite
> concluir?
