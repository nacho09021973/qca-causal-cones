# qca-causal-cones

Finite-range quantum cellular automata (QCA): can one substrate, with one
fixed update rule, both compute universally and look relativistic at low
energy?

## Current research snapshot (2026-11-26)

**The main coexistence problem remains OPEN.** No single fixed, autonomous,
finite-range QCA has yet been shown *in this project* to supply both
composable universal quantum computation and a controlled interacting
relativistic low-energy regime. A positive result on one code, or on one
kinematic observable, must not be promoted to that conjunction.

Two distinct lines must not be conflated:

See the table below. | F, universal *composable* computation with allowed resources, and the interacting relativistic limit: **OPEN**. |
| **Dispersive-horizon quantum walk, prescribed spatial profile** | Author derivation of a local unitary walk with negative outgoing IR velocity inside, positive outside, positive UV branch on both sides, exact microscopic support and an explicit stationary 12×12 transfer matrix. | Independent audit, *actual* stationary transmission through the full inhomogeneous profile, and novelty: **OPEN**. This is **not** a dynamical horizon generated by a homogeneous rule. |

### New exploratory line: dispersive horizon and transfer matrix

The separate one-particle construction uses local real coins
\(C(\beta)=e^{-i\beta\sigma_y}\), conditional shift \(S\), and a uniform
left shift \(L_-\), with explicit conventions in the report:

\[
W=S C(\theta)S C(\theta)S C(-2\theta),\qquad
U=L_-W^2,\qquad
\theta_x=\arccos\sqrt{t_L(x)},
\]
\[
t_L(x)=\frac38+\frac1{16}\tanh(x/L),\quad L>0.
\]

The full update is unitary, with microscopic support
\(C_{\mathrm{micro}}=[-7,5]\). For the frozen homogeneous symbol,
\(A=t(2t-1)\) and
\[
\cos E=A\cos 3k+(1-A)\cos k,\qquad
\Omega_\pm=-k\pm 2E.
\]
The outgoing infrared velocity is \(v_{\mathrm{IR,out}}=8t-3\):
**−1/2 inside, 0 at the nominal horizon, +1/2 outside**. At \(k=\pi/2\)
the outgoing high-momentum branch has \(v_{\mathrm{UV,out}}=1-8A>0\)
at all three profile values. A nondegenerate outgoing branch at a common
nearby quasienergy exists for the *locally frozen* symbols. None of these
facts on its own establishes transmission in the spatially varying walk.

The stationary equation \(U\psi=z\psi\) has an explicit **12×12 spatial
transfer matrix** \(Y_{x+1}=M_x(z)Y_x\), accounting for the coins at both
\(x\) and \(x+1\), with
\[
\det M_x(z)=\frac{\cot\theta_x}{\cot\theta_{x+1}}.
\]
The full 144-entry construction (given as 12 recurrence rows and four
6×6 blocks), homogeneous characteristic polynomial, preliminary numerical
checks, and two discarded simpler prototypes are documented in
[the 2026-11-26 report](reports/2026-11-26--dispersive-horizon-three-step-transfer.md).

**Evidence ceiling:** `DERIVACION_DE_AUTOR — NO AUDITADA`;
`TRANSMISSION = OPEN`; `NOVELTY = OPEN`. The numerical checks are
floating-point consistency tests, not a proof or independent certification.
The walk has an **externally imposed** spatial profile; it does not
demonstrate spontaneous/emergent spacetime geometry, a general-relativistic
black hole, Hawking radiation or universal computation. The Floquet
degeneracy at \(k=\pi/2\) also requires a species/doubling audit before
interpreting the UV branch as the same infrared field.

**Next single gate:** independently verify the transfer recurrence,
determinant and homogeneous dispersion *before* attempting a stationary
scattering computation. Only after that: determine whether the physical
flux-normalized transmission probability \(\mathcal T_L(\omega_*)\) is
strictly positive for the full tanh profile. If it is, check prior art
before making any novelty claim. The longer-term goal of a horizon
generated by an autonomous homogeneous rule is conceptually separate.

## Project question

Does a single finite-range QCA, evolving under one fixed local rule, admit
**both**

1. **universal quantum computation**: an encoding of qubits in its states
   such that the rule itself, with no external control of its free or
   interacting parts, implements an entangling gate set that composes into
   a universal set, with preparation and readout stated explicitly; and
2. **a relativistic low-energy regime of the same rule**: an effective
   propagation speed `c_IR` for its low-energy excitations, with the
   interacting dynamics, not only free envelopes, controlled?

The question is stated per code, per resource set (ancillas, measurement,
geometry) and per parameter choice. A negative answer for one code is not a
no-go for the substrate. The working model is the Thirring QCA
(`sources/1711.03920v1.pdf`, `sources/1804.08508v1.pdf`): a one-dimensional
Dirac walk with an on-site two-fermion phase, `U = F J`.

Two distinctions are kept throughout:

- `C_micro` (causal body fixed by locality), `V_grp^max` (group-velocity
  envelope) and `c_IR` (low-energy speed) are different objects
  ([`theory/THREE_VELOCITIES.md`](theory/THREE_VELOCITIES.md)); never write
  `v_max` unqualified.
- `c_IR` has units of length per time and an update frequency has units of
  inverse time. Comparing them needs a spatial scale, a time scale and the
  relevant dimensionless coefficient.

## Why the question changed

The repository started with a narrower question: can `c_IR` be derived from
the causal geometry of the substrate alone? The answer found is that, in
general, it cannot (summary below). The coexistence question above is more
concrete: it names the operations that must be shown, and each can be
proved or excluded for a declared code.

Read together: the fixed rule produces an exact entangling gate once, but in
the microscopic codes tested it neither keeps the code closed under
repeated contacts nor yields a universal set. In the flavour-packet code,
low-energy packets crossing in either direction act by one leakage-free
entangling family `V(r)`; under F, at `χ = π/2`, these crossings are
classically simulable matchgates, so crossings alone in that code and
with those resources are not a route to universality (an efficient
universal construction would imply BQP ⊆ P). Free nodal envelopes have
`c_IR = a/tau`. No interacting relativistic limit has been established.
Open: F itself, `χ ≢ π/2 (mod π)`, other codes, ancillas or measurement,
composition with controlled error, and the low-energy regime of the
interacting rule.

## How to work here

Read `CLAUDE.md`, `PROJECT_INSTRUCTIONS.md` and `state/CURRENT_STATE.md`
first; for the separate horizon line, read the 2026-11-26 report as well. Every result follows the cycle: frozen contract in `theory/`,
execution in `reports/` with a permanent verifier in `scripts/`, independent
cross-family review, and a separate promotion commit. No result is promoted
because it fits the narrative.

```sh
pip install -r scripts/requirements.txt          # Python 3.12, sympy==1.14.0, numpy==1.26.4
python3 -B scripts/verify_<gate>.py              # run from the repo root; fails closed
cd formal && lake exe cache get && lake build   # Lean fragment
```

[`scripts/README.md`](scripts/README.md) states what each verifier certifies
and what it does not.
